## Formato de Archivos de Idioma

Los archivos de idioma están en formato JSON, almacenados en el directorio `game/lang/`:

```json
{
  "window_title": "Wayward Crown",
  "log_defeated_enemy": "{adv} derrotó a {enemy} (Oro: {gold} XP: {xp})",
  "building_market": "Mercado",
  "class_warrior": "Guerrero"
}
```

- Soporta sustitución dinámica con `{marcador}`
- Las claves de traducción faltantes recurren automáticamente al inglés
- Cambiar de idioma surte efecto inmediatamente sin necesidad de reiniciar

---

## Orden de Detección de Idioma

1. Argumento CLI `--lang` / `--language` (máxima prioridad; solo se aplica a esta sesión y no se guarda)
2. Idioma seleccionado manualmente por el usuario en el menú de ajustes (elegir "Automático" allí lo borra)
3. Idioma del cliente de Steam (detección automática en cada inicio mientras no haya una elección manual)
4. El idioma usado la última vez
5. Inglés (idioma predeterminado)

## Añadir Idiomas (Plugins)

Añadir un idioma mediante un plugin solo requiere un archivo de traducción y un `plugin.json` que lo incluya en `content.languages` (un archivo que no aparece en la lista no se carga):

```
plugins/my_lang/
├── plugin.json
└── lang/
    └── xx.json    # Tu código de idioma
```

```json
{
  "id": "my_lang",
  "name": "My Language",
  "content": {"languages": ["lang/xx.json"]}
}
```

El código de idioma y el nombre que se muestra en la lista de idiomas proceden del bloque `_meta` del archivo (`"_meta": {"language": "xx", "label": "My Language"}`); sin él se usa el nombre del archivo. El código puede ser cualquier cadena de texto (por ejemplo, `ja`, `ko`, `my_custom`) y aparecerá automáticamente en la lista de idiomas del menú de ajustes.

## Internacionalización de Campañas

El texto de las campañas puede usar el prefijo `i18n:` para hacer referencia a claves de traducción:

```json
{
  "title": "i18n:tut_level1_title",
  "intro": "i18n:tut_level1_intro"
}
```

El juego resuelve automáticamente las claves de traducción según el idioma actual. Si no se encuentra una traducción correspondiente, se muestra el nombre de la clave tal cual.
