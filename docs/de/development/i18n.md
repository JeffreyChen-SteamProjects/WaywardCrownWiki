## Sprachdatei-Format

Sprachdateien liegen im JSON-Format im Verzeichnis `game/lang/`:

```json
{
  "window_title": "Wayward Crown",
  "log_defeated_enemy": "{adv} defeated {enemy} (Gold: {gold} XP: {xp})",
  "building_market": "Market",
  "class_warrior": "Warrior"
}
```

- Unterstützt dynamische Ersetzung mit `{placeholder}`
- Fehlende Übersetzungsschlüssel fallen automatisch auf Englisch zurück
- Ein Sprachwechsel wird sofort wirksam, ohne Neustart

---

## Reihenfolge der Spracherkennung

1. CLI-Argument `--lang` / `--language` (höchste Priorität; gilt nur für diese Sitzung und wird nicht gespeichert)
2. Vom Benutzer manuell im Einstellungsmenü gewählte Sprache (die Auswahl „Automatisch“ dort hebt sie auf)
3. Sprache des Steam-Clients (bei jedem Start automatisch erkannt, solange keine manuelle Auswahl besteht)
4. Die zuletzt verwendete Sprache
5. Englisch (Standard-Fallback)

## Sprachen per Plugin hinzufügen

Um eine Sprache per Plugin hinzuzufügen, werden nur eine Übersetzungsdatei und eine `plugin.json` benötigt, die sie unter `content.languages` aufführt (eine nicht aufgeführte Datei wird nicht geladen):

```
plugins/my_lang/
├── plugin.json
└── lang/
    └── xx.json    # Your language code
```

```json
{
  "id": "my_lang",
  "name": "My Language",
  "content": {"languages": ["lang/xx.json"]}
}
```

Der Sprachcode und der in der Sprachauswahl angezeigte Name stammen aus dem `_meta`-Block der Datei (`"_meta": {"language": "xx", "label": "My Language"}`); ohne ihn wird der Dateiname verwendet. Der Code kann eine beliebige Zeichenkette sein (z.B. `ja`, `ko`, `my_custom`) und erscheint automatisch in der Sprachauswahl im Einstellungsmenü.

## Kampagnen-Internationalisierung

Kampagnentexte können das Präfix `i18n:` verwenden, um auf Übersetzungsschlüssel zu verweisen:

```json
{
  "title": "i18n:tut_level1_title",
  "intro": "i18n:tut_level1_intro"
}
```

Das Spiel löst Übersetzungsschlüssel automatisch anhand der aktuellen Sprache auf. Wird keine passende Übersetzung gefunden, wird der Schlüsselname unverändert angezeigt.
