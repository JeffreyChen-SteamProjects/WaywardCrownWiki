## Deine Rolle

Du bist der Verwalter von Wayward Crown. Du **kannst** die Bewegungen oder Angriffe von Abenteurern nicht direkt steuern — sie handeln autonom basierend auf ihrer Persönlichkeit, ihren Bedürfnissen und ihrem aktuellen Zustand.

Was du tun kannst:

- **Auftragsflaggen** platzieren, um Abenteurer mit Goldbelohnungen an bestimmte Orte zu locken
- **Gebäude** errichten, um bestimmte Klassen zu rekrutieren und Ausrüstung sowie Rastplätze bereitzustellen
- Fähigkeiten in der **Bibliothek** erforschen, um alle Abenteurer zu stärken
- Die **Wirtschaft** verwalten, um Einnahmen und Ausgaben im Gleichgewicht zu halten, damit die Gilde funktionsfähig bleibt

---

## Dein erstes Spiel

### 1. Erste Bauphase

Du startest das Spiel mit **1.500 Gold** und einer Burg. Baue in dieser Reihenfolge:

1. **Kaserne** (150g) — Rekrutiert Krieger, deine grundlegendste Kampftruppe
2. **Markt** (300g) — Liefert ein stetiges Steuereinkommen
3. **Gasthaus** (120g) — Ermöglicht verletzten Abenteurern Rast und HP-Regeneration
4. **Wachposten** (120g) — Rekrutiert Wachen, die Gebäude patrouillieren und schützen

:::tip[Tipps zur Gebäudeplatzierung]
Beim Platzieren von Gebäuden erscheint eine Bauplanvorschau: **Blau** bedeutet, der Standort ist gültig, **Rot** bedeutet, er ist es nicht. Gebäude brauchen erforschten, trockenen Boden, mindestens 14 Felder Abstand zur Burg und 3 Felder zu anderen Gebäuden.
:::

### 2. Aufträge veröffentlichen

Klicke auf die Auftragsschaltfläche im linken Bereich, um Flaggen auf der Karte zu platzieren:

- **Erkundungsauftrag** — Enthüllt den Nebel des Krieges und entdeckt neue Gebiete
- **Tötungsauftrag** — Schickt Abenteurer los, um ein bestimmtes Ziel zu eliminieren
- **Verteidigungsauftrag** — Weist Abenteurer zu, eines deiner Gebäude oder die Burg zu patrouillieren und zu bewachen

:::note[Auftragsbelohnungen]
Je höher die Belohnung, desto mehr Abenteurer sind bereit, den Auftrag anzunehmen. Behalte aber dein Budget im Auge!
:::

### 3. Beobachten und Anpassen

Abenteurer werden automatisch:

- Tränke und Ausrüstung in Läden nahe der Burg kaufen
- Aufträge annehmen, die zu ihrer Persönlichkeit passen
- Feinde im Kampf angreifen, wenn sie auf sie treffen
- Zur Rast zurückkehren, wenn ihre HP niedrig sind
- Unbekannte Gebiete erkunden und Schatzkisten plündern

### 4. Auf Bedrohungen reagieren

Im Spielverlauf treten verschiedene Zufallsereignisse auf:

- **Monsterinvasion**: Eine große Feindwelle greift die Burg an
- **Blutmond**: Feindliche Angriffskraft steigt
- **Drachennest**: Ein Drachennest erscheint in der Ferne und muss zerstört werden

Stelle sicher, dass du genügend Kämpfer und Pfeiltürme zur Verteidigung hast!

## Wirtschaftsmanagement

### Einnahmequellen

| Quelle | Betrag | Häufigkeit |
|--------|--------|-----------|
| Markteinkommen | 30g × Marktstufe | Alle 72 Sekunden Spielzeit |
| Steuer | 20% dessen, was Abenteurer ausgeben oder verdienen | Wenn Abenteurer kaufen, studieren, töten oder Truhen öffnen |

Steuern und Markteinkommen warten in der Kasse des Gebäudes, bis ein Steuereintreiber sie zur Burg trägt.

### Hauptausgaben

| Posten | Kosten |
|--------|--------|
| Gebäudebau | 0 – 300g (jedes weitere Exemplar eines Typs kostet 50% mehr) |
| Gebäude-Upgrades | 140 – 600g |
| Auftragsbelohnungen | Individuell (Standard 200g) |
| Fähigkeitsforschung | 150 – 900g |

:::caution[Warnung]
Die Gilde kann nicht funktionieren, wenn die Ausgaben die Einnahmen übersteigen. Priorisiere den Bau von Märkten, um einen stabilen Einkommensstrom zu sichern.
:::

## Schwierigkeitseinstellungen

Du kannst folgende Einstellungen beim Start eines neuen Spiels anpassen:

| Einstellung | Beschreibung | Standard |
|-------------|-------------|---------|
| Feindverhältnis | Anzahl der Feinde pro Abenteurer | 2 |
| Feind-HP-Multiplikator | HP-Multiplikator der Feinde | 1.0x |
| Gold-Multiplikator | Gold-Einnahmen-Multiplikator | 1.0x |
| Feindliche Festungen | Anzahl feindlicher Festungen auf der Karte | 3 |
| Kartengröße | Kantenlänge der Karte (250 – 1000) | 1000 |
| Sandkasten-Festungsvolk | Beschränkt die erzeugten Festungen auf ein Volk | Beliebig |
| Sandkasten-Schwierigkeit | Leicht, Normal oder Schwer: ein Angreifer weniger oder zwei mehr in jedem Raubzug eines Unterschlupfs | Normal |
| Boss-Herausforderung | Häuptling Knirschzahn kommt einmal, nach 20 Minuten | Aus |

Leicht und Schwer ändern nie die Lebenspunkte der Feinde: Leicht nimmt jedem Raubzug eines Unterschlupfs einen Angreifer, Schwer gibt ihm zwei mehr; in einem Kampagnenlevel, dessen Schwierigkeit im Missionsbildschirm gewählt wird, hat eine geskriptete Welle außerdem 75% oder 125% ihrer Größe, und das Level beginnt mit 125% oder 85% seines Goldes. Steht keine Gilde mehr und fehlt das Gold für eine neue, gleicht die Krone die Differenz aus (höchstens einmal alle fünf Minuten). Die Schwierigkeit legt auch fest, wie lange das Königreich Zeit hat, sich auf selbst verursachten Druck vorzubereiten, die ruhige Anfangszeit ebenso wie die Vorwarnung vor einem Rudel: 125 % der üblichen Zeit auf Leicht, 80 % auf Schwer. Die Warnung kommt immer.

## Steuerung

| Aktion | Beschreibung |
|--------|-------------|
| Scrollrad | Karte zoomen |
| Rechtsklick ziehen | Kamera schwenken |
| Linksklick auf eine Einheit | Detaillierte Infos anzeigen |
| Linksklick auf die Karte | Gebäude / Auftrag platzieren |
| Linksklick ziehen | Eine Straße zeichnen (mit dem Straßenwerkzeug) |
| Rechtsklick ohne Ziehen | Auftragsmenü öffnen |
| Leertaste | Pause / Fortsetzen |
| 1 / 2 / 3 | Spielgeschwindigkeit (setzt ein pausiertes Spiel auch fort) |
| Esc | Platzierung eines Gebäudes oder Kopfgelds abbrechen, sonst das Spielmenü öffnen (Speichern, Laden, Einstellungen, Level neu starten, Hauptmenü) |
| Umschalt + Linksklick | Ein Gebäude platzieren und ausgewählt lassen |
| Doppelklick auf die Karte | Das Kopfgeld aufgeben, das zu dem passt, was dort ist |
| Strg+S / Strg+O | Spiel speichern / laden |
| Klick auf die Minikarte | Zu diesem Ort springen |
| Pos1 | Burg zeigen |
| P | Fenster der Burgwege (auf Karten mit Burgwegen) |
| K / C | Königreichsübersicht / Chronik |
| L | Die Verzeichnisse: jeder Held, jede Gilde, jede Arbeit und die Einnahmen jedes Gebäudes, mit Filtern |
| M | Die Kartenebenen: Versorgung, Gold unterwegs, Arbeiten, bekannte Bedrohungen, Zauberreichweite |
| Klick auf eine Meldung zu einem Ort | Diesen Ort zeigen |
| Klick auf das Gold | Königreichsübersicht öffnen |
| F | Baumenü durchsuchen |
| Q / W | Ersten / zweiten königlichen Zauber bereit machen |
| A / S / D / G / H | Eine Auftragsart aufnehmen, in der Reihenfolge des Reiters (dieselbe Taste legt sie wieder weg) |
| B | Das zuletzt gebaute Gebäude noch einmal aufnehmen |
| F6, dann Tab | Tastatur ins nächste Fenster bringen und durch seine Bedienelemente gehen (Esc zurück zur Karte) |

Jede Taste oben außer Esc lässt sich unter Einstellungen > Tasten ändern; eine Taste, die zwei Aktionen hat, gilt für die erste in der Liste, und die Einstellungen sagen es; eine schon belegte Taste wird abgelehnt. Eine Ziffer des Ziffernblocks zählt als die Ziffer. Eine gehaltene Taste wirkt nur einmal.

Ein kurzer Hinweis kommt, wenn zum ersten Mal etwas Neues möglich ist: eine Baustelle, eine zu leerende Kasse, ein Auftrag, den niemand annimmt, eine Burg, die ausgebaut werden kann, ein Weg zur Wahl, eine Spezialisierung zur Wahl, ein bereiter Zauber. Jeder kommt einmal, steht in der Chronik zum Nachlesen, die Ratgeber-Einstellung stellt seine Meldung stumm, und Einstellungen > Hinweise erneut zeigen holt alle zurück. Spätere kommen mit den Systemen, zu denen sie gehören: die Kartenebenen, sobald ein Unterschlupf bekannt ist, die Reihenfolge der Arbeiten, wenn sich Arbeiten stauen, gebundenes Gold, selbst verursachter Druck, ein Held, dessen Gilde fort ist, ein Held, der ans Gehen denkt.
