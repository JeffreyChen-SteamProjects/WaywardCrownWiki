## บทบาทของคุณ

คุณคือผู้จัดการ Wayward Crown คุณ **ไม่สามารถ** ควบคุมการเคลื่อนที่หรือการโจมตีของนักผจญภัยได้โดยตรง — พวกเขากระทำอย่างอิสระตามบุคลิกภาพ ความต้องการ และสถานะปัจจุบัน

สิ่งที่คุณทำได้:

- วาง **ธงค่าหัว** เพื่อดึงดูดนักผจญภัยไปยังตำแหน่งเฉพาะด้วยรางวัลทอง
- สร้าง **อาคาร** เพื่อรับสมัครคลาสเฉพาะและจัดหาอุปกรณ์และสถานที่พักผ่อน
- วิจัยทักษะที่ **ห้องสมุด** เพื่อเสริมความแกร่งให้นักผจญภัยทุกคน
- จัดการ **เศรษฐกิจ** เพื่อให้รายรับและรายจ่ายสมดุล เพื่อให้สมาคมดำเนินงานต่อไปได้

---

## เกมแรกของคุณ

### 1. การก่อสร้างเริ่มต้น

คุณเริ่มเกมด้วย **ทอง 1,500** และปราสาท สร้างตามลำดับนี้:

1. **ค่ายทหาร** (150g) — รับสมัครนักรบ กำลังรบพื้นฐานที่สุดของคุณ
2. **ตลาด** (300g) — ให้รายได้ภาษีที่มั่นคง
3. **โรงแรม** (120g) — ให้นักผจญภัยที่บาดเจ็บพักฟื้นและฟื้นฟู HP
4. **ป้อมยาม** (120g) — รับสมัครองครักษ์เพื่อลาดตระเวนและป้องกันอาคาร

:::tip[เคล็ดลับการวางอาคาร]
แบบพิมพ์เขียวจะแสดงเมื่อวางอาคาร: **สีน้ำเงิน** หมายถึงตำแหน่งถูกต้อง **สีแดง** หมายถึงไม่ถูกต้อง อาคารต้องวางบนพื้นดินแห้งที่สำรวจแล้ว ห่างจากปราสาทอย่างน้อย 14 ช่อง และห่างจากอาคารอื่นอย่างน้อย 3 ช่อง
:::

### 2. ประกาศค่าหัว

คลิกปุ่มค่าหัวที่แผงด้านซ้ายเพื่อวางธงบนแผนที่:

- **ค่าหัวสำรวจ** — เปิดเผยหมอกสงครามและค้นพบพื้นที่ใหม่
- **ค่าหัวสังหาร** — ส่งนักผจญภัยไปกำจัดเป้าหมายที่กำหนด
- **ค่าหัวป้องกัน** — มอบหมายนักผจญภัยให้ลาดตระเวนและรักษาอาคารหนึ่งของคุณหรือปราสาท

:::note[รางวัลค่าหัว]
ยิ่งรางวัลสูง นักผจญภัยจะยิ่งเต็มใจรับค่าหัวมากขึ้น แต่อย่าลืมดูงบประมาณด้วย!
:::

### 3. สังเกตและปรับตัว

นักผจญภัยจะทำสิ่งต่อไปนี้โดยอัตโนมัติ:

- ซื้อยาและอุปกรณ์จากร้านค้าใกล้ปราสาท
- รับค่าหัวที่ตรงกับบุคลิกภาพของตน
- เข้าสู้รบกับศัตรูเมื่อพบเจอ
- กลับมาพักผ่อนเมื่อ HP ต่ำ
- สำรวจพื้นที่ที่ไม่รู้จักและเก็บหีบสมบัติ

### 4. ตอบสนองต่อภัยคุกคาม

เมื่อเกมดำเนินไป จะเกิดเหตุการณ์สุ่มต่าง ๆ:

- **การรุกรานของสัตว์ประหลาด**: ศัตรูจำนวนมากโจมตีปราสาท
- **ดวงจันทร์สีเลือด**: พลังโจมตีของศัตรูเพิ่มขึ้น
- **รังมังกร**: รังมังกรปรากฏขึ้นในระยะไกลและต้องถูกทำลาย

ตรวจสอบให้แน่ใจว่าคุณมีนักสู้และหอคอยธนูเพียงพอเพื่อป้องกัน!

## การบริหารเศรษฐกิจ

### แหล่งรายได้

| แหล่ง | จำนวน | ความถี่ |
|--------|--------|---------|
| รายได้จากตลาด | 30g × ระดับตลาด | ทุก 72 วินาทีของเวลาในเกม |
| ภาษี | 20% ของทองที่นักผจญภัยใช้หรือได้รับ | เมื่อนักผจญภัยซื้อของ ศึกษา สังหาร หรือเปิดหีบ |

ภาษีและรายได้จากตลาดจะรออยู่ในลิ้นชักเงินของอาคาร จนกว่าคนเก็บภาษีจะนำไปยังปราสาท

### ค่าใช้จ่ายหลัก

| รายการ | ค่าใช้จ่าย |
|--------|------------|
| การก่อสร้างอาคาร | 0 – 300g (อาคารประเภทเดิมแต่ละหลังที่เพิ่มขึ้นแพงขึ้น 50%) |
| การอัปเกรดอาคาร | 140 – 600g |
| รางวัลค่าหัว | กำหนดเอง (ค่าเริ่มต้น 200g) |
| การวิจัยทักษะ | 150 – 900g |

:::caution[คำเตือน]
สมาคมจะไม่สามารถดำเนินงานได้หากรายจ่ายเกินรายรับ ให้ความสำคัญกับการสร้างตลาดเพื่อรักษาแหล่งรายได้ที่มั่นคง
:::

## การตั้งค่าความยาก

คุณสามารถปรับค่าต่อไปนี้เมื่อเริ่มเกมใหม่:

| การตั้งค่า | คำอธิบาย | ค่าเริ่มต้น |
|-------------|----------|-------------|
| อัตราส่วนศัตรู | จำนวนศัตรูต่อนักผจญภัย | 2 |
| ตัวคูณ HP ศัตรู | ตัวคูณ HP ของศัตรู | 1.0x |
| ตัวคูณทอง | ตัวคูณการได้รับทอง | 1.0x |
| ฐานที่มั่นศัตรู | จำนวนฐานที่มั่นศัตรูบนแผนที่ | 3 |
| ขนาดแผนที่ | ความยาวขอบแผนที่ (250 – 1000) | 1000 |
| เผ่าของฐานที่มั่นในแซนด์บ็อกซ์ | จำกัดฐานที่มั่นที่สร้างขึ้นให้เป็นเผ่าเดียว | อะไรก็ได้ |
| ความยากแซนด์บ็อกซ์ | ง่าย ปกติ หรือ ยาก: การปล้นจากรังแต่ละครั้งมีน้อยลงหนึ่งตัวหรือมากขึ้นสองตัว | ปกติ |
| ท้าทายบอส | หัวหน้าเผ่าเขี้ยวขบมาหนึ่งครั้ง หลังผ่านไป 20 นาที | ปิด |

ระดับง่ายและยากไม่เปลี่ยนพลังชีวิตของศัตรูเลย: ระดับง่ายลดกองปล้นจากรังครั้งละหนึ่งตัว ระดับยากเพิ่มสองตัว ในด่านแคมเปญ ซึ่งเลือกความยากที่หน้าจอภารกิจ คลื่นตามสคริปต์ยังมีขนาด 75% หรือ 125% และด่านเริ่มด้วยทอง 125% หรือ 85% หากไม่เหลือกิลด์และไม่มีทองสร้างใหม่ ราชสำนักจะออกส่วนต่างให้ (ไม่เกินหนึ่งครั้งทุกห้านาที) ระดับความยากยังกำหนดเวลาที่อาณาจักรมีไว้เตรียมรับแรงกดดันที่นำมาสู่ตัวเอง ทั้งช่วงต้นที่สงบและคำเตือนก่อนฝูงจะมา: 125% ของเวลาปกติในระดับง่าย 80% ในระดับยาก คำเตือนมาเสมอ

## การควบคุม

| การกระทำ | คำอธิบาย |
|----------|----------|
| ล้อเลื่อน | ซูมแผนที่ |
| คลิกขวาลาก | เลื่อนกล้อง |
| คลิกซ้ายที่หน่วย | ดูข้อมูลรายละเอียด |
| คลิกซ้ายที่แผนที่ | วางอาคาร / ค่าหัว |
| คลิกซ้ายลาก | วาดถนน (ด้วยเครื่องมือถนน) |
| คลิกขวาโดยไม่ลาก | เปิดเมนูค่าหัว |
| Space | หยุดชั่วคราว / เล่นต่อ |
| 1 / 2 / 3 | ความเร็วเกม (และเล่นต่อหากหยุดชั่วคราวอยู่) |
| Esc | ยกเลิกการวางอาคารหรือค่าหัว ถ้าไม่ได้วางอยู่จะเปิดเมนูเกม (บันทึก โหลด ตั้งค่า เริ่มด่านใหม่ เมนูหลัก) |
| Shift + คลิกซ้าย | วางอาคารแล้วยังเลือกอาคารนั้นค้างไว้ |
| ดับเบิลคลิกบนแผนที่ | ตั้งค่าหัวที่เหมาะกับสิ่งที่อยู่ตรงนั้น |
| Ctrl+S / Ctrl+O | บันทึก / โหลดเกม |
| คลิกมินิแมป | กระโดดไปยังตำแหน่งนั้น |
| Home | แสดงปราสาท |
| P | หน้าต่างเส้นทางของปราสาท (แผนที่ที่มีเส้นทาง) |
| K / C | ภาพรวมอาณาจักร / บันทึกเหตุการณ์ |
| L | ทะเบียน: วีรบุรุษ กิลด์ งานก่อสร้าง และรายได้ของอาคารทุกแห่ง พร้อมตัวกรอง |
| M | เลเยอร์แผนที่: เสบียง ทองที่กำลังเดินทาง งานก่อสร้าง ภัยคุกคามที่รู้จัก ระยะเวท |
| คลิกข้อความที่บอกสถานที่ | แสดงสถานที่นั้น |
| คลิกทอง | เปิดภาพรวมอาณาจักร |
| F | ค้นหาในเมนูก่อสร้าง |
| Q / W | เตรียมเวทของราชสำนักอันแรก / อันที่สอง |
| A / S / D / G / H | หยิบประเภทค่าหัวตามลำดับในแผง (กดปุ่มเดิมอีกครั้งเพื่อวางลง) |
| B | หยิบอาคารที่วางล่าสุดอีกครั้ง |
| F6 แล้ว Tab | ย้ายแป้นพิมพ์ไปแผงถัดไปและไล่ตัวควบคุมในแผง (Esc กลับไปที่แผนที่) |

ทุกปุ่มด้านบนยกเว้น Esc เปลี่ยนได้ใน การตั้งค่า > ปุ่ม ปุ่มที่ตั้งให้สองการกระทำจะใช้กับอันแรกในรายการ และหน้าการตั้งค่าจะบอกไว้ ปุ่มที่ถูกใช้แล้วจะถูกปฏิเสธ ตัวเลขบนแป้นตัวเลขนับเป็นตัวเลขนั้น การกดปุ่มค้างไว้จะทำงานเพียงครั้งเดียว

คำแนะนำสั้น ๆ จะปรากฏเมื่อทำสิ่งใหม่ได้เป็นครั้งแรก: ไซต์ก่อสร้าง ลิ้นชักเงินที่ควรเก็บ ค่าหัวที่ไม่มีใครรับ ปราสาทที่พร้อมยกระดับ เส้นทางที่เลือกได้ ความเชี่ยวชาญที่เลือกได้ เวทที่พร้อมใช้ แต่ละคำแนะนำมาเพียงครั้งเดียว อยู่ในบันทึกเหตุการณ์ให้อ่านซ้ำได้ การตั้งค่าที่ปรึกษาปิดป๊อปอัปได้ และ การตั้งค่า > แสดงคำแนะนำอีกครั้ง จะนำทั้งหมดกลับมา คำแนะนำช่วงหลังมาพร้อมกับระบบที่เกี่ยวข้อง: เลเยอร์แผนที่เมื่อรู้จักรัง ลำดับงานของทีมช่างเมื่องานค้างคิว ทองที่ค้างอยู่ แรงกดดันที่อาณาจักรนำมาสู่ตัวเอง วีรบุรุษที่กิลด์หายไป วีรบุรุษที่คิดจะจากไป
