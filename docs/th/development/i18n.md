## รูปแบบไฟล์ภาษา

ไฟล์ภาษาอยู่ในรูปแบบ JSON จัดเก็บในไดเรกทอรี `game/lang/`:

```json
{
  "window_title": "Wayward Crown",
  "log_defeated_enemy": "{adv} defeated {enemy} (Gold: {gold} XP: {xp})",
  "building_market": "Market",
  "class_warrior": "Warrior"
}
```

- รองรับการแทนที่แบบไดนามิกด้วย `{placeholder}`
- คีย์คำแปลที่ขาดหายจะถอยกลับไปใช้ภาษาอังกฤษโดยอัตโนมัติ
- การเปลี่ยนภาษามีผลทันทีโดยไม่ต้องรีสตาร์ท

---

## ลำดับการตรวจจับภาษา

1. อาร์กิวเมนต์ CLI `--lang` / `--language` (ลำดับความสำคัญสูงสุด ใช้เฉพาะเซสชันนี้และไม่ถูกบันทึก)
2. ภาษาที่ผู้ใช้เลือกด้วยตนเองในเมนูตั้งค่า (การเลือก "อัตโนมัติ (Steam)" ในเมนูนั้นจะล้างค่านี้)
3. ภาษาไคลเอนต์ Steam (ตรวจจับอัตโนมัติทุกครั้งที่เปิดเกมขณะที่ไม่มีการเลือกด้วยตนเอง)
4. ภาษาที่ใช้ครั้งล่าสุด
5. ภาษาอังกฤษ (ค่าเริ่มต้นสำรอง)

## การเพิ่มภาษา (ปลั๊กอิน)

การเพิ่มภาษาผ่านปลั๊กอินต้องการเพียงไฟล์คำแปลและ `plugin.json` ที่ระบุไฟล์นั้นไว้ใน `content.languages` (ไฟล์ที่ไม่ได้ระบุไว้จะไม่ถูกโหลด):

```
plugins/my_lang/
├── plugin.json
└── lang/
    └── xx.json    # Your language code
```

```json
{
  "id": "my_lang",
  "name": "My Language",
  "content": {"languages": ["lang/xx.json"]}
}
```

รหัสภาษาและชื่อที่แสดงในรายการภาษามาจากบล็อก `_meta` ของไฟล์ (`"_meta": {"language": "xx", "label": "My Language"}`) หากไม่มีบล็อกนี้จะใช้ชื่อไฟล์แทน รหัสสามารถเป็นสตริงใดก็ได้ (เช่น `ja`, `ko`, `my_custom`) และจะแสดงในรายการภาษาในเมนูตั้งค่าโดยอัตโนมัติ

---

## การรองรับหลายภาษาในแคมเปญ

ข้อความแคมเปญสามารถใช้คำนำหน้า `i18n:` เพื่ออ้างอิงคีย์คำแปล:

```json
{
  "title": "i18n:tut_level1_title",
  "intro": "i18n:tut_level1_intro"
}
```

เกมจะแปลงคีย์คำแปลโดยอัตโนมัติตามภาษาปัจจุบัน หากไม่พบคำแปลที่ตรงกัน จะแสดงชื่อคีย์ตามที่เป็น
