title: "บทเรียนสำหรับผู้สร้าง"
---

ทุกเทมเพลตเริ่มที่ **ผู้สร้างและเวิร์กชอปบน Steam** (เมนูหลัก ตัวจัดการแผนที่ หรือตัวจัดการปลั๊กอิน) และไปทางเดียวกันจาก **โครงการใหม่** จนเป็นรายการเวิร์กช็อปแบบส่วนตัว มีเพียงขั้นสุดท้ายที่ต้องใช้ Steam

## ขั้นตอนร่วม

1. **โครงการใหม่**: เลือกเทมเพลต ชื่อ และโฟลเดอร์ หน้าต่างจะแสดงว่าผลงานจะอยู่ที่ไหนก่อนเขียนอะไรลงไป
2. **แก้ไขโปรเจ็กต์**: ปลั๊กอินเปิดในตัวแก้ไขปลั๊กอิน แผนที่หรือแคมเปญเปิดด้วย **เปิดตัวแก้ไขภูมิประเทศ / แคมเปญ** ในกระบวนการแยกที่โหลดเฉพาะสิ่งที่ผลงานต้องใช้ บันทึกก่อนขั้นถัดไป เพราะการตรวจ การทดลองเล่น และการเผยแพร่ใช้ไฟล์ที่บันทึกแล้ว
3. **ตรวจสอบเนื้อหา**: ทุกปัญหาบอกตำแหน่ง ดับเบิลคลิกเพื่อเปิดตัวแก้ไขที่ตรงนั้น
4. **ทดสอบการเล่น**: เกมแยกที่มีเฉพาะผลงานนี้และสิ่งที่ต้องใช้ รายงานจะแสดงสิ่งที่โหลด และระหว่างทำงานจะแสดงเวลา tick หน่วยความจำ และแอตลาสสไปรต์ โดยจัดระดับตั้งแต่ปกติถึงหนักเกินไป
5. **ส่งออก…**: ZIP หรือโฟลเดอร์ที่ใช้ ID ผลงานเดิม เพื่อเก็บไว้หรือแชร์
6. **เผยแพร่ไปยังเวิร์กช็อป**: ขณะ Steam ทำงาน ให้เลือก **ส่วนตัว** สำหรับการทดสอบครั้งแรก แล้วกด **ตรวจสอบและทบทวน** และ **ส่งการเผยแพร่** การเผยแพร่ไม่ได้ทดสอบการโหลด ให้หารายการใน **เรียกดูเวิร์กช็อป** กด **สมัครสมาชิก** และดูใน **การสมัครสมาชิก** จนกว่าจะใช้งานได้

## แผนที่

เทมเพลตคือแผนที่ 32×32 ที่มีปราสาท หีบทอง 100 ห่างไปทางตะวันออกสองช่อง ทองเริ่มต้น 500 และชนะเมื่อเก็บหีบครบ

1. ระบายพื้นที่และวางสิ่งก่อสร้าง ป้อมปราการ และหีบในตัวแก้ไขพื้นที่ แล้วบันทึก
2. **ตรวจสอบเนื้อหา** เตือนเมื่อมีป้อมปราการ หีบ หรือบอสที่ฮีโร่เดินไปจากปราสาทไม่ถึง
3. เวอร์ชัน: เพิ่ม **เวอร์ชันโปรเจ็กต์** ทุกครั้งที่เผยแพร่การเปลี่ยนแปลง เซฟที่ทำด้วยเวอร์ชันเก่าจะเก็บสำเนาของเวอร์ชันนั้นไว้

## แคมเปญ

เทมเพลตมีสองด่าน แต่ละด่านมีแผนที่ของตัวเองที่มีปราสาทและหีบแบบเดียวกัน ไฟล์แคมเปญกำหนดลำดับและให้ชื่อ ข้อความเรื่องราว และทองเริ่มต้นแก่แต่ละด่าน

1. เปิดแผงแคมเปญในตัวแก้ไขพื้นที่เพื่อกำหนดลำดับด่าน เงื่อนไขชนะ ข้อความเรื่องราว สิ่งที่ส่งต่อ และทริกเกอร์
2. **ทดสอบการเล่น** เริ่มจากด่านใดก็ได้
3. การพึ่งพา: เมื่อด่านใช้ยูนิตของปลั๊กอิน ให้เพิ่มผลงานของปลั๊กอินนั้นใน **การพึ่งพา** พร้อมช่วงเวอร์ชัน เช่น `>=1.0.0, <2.0.0`

## ปลั๊กอิน

เทมเพลตมีคลาสฮีโร่ ศัตรู สิ่งก่อสร้างที่รับสมัครคลาสนั้น ป้อมปราการที่ส่งศัตรูนั้นออกมา สกิล งานวิจัย เหตุการณ์ บอสที่มีชื่อ รูปลักษณ์ช่องพื้น และไฟล์ภาษาอังกฤษ ทั้งหมดอยู่ใต้เนมสเปซของผลงานเอง

1. แก้ไขในแท็บ **ออบเจกต์** แถบด้านบนใช้เลือกชนิด คำจำกัดความแต่ละรายการแสดงด้วยชื่อและรูปที่เกมจะให้ และรายการที่เลือกจะมีตัวอย่าง (ยูนิตที่เดินได้จะเดิน) **สร้างใหม่…** เพิ่มรายการจากสิ่งที่อิงและชื่อ รูปและเสียงเลือกหรือนำเข้าได้ในแถวของมันเอง แบบฟอร์มคุณสมบัติแสดงค่าที่รับมาจากคำจำกัดความฐานเป็นสีเทา และทำเครื่องหมายค่าที่เกินขอบเขตของเกมทันที **ขั้นสูง** แสดงแถวเพิ่มด้วย ID และ JSON ของคำจำกัดความ ชื่อกำหนดได้ในแต่ละภาษาของปลั๊กอิน ในแถวด้านล่างชื่อ (**เพิ่มภาษา** เพิ่มภาษาให้ปลั๊กอิน) เส้นทางของปราสาทมีตารางสำหรับผลและความเชี่ยวชาญ และมีแถวสำหรับข้อความอื่น ๆ
2. ทรัพยากร: แท็บ **ทรัพยากร** รับไฟล์ภาพที่ลากมาวาง และเทียบแต่ละไฟล์กับขีดจำกัดขนาดและหน่วยความจำ รูปลักษณ์ช่องพื้นของเทมเพลตใช้ `preview.png` เป็นภาพตัวอย่าง เปลี่ยนได้ที่นั่น
3. การเขียนทับ: **คัดลอกของในเกม…** เพิ่มสำเนาเต็มของตัวละครในเกมด้วย ID ของคุณเอง ซึ่งจะแทนตัวเดิมในที่ที่ถูกใช้ นิยามที่ใช้ ID ในตัว (เช่น `SLIME` ที่มีฐานเป็น `SLIME`) จะเปลี่ยนสไลม์ของเกมเองขณะปลั๊กอินเปิดอยู่ ส่วน **โปรไฟล์เนื้อหา** แสดงว่าการเขียนทับของปลั๊กอินใดชนะ
4. เวอร์ชัน: **เวอร์ชันโปรเจ็กต์** คือเวอร์ชันของผลงานเอง **เวอร์ชันเกมที่รองรับ** คือช่วงเวอร์ชันเกมที่ยอมรับ (`*` หมายถึงทุกเวอร์ชัน บิลด์สำหรับพัฒนายอมรับเฉพาะ `*`)

## บทสอนบอส (ปลั๊กอิน + แคมเปญสองด่าน)

เทมเพลตคือโฟลเดอร์ที่มีปลั๊กอินและแคมเปญสองด่านที่ต้องใช้ปลั๊กอินนั้น ด่านที่สองชนะเมื่อปราบบอสที่มีชื่อของปลั๊กอิน

1. **การพึ่งพา** ของแคมเปญระบุผลงานและเวอร์ชันของปลั๊กอิน การทดลองเล่นจึงนำปลั๊กอินไปด้วย
2. เผยแพร่ปลั๊กอินก่อน แล้วจึงแคมเปญ หน้าต่างเผยแพร่จะแนะนำรายการเวิร์กช็อปของปลั๊กอินเป็นรายการที่จำเป็น
3. เพิ่ม **เวอร์ชันโปรเจ็กต์** ของปลั๊กอินทุกครั้งที่แก้ไข และตั้งช่วงของแคมเปญให้กว้างพอที่จะรับได้

## ภารกิจอาณาจักร (หนึ่งด่าน: สรุปภารกิจ ค่าหัว คลื่นศัตรู บอส)

เทมเพลตคือด่านอาณาจักรหนึ่งด่าน มีการบรีฟ เมือง รัง ธงสำรวจ สังหาร และป้องกันของราชสำนัก การบุกที่ประกาศล่วงหน้าสองระลอก บอสที่มีชื่อ และสิ่งที่ค้นพบแบบเลือกได้ แยกส่วนทีละด่านในแผงแคมเปญ แล้วทำตามขั้นตอนร่วม

## ตัวอย่าง Frostfang (ชุดเนื้อหาสำเร็จรูปและแผนที่ของมัน)

เทมเพลตนี้เป็นตัวอย่างสำเร็จรูปให้แกะดู: ชุดเนื้อหาที่มีอาชีพฮีโร่ (ผู้พิทักษ์น้ำแข็ง) มอนสเตอร์ (เยติน้ำค้างแข็ง) โถงที่รับสมัครอาชีพนั้น รังของมอนสเตอร์ สกิลสองอย่าง วิจัยหนึ่งอย่าง และบอสมีชื่อ แต่ละอย่างมีรูปและเสียงของตัวเอง กับแผนที่ที่ต้องใช้ชุดเนื้อหานี้และชนะได้ด้วยการปราบบอส หน้าต่างเดียวกันยังมีตัวอย่างที่ทำเสร็จแล้วสำหรับหมวดอื่นของ Workshop ด้วย แต่ละอันชื่อ **ตัวอย่าง: <หมวด>** (เช่น แผนที่ แคมเปญ เนื้อเรื่อง ชุดความท้าทาย และชุดเนื้อหาของงานวิจัย เหตุการณ์ และภาษา) มันจะถูกคัดลอกมาเป็นโปรเจกต์ของคุณเอง เพื่อเล่น แกะดู และแก้ไข

1. เปิดแผนที่ในตัวแก้ไขภูมิประเทศแล้วกด **ออบเจกต์…** เพื่อดูว่าคำจำกัดความแต่ละรายการอิงจากอะไรในเกม ลองเปลี่ยนตัวเลขหรือชื่อ บันทึก แล้ววางผลลัพธ์ลงบนแผนที่
2. กด **ทดลองเล่น** เพื่อเล่นแผนที่พร้อมชุดเนื้อหานี้ โดยไม่มีเนื้อหาอื่นของคุณ
3. เผยแพร่ชุดเนื้อหาก่อน แล้วจึงเผยแพร่แผนที่: หน้าต่างเผยแพร่จะแนะนำไอเท็ม Workshop ของชุดเนื้อหาเป็นไอเท็มที่จำเป็น

## สิ่งที่เทมเพลตไม่มีเลย

เทมเพลตไม่มี ID รายการเวิร์กช็อปจริง บัญชี Steam หรือพาธแบบสัมบูรณ์ ID ผลงานถูกสร้างใหม่บนคอมพิวเตอร์ของคุณ และทุกไฟล์ใช้ชื่อแบบสัมพัทธ์กับผลงาน
