Wayward Crown มีเครื่องมือแก้ไขแผนที่และแคมเปญในตัว ให้คุณสร้างด่านและสถานการณ์กำหนดเองได้

---

## เครื่องมือแก้ไขแผนที่

ปุ่ม **ตัวแก้ไขแผนที่** ในเมนูหลักจะเปิดเครื่องมือแก้ไขพร้อมแผนที่ใหม่ แผนที่ที่บันทึกไว้จะแสดงรายการ เล่น แก้ไข นำเข้า และส่งออกได้ในแท็บ **แผนที่** ของตัวจัดการแผนที่ ซึ่งเปิดได้จากปุ่ม **แคมเปญ** ในเมนูหลัก

### คุณสมบัติ

- **วาดภูมิประเทศ** — เลือกประเภทภูมิประเทศแล้ววาดลงบนแผนที่ด้วยแปรง (ขนาด 1 – 20) หรือเติมพื้นที่ทั้งบริเวณ
- **วางอาคาร** — วางอาคารของผู้เล่น ฐานที่มั่นศัตรู และหีบสมบัติ ย้ายปราสาท หรือลบ
- **สุ่ม** — สร้างแผนที่แบบสุ่มเพื่อใช้เป็นจุดเริ่มต้น
- **เลิกทำ / ทำซ้ำ** — ได้สูงสุด 30 ขั้น (Ctrl+Z / Ctrl+Y)
- **การตั้งค่าแผนที่** — ขนาด (100 – 1000 ช่องต่อด้าน) ชื่อ ผู้สร้าง และรายละเอียดอื่น ๆ ทองเริ่มต้น และเงื่อนไขชนะ
- **บันทึก/โหลด** — บันทึกแผนที่ลงในไดเรกทอรี `maps/` ปุ่มปิด Esc และสร้างใหม่จะถามก่อนทิ้งการเปลี่ยนแปลงที่ยังไม่บันทึก (บันทึก / ทิ้ง / ยกเลิก) และการทิ้งแคมเปญที่ไม่เคยบันทึกจะลบโฟลเดอร์ของมันด้วย
- **ออบเจกต์…** — แก้ไขอาชีพฮีโร่ มอนสเตอร์ อาคาร ฐานที่มั่น และบอสที่สร้างไว้สำหรับแผนที่ในตัวแก้ไขออบเจกต์ ครั้งแรกจะสร้างชุดเนื้อหาของแผนที่ (ปลั๊กอินของคุณเองที่แผนที่กำหนดให้ต้องมี) เมื่อบันทึกชุดเนื้อหา เนื้อหาจะถูกโหลดใหม่ สิ่งที่มันกำหนดจึงวางได้ทันที
- **ทดลองเล่น** — เริ่มแผนที่ที่บันทึกไว้ หรือแคมเปญในด่านที่กำลังแก้ไข ในเกมแยกต่างหาก พร้อมชุดเนื้อหาของมัน โดยไม่มีเนื้อหาอื่นของคุณ

แผนที่ไม่เก็บยูนิตใด ๆ: นักผจญภัยจะถูกรับสมัครและศัตรูจะเกิดเมื่อเกมเริ่มทำงาน

### ประเภทภูมิประเทศ

- ทุ่งหญ้า, ป่า, ภูเขา, น้ำ, ทะเลทราย, ถนน, โคลน, หนองบึง, หิมะ, เนินเขา, ดินแดนแห้งแล้ง, ทุ่งดอกไม้

### รูปแบบการบันทึก

แผนที่จัดเก็บในรูปแบบ JSON ในไดเรกทอรี `maps/` ประกอบด้วย:

- ข้อมูลภูมิประเทศ (อาร์เรย์ NumPy ที่บีบอัด)
- ข้อมูลความสูง
- อาคาร ฐานที่มั่นศัตรู และหีบสมบัติ
- ตำแหน่งปราสาท
- รายละเอียดแผนที่ ทองเริ่มต้น และเงื่อนไขชนะ

## เครื่องมือแก้ไขแคมเปญ

แคมเปญจะถูกสร้าง เปิด นำเข้า และส่งออกในแท็บ **แคมเปญ** ของตัวจัดการแผนที่ (ปุ่ม **แคมเปญ** ในเมนูหลัก) การเปิดแคมเปญจะเริ่มเครื่องมือแก้ไขแผนที่พร้อมแผงแคมเปญ คุณจึงแก้ไขแผนที่และการตั้งค่าของแต่ละด่านได้ในที่เดียว

### คุณสมบัติ

- **ลำดับด่าน** — เลื่อนด่านขึ้นและลงด้วยปุ่มลูกศร
- **เงื่อนไขชนะ** — ตั้งเงื่อนไขชนะสำหรับแต่ละด่าน รวมถึงประเภทฐานที่มั่นสำหรับ `destroy_building`
- **ข้อความเนื้อเรื่อง** — ตั้งข้อความเปิดและข้อความเมื่อผ่านด่าน
- **ทรัพยากรเริ่มต้น** — ตั้งทองเริ่มต้นสำหรับแต่ละด่าน
- **สืบทอดจากด่านก่อน** — เก็บทอง นักผจญภัย และงานวิจัยจากด่านก่อนหน้าไว้
- **ข้อจำกัดอาคาร** — จำกัดประเภทอาคารที่ผู้เล่นสามารถใช้ได้
- **ทริกเกอร์** — เขียนสคริปต์ข้อความและการปลดล็อกอาคารสำหรับด่าน (เฉพาะด่านแคมเปญ)
- **ช่องข้อมูลอาณาจักร** — ระดับปราสาทเริ่มต้นของด่าน จำกัดเวลา คำแนะนำในสรุปภารกิจ และเป้าหมายเสริมสูงสุดสองอย่าง
- **เป้าหมายเพิ่มเติมและเงื่อนไขแพ้** — เงื่อนไขชนะเพิ่มเติมแบบบังคับหรือเสริม และวิธีแพ้เพิ่มเติม (ฮีโร่ที่ล้ม อาคารหรือกองคาราวานที่เสียไป) ในสองตารางพร้อมปุ่มเพิ่มและลบ
- **ที่มาของเป้าหมาย** — ใต้เป้าหมายชัยชนะ จะบอกว่าบอสวางไว้บนแผนที่หรือทริกเกอร์เป็นผู้เริ่ม และประเภทป้อมปราการมาจากเกมหรือปลั๊กอิน มีอยู่บนแผนที่กี่แห่ง เป้าหมายของเป้าหมายเพิ่มเติมบอกสิ่งเดียวกันในคำแนะนำ

### ตัวเลือกเงื่อนไขชนะ

| ประเภท | คำอธิบาย |
|--------|----------|
| `free` | โหมดอิสระ ไม่มีเงื่อนไขชนะ |
| `destroy_enemy_buildings` | ทำลายฐานที่มั่นศัตรูทั้งหมด |
| `survive_ticks` | อยู่รอดตามระยะเวลาที่กำหนด |
| `reach_gold` | สะสมทองตามจำนวนที่กำหนด |
| `destroy_building` | ทำลายฐานที่มั่นประเภทที่กำหนด |
| `defend` | ป้องกันปราสาทตามระยะเวลาที่กำหนด |
| `collect_chests` | เก็บหีบสมบัติทั้งหมด |

### โครงสร้างการบันทึก

```
campaigns/my_campaign/
├── campaign.json         # Campaign metadata
├── level1.json           # Level 1 map
├── level2.json           # Level 2 map
└── level3.json           # Level 3 map
```

## การแชร์เนื้อหากำหนดเอง

- โฟลเดอร์แผนที่และแคมเปญสามารถแชร์ได้เพียงแค่คัดลอก หรือใช้การส่งออกและนำเข้าของตัวจัดการแผนที่
- วางแผนที่ที่ได้รับลงใน `maps/` เพื่อโหลดจากเมนูหลัก
- วางแคมเปญที่ได้รับลงใน `campaigns/` เพื่อให้แสดงในเมนูหลัก
- เมื่อเปิดเกมผ่าน Steam ปุ่ม **เผยแพร่ไปยังเวิร์กช็อป** ในตัวจัดการแผนที่จะนำแผนที่หรือแคมเปญของคุณขึ้น Steam Workshop และรายการที่คุณติดตามจะแสดงในรายการพร้อมเครื่องหมาย [เวิร์กช็อป] Steam จะอัปเดตให้เอง จึงแก้ไข เปลี่ยนชื่อ หรือลบไม่ได้ **ทำสำเนา** เพื่อให้ได้แผนที่ของคุณเอง
- แผนที่หรือแคมเปญที่มีชุดเนื้อหาต้องใช้ปลั๊กอินนั้น: แชร์ชุดเนื้อหาไปด้วยกัน และเผยแพร่ชุดเนื้อหาก่อน (หน้าต่างเผยแพร่จะแนะนำไอเท็ม Workshop ของชุดเนื้อหาเป็นไอเท็มที่จำเป็น)
