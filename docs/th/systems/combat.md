title: "ระบบการต่อสู้"
---

การต่อสู้เป็นแบบอัตโนมัติทั้งหมด นักผจญภัยและศัตรูเข้าสู้รบเมื่ออยู่ในระยะโจมตีของกันและกัน

---

## ขั้นตอนการต่อสู้

1. **ตรวจจับ** — นักผจญภัยพบศัตรูภายในระยะมองเห็น (ตรวจสอบทุก 2 tick)
2. **เข้าใกล้** — ถ้าศัตรูมองเห็นได้แต่อยู่นอกระยะโจมตี นักผจญภัยจะไล่ตาม
3. **โจมตี** — เมื่ออยู่ในระยะโจมตี ทั้งสองฝ่ายเริ่มสู้รบ
4. **ตัดสิน** — ความเสียหายถูกคำนวณทุก 5 tick

---

## การคำนวณความเสียหาย

### นักผจญภัยโจมตีศัตรู

| ประเภท | สูตรความเสียหาย |
|--------|----------------|
| ประชิด | `ATK × 2` (ตัวคูณความเสียหายทั่วไป) |
| ระยะไกล | `ATK` (ความเสียหายกระสุน ไม่ใช้ตัวคูณ) |

### ศัตรูโจมตีนักผจญภัย

```
ความเสียหาย = (ATK ศัตรู + random(0~2)) × 2
```

### การป้องกัน

```
ความเสียหายจริง = max(1, ความเสียหาย - DEF)
```

### การหลบหลีก

| แหล่ง | อัตราการหลบหลีก |
|-------|----------------|
| การหลบหลีกพื้นฐานของนักผจญภัย | 10% + 1% × AGI (≤ 70%) |
| การหลบหลีกพื้นฐานศัตรู | 5% |
| ทักษะ "หลบหลีก" ของพราน | +15% |
| โจร: หลบหลีก | +10% |
| โจร: ระบำเงา | +18% |
| พราน: ตัดสายลม | +25% |

## ระบบกระสุน

ยูนิตที่สู้จากระยะไกลแต่ละตัวยิงกระสุนของตัวเอง จึงดูออกว่าใครยิงจากสิ่งที่พุ่งไป คลาสอื่นสู้ระยะประชิดแม้จะเอื้อมถึง 3 ช่อง:

| คลาส | ประเภทกระสุน |
|-------|-------------|
| พราน | ลูกธนู (arrow) |
| ผู้นำทาง | หอกซัด (javelin) |
| ผู้พิทักษ์เส้นทาง | ลูกดอกหน้าไม้ (bolt) |
| นักเวทย์ | ลูกไฟ (fireball) |
| ผู้ฝึกเวทกังวาน | เศษแสง (light_shard) |
| นักธนูก็อบลิน (ศัตรู) | ลูกธนูหยาบ (goblin_arrow) |
| สาวกแห่งความมืด (ศัตรู) | ลูกแก้วมืด (dark_orb) |
| มังกร (ศัตรู) | เปลวไฟพ่น (dragon_flame) |

กระสุนเดินทางไปยังเป้าหมายแต่ละ tick หลังยิงออกไปและสร้างความเสียหายเมื่อโดน กระสุนแต่ละชนิดถูกวาดตามทิศที่มันพุ่งไป ลูกที่พุ่งขึ้นไปบนแผนที่จะเห็นจากด้านหลัง ส่วนลูกที่พุ่งขวางจะเห็นจากด้านข้าง

## หอคอยธนู

หอคอยธนูเป็นอาคารป้องกันอัตโนมัติ:

| คุณสมบัติ | ค่า |
|-----------|------|
| ระยะโจมตี | 20 ช่อง |
| ความเสียหายพื้นฐาน | 16 + 8 × (Lv − 1) |
| การปรับขนาดจากอัปเกรด | เพิ่มขึ้นตามระดับ |

หอคอยธนูโจมตีศัตรูที่ใกล้ที่สุดภายในระยะโดยอัตโนมัติ

## รางวัลค่าประสบการณ์

| แหล่ง | XP |
|-------|-----|
| ต่อการโจมตี (Drip) | 1/5 ของ XP สังหาร |
| สังหารสไลม์ | 10 XP |
| สังหารก็อบลิน | 25 XP |
| สังหารโครงกระดูก | 40 XP |
| สังหารซอมบี้ | 60 XP |
| สังหารมังกร | 150 XP |

:::note[XP หยด]
ทุกครั้งที่นักผจญภัยโจมตีศัตรู — ไม่ว่าจะเป็นประชิดหรือกระสุน — จะได้รับ 1/5 ของ XP สังหารของศัตรูนั้น สิ่งนี้ทำให้นักผจญภัยได้รับประสบการณ์แม้ไม่ได้ลงมือสังหารเอง
:::

## AI การต่อสู้

### เงื่อนไขการหนีของนักผจญภัย

- HP < 30% (HP_CRITICAL)
- ความน่าจะเป็นในการหนีได้รับอิทธิพลจากลักษณะนิสัยความปลอดภัย

### การใช้ยา

| เงื่อนไข | พฤติกรรม |
|----------|----------|
| HP < 30% | ใช้ยาอย่างเร่งด่วน |
| HP < 50% | ใช้ยา |

### ลำดับความสำคัญเป้าหมายของศัตรู

1. นักผจญภัยที่พร้อมรบ (ไม่ใช่สันตินิยม)
2. ช่างก่อสร้าง (สันตินิยม)
3. อาคารที่เป็นภัยคุกคาม เช่น หอคอยธนู
4. ปราสาท
5. อาคารอื่น ๆ
