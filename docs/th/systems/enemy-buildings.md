## มอนสเตอร์กลับมา

เมื่อไม่เหลือฐานที่มั่นใดตั้งอยู่บนแผนที่ มอนสเตอร์จะกลับมาสร้างขึ้นใหม่หนึ่งแห่ง:

| ขั้น | สิ่งที่เกิดขึ้น |
|------|-------------|
| ระยะรอ | ประมาณ 3 นาทีหลังฐานที่มั่นแห่งสุดท้ายล่มสลาย |
| กลุ่ม | มอนสเตอร์ห้าตัวจากฐานที่มั่นชนิดหนึ่งของแผนที่ เดินเข้ามาจากขอบแผนที่ที่ใกล้ที่สุด |
| ที่ตั้ง | หนึ่งในที่ตั้งเดิมของฐานที่มั่น ห่างไกลจากปราสาทและอาคารของคุณ |
| ไซต์ก่อสร้าง | เมื่อมาถึงสามตัว: ฐานที่มั่นที่มีกำแพงราวหนึ่งในสาม ไม่ปล่อยมอนสเตอร์และไม่ส่งกองปล้น |
| สร้างเสร็จ | หลัง 2 นาทีจะตั้งขึ้นสมบูรณ์เป็นฐานที่มั่นธรรมดา |
| ถูกหยุด | ฆ่ากลุ่มนั้นระหว่างทางหรือทำลายไซต์ก่อสร้าง ความพยายามครั้งต่อไปจะมาอีก 5 นาทีต่อมา |

แผนที่จะไม่มีวันได้ฐานที่มั่นคืนมามากกว่าที่มีตอนเริ่ม และแผนที่ที่เริ่มโดยไม่มีฐานที่มั่นเลยจะไม่มีวันได้สักแห่ง

## การโจมตีฐานที่มั่น

### ลำดับการโจมตี

1. นักผจญภัยเดินทางมาถึงบริเวณใกล้ฐานที่มั่น
2. พวกเขาสู้กับ **ศัตรูรักษาการณ์** ก่อน (สูงสุด 3 ตัว)
3. ขณะอยู่ใกล้ฐานที่มั่น สามารถ **ขโมยทอง** ได้
4. เมื่อทองหมด สามารถ **โจมตีกำแพง** ได้
5. เมื่อ HP กำแพงถึงศูนย์ ฐานที่มั่นจะถูกทำลาย

### เคล็ดลับกลยุทธ์

:::tip[วิธีทำลายฐานที่มั่นอย่างมีประสิทธิภาพ]
1. วาง **ค่าหัว** (รางวัลสูง) ใกล้ฐานที่มั่น
2. ตรวจสอบว่ามีนักผจญภัยระยะไกลเพียงพอ (นักเวทย์ / พราน)
3. นักเวทย์ (ระยะโจมตี 12) และพราน (ระยะโจมตี 11) สามารถยิงจากระยะปลอดภัย
4. นำองครักษ์ไปด้วยเพื่อปกป้องหน่วยระยะไกล
5. เตรียมช่างก่อสร้างไว้ซ่อมแซมอาคารที่เสียหาย
:::

:::caution[หมายเหตุ]
การโจมตีกำแพงฐานที่มั่น **ไม่ให้ค่าประสบการณ์** มีเพียงการสังหารศัตรูรักษาการณ์เท่านั้นที่ให้ค่าประสบการณ์ การทำลายฐานที่มั่นให้ชื่อเสียง +25 และจ่ายค่าหัวที่ตั้งไว้ ไม่มีของตก
:::
