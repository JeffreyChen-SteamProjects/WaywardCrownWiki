## การโจมตีฐานที่มั่น

### ลำดับการโจมตี

1. นักผจญภัยเดินทางมาถึงบริเวณใกล้ฐานที่มั่น
2. พวกเขาสู้กับ **ศัตรูรักษาการณ์** ก่อน (สูงสุด 3 ตัว)
3. ขณะอยู่ใกล้ฐานที่มั่น สามารถ **ขโมยทอง** ได้
4. เมื่อทองหมด สามารถ **โจมตีกำแพง** ได้
5. เมื่อ HP กำแพงถึงศูนย์ ฐานที่มั่นจะถูกทำลาย

### เคล็ดลับกลยุทธ์

:::tip[วิธีทำลายฐานที่มั่นอย่างมีประสิทธิภาพ]
1. วาง **ค่าหัว** (รางวัลสูง) ใกล้ฐานที่มั่น
2. ตรวจสอบว่ามีนักผจญภัยระยะไกลเพียงพอ (นักเวทย์ / พราน)
3. นักเวทย์ (ระยะโจมตี 12) และพราน (ระยะโจมตี 11) สามารถยิงจากระยะปลอดภัย
4. นำองครักษ์ไปด้วยเพื่อปกป้องหน่วยระยะไกล
5. เตรียมช่างก่อสร้างไว้ซ่อมแซมอาคารที่เสียหาย
:::

:::caution[หมายเหตุ]
การโจมตีกำแพงฐานที่มั่น **ไม่ให้ค่าประสบการณ์** มีเพียงการสังหารศัตรูรักษาการณ์เท่านั้นที่ให้ค่าประสบการณ์ การทำลายฐานที่มั่นให้ชื่อเสียง +25 และจ่ายค่าหัวที่ตั้งไว้ ไม่มีของตก
:::

- การปล้นทุกครั้งจะแจ้งล่วงหน้า 30 วินาทีในบันทึกเหตุการณ์ พร้อมตำแหน่งของรังหากวีรบุรุษเคยเห็นแล้ว รังที่ยังไม่เคยเห็นจะแจ้งโดยไม่มีตำแหน่ง การสอดแนมจึงคุ้มค่า
- กองปล้นออกเดินทางเป็นหมู่เดียวจากข้างรัง ระดับง่ายน้อยลงหนึ่งตัว ระดับยากเพิ่มสองตัว
- แต่ละรังมีทหารยามชนิดเดียวกันได้สูงสุด 3 ตัว เพิ่มใหม่ทุก 30 วินาที
- การทำลายรังจะยุติการปล้นและให้ราชสำนักได้ครึ่งหนึ่งของทองที่เหลือ สิ่งที่วีรบุรุษปล้นไปก่อนหน้านั้นเป็นของพวกเขา
- การเลือกรังจะแสดงว่าใครอยู่ที่นั่นและอะไรรับมือได้ การปล้นครั้งถัดไปออกเดินทางเมื่อใด และการทำลายจะได้คืนเท่าใด
- รังอื่น ๆ ปล้นเมืองตามค่าเริ่มต้น (ครั้งแรกหลัง 10:00 จากนั้นทุก 6:40 จำนวน 3 ถึง 6 ตัว) รังแมงมุม รังหมาป่ายักษ์ และรังหนูยักษ์ไม่ส่งกองปล้น
