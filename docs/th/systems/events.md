เกมจะเรียกเหตุการณ์สุ่มในช่วงเวลาที่กำหนด เพิ่มความไม่แน่นอนให้การเล่น ความรุนแรงของเหตุการณ์จะปรับขนาดตามจำนวนนักผจญภัยของคุณโดยอัตโนมัติ บทสอนในตัวเกมจะไม่สุ่มแผ่นดินไหว และไม่สุ่มเหตุการณ์ที่สร้างสิ่งก่อสร้างใหม่บนแผนที่

---

## กฎการเรียกเหตุการณ์

| การตั้งค่า | ค่า |
|------------|------|
| ช่วงผ่อนผันเปิดเกม | 1500 tick (~5 นาที) |
| ช่วงเวลาตรวจสอบ | ทุก 300 tick |
| โอกาสเกิดเหตุการณ์ | 60% |
| คูลดาวน์เหตุการณ์ | 600 tick (~2 นาที) |

## กลยุทธ์การรับมือ

:::tip[เหตุการณ์ภัยคุกคาม]
- รักษาแนวป้องกันถาวรด้วยองครักษ์และหอคอยธนูตลอดเวลา
- ระหว่างเหตุการณ์บุกรุก ตรวจสอบให้แน่ใจว่ามีกำลังรบเพียงพอรอบปราสาท
- ส่งค่าหัวเพื่อทำลายรังมังกรและกิลด์กบฏโดยเร็วที่สุด
- ทั้งสองจะถูกทำเครื่องหมายบนแผนที่ทันทีที่ปรากฏ: คลิกเพื่อดูพลังชีวิต และตั้งค่าหัว «สังหาร» เพื่อส่งฮีโร่ไปทำลาย
:::

:::tip[การใช้ประโยชน์จากเหตุการณ์เสริมพลัง]
- ระหว่าง XP สองเท่า ให้นักผจญภัยสู้รบให้มากที่สุดเพื่อเพิ่มระดับ
- ระหว่างคลั่งก่อสร้าง ถือโอกาสขยายฐาน
- ระหว่างคลื่นเกณฑ์ ตรวจสอบว่ามีอาคารรับสมัครเพียงพอ
:::
