---
title: "โหมดแคมเปญ"
---

โหมดแคมเปญนำเสนอสถานการณ์หลายด่าน แต่ละด่านมีเงื่อนไขชนะเฉพาะและฉากหลังเนื้อเรื่อง

---

## แคมเปญในตัว

เกมมี **แคมเปญบทเรียน** ในตัว (5 ด่าน) ที่นำผู้เล่นใหม่ผ่านกลไกเกมต่าง ๆมีปุ่มของตัวเอง เป็นปุ่มแรกของเมนูหลัก

---

## เงื่อนไขชนะ

แต่ละด่านของแคมเปญสามารถมีเงื่อนไขชนะอย่างใดอย่างหนึ่งต่อไปนี้:

| `victory` | เงื่อนไข | คำอธิบาย |
|---|----------|----------|
| `free` | **เล่นอิสระ** | ไม่มีเงื่อนไขชนะเฉพาะ เล่นได้อย่างอิสระ |
| `destroy_enemy_buildings` | **ทำลายฐานที่มั่นทั้งหมด** | กำจัดฐานที่มั่นศัตรูทั้งหมดบนแผนที่ |
| `survive_ticks` | **อยู่รอดตามเวลาที่กำหนด** | รักษาปราสาทให้อยู่รอดเกินจำนวน tick ที่กำหนด |
| `reach_gold` | **สะสมทอง** | ไปถึงจำนวนทองเป้าหมายในคลัง |
| `destroy_building` | **ทำลายฐานที่มั่นเฉพาะ** | ทำลายฐานที่มั่นศัตรูประเภทที่กำหนด |
| `defend` | **ป้องกันปราสาท** | ป้องกันไม่ให้ปราสาทถูกทำลายภายในเวลาที่กำหนด |
| `collect_chests` | **เก็บหีบสมบัติทั้งหมด** | เปิดหีบสมบัติทุกใบบนแผนที่ |
| `secure_trade` | **รักษาเส้นทางการค้า** | กองคาราวานไปกลับได้รับเงินครบ `victory_value` รอบ และฐานศัตรูทั้งหมดบนแผนที่ถูกทำลาย |

---

## โครงสร้างแคมเปญ

แคมเปญจัดเก็บเป็นโฟลเดอร์ในไดเรกทอรี `campaigns/`:

```
campaigns/
└── tutorial/
    ├── campaign.json     # เมตาดาต้าแคมเปญและรายการด่าน
    ├── level1.json       # แผนที่ด่านที่ 1
    ├── level2.json       # แผนที่ด่านที่ 2
    └── ...
```

### รูปแบบ campaign.json

```json
{
  "name": "Tutorial Campaign",
  "description": "Learn the basic game mechanics",
  "levels": [
    {
      "map": "level1.json",
      "title": "A New Beginning",
      "intro": "Welcome to Wayward Crown...",
      "outro": "Congratulations on clearing this level!",
      "starting_gold": 500,
      "victory": "destroy_enemy_buildings",
      "victory_value": 0,
      "victory_target": "",
      "unlocked_buildings": [],
      "carry_over": {"gold": true, "adventurers": true},
      "triggers": [
        {"id": "welcome", "condition": "tick_reached", "params": {"value": 2},
         "action": "show_message", "action_params": {"text_key": "tut_welcome"}}
      ]
    }
  ]
}
```

### การตั้งค่าด่าน

| ฟิลด์ | คำอธิบาย |
|-------|----------|
| `map` | เส้นทางไฟล์แผนที่ (สัมพันธ์กับโฟลเดอร์แคมเปญ) |
| `title` | ชื่อด่าน |
| `intro` | ข้อความเปิด |
| `outro` | ข้อความเมื่อผ่านด่าน |
| `starting_gold` | ทองเริ่มต้น (0 – 10⁷) |
| `victory` | ประเภทเงื่อนไขชนะ |
| `victory_value` | ค่าเงื่อนไขชนะ (เช่น จำนวน tick ที่ต้องอยู่รอด จำนวนทองเป้าหมาย ฯลฯ) (0 – 10⁹) |
| `unlocked_buildings` | รายการอาคารที่อนุญาต (จำกัดตัวเลือกอาคารของผู้เล่น) รายการว่างหมายถึงอนุญาตทุกอาคาร ส่วน `unlock_building` จะเพิ่มลงในรายการที่ไม่ว่าง |
| `victory_target` | ประเภทฐานที่มั่นสำหรับ `destroy_building` (เช่น `DRAGON_NEST`) เงื่อนไขอื่นจะไม่ใช้ค่านี้ |
| `carry_over` | สิ่งที่ยกมาจากด่านก่อนหน้า: `gold`, `adventurers`, `research`, `path` (เส้นทางปราสาทและความเชี่ยวชาญ) (แต่ละค่าเป็น true/false) สิ่งที่ด่านระบุไว้ใน `carry_over` จะถูกนำมาจากอีกด่านหนึ่งของแคมเปญเดียวกันเมื่อผู้เล่นเล่นต่อโดยตรง และถูกบันทึกไว้ ณ ตอนนั้น การลองด่านใหม่ทุกครั้งจะเริ่มจากบันทึกนี้ ด่านที่เริ่มจากรายการภารกิจจะไม่นำอะไรมาด้วย และสิ่งที่ด่านไม่ได้ระบุ (รวมถึงงานวิจัยและเส้นทางของปราสาท) จะไม่คงอยู่ข้ามแผนที่ |
| `triggers` | เหตุการณ์ตามสคริปต์: `condition` + `params`, `action` + `action_params` และเลือกใส่ `id`, `after` (รอให้ทริกเกอร์นั้นทำงานก่อน), `once` ได้ เงื่อนไข: `always`, `tick_reached`, `tick_after_fire`, `gold_at_least`, `adventurer_count_at_least`, `building_built`, `building_count_at_least`, `any_building_damaged`, `enemy_buildings_destroyed`, `enemy_building_seen`, `chests_opened`, `enemy_killed_count`, `bounties_completed`, `buildings_lost`, `caravan_rounds`, `caravans_lost`, `ticks_after_step`, `site_count_at_least`, `bounty_posted`, `taxes_collected`, `branch_chosen`, `spell_cast`, `hero_geared` การกระทำ: `show_message`, `unlock_building`, `spawn_boss`, `start_event`, `spawn_enemies`, `post_bounty`, `grant_gold`, `reveal` ทริกเกอร์ที่ไม่ใช่อ็อบเจกต์ หรือมีฟิลด์ที่ชนิดค่าไม่ถูกต้อง จะถูกตัดออกและแจ้งในคอนโซล `chests_opened`, `enemy_killed_count` และ `bounties_completed` นับตั้งแต่เริ่มด่าน ทริกเกอร์ที่ทำซ้ำ (`once: false`) จะทำงานทุก tick ที่เงื่อนไขเป็นจริง การตรวจจึงปฏิเสธทริกเกอร์ที่เสกศัตรู ให้เงิน ปักค่าหัว หรือเริ่มเหตุการณ์ การเผชิญหน้าบอสเริ่มได้ครั้งเดียว และจะเริ่มหลังจากตัวเองพ่ายแพ้ไม่ได้คลื่น `spawn_enemies` ใส่ `march` (`castle` หรือ `road`) ได้ คลื่นนั้นจะเดินทัพไปยังปราสาทหรือสถานีการค้าที่ใกล้ที่สุด แทนที่จะเดินเตร่อยู่ตรงจุดที่ปรากฏ `reveal` (`x`, `y`, `radius` ตั้งแต่ 1 ถึง 40) แสดงสถานที่ให้ผู้เล่นเห็น พื้นที่ในรัศมีนั้นจะถูกสำรวจแล้ว `ticks_after_step` นับ `value` จาก tick ที่ทริกเกอร์ซึ่งระบุใน `after` ทำงาน พารามิเตอร์ของ `show_message` ที่เขียนเป็น `i18n:<key>` จะถูกแปลก่อนใส่ลงในข้อความ ข้อความจึงเรียกแผงหรือสิ่งก่อสร้างด้วยคำของเกมเองได้ |
| `id` | ชื่อคงที่ของด่านสำหรับความคืบหน้าและ `requires` (ตัวอักษร ตัวเลข `.` `-` `_`) หากไม่ระบุจะเป็น `level<n>` ตามลำดับ |
| `requires` | ด่านที่ต้องผ่านก่อน: `id` ของด่านในแคมเปญนี้ หรือ `<id แคมเปญ>/<id ด่าน>` |
| `ruleset` | เป็นได้เฉพาะ `kingdom` และไม่ระบุก็ได้: ทุกด่านเล่นด้วยกฎอาณาจักร ด่านหรือแผนที่ที่ระบุ `classic` หรือไม่ระบุเลย จะเล่นเป็นอาณาจักร ส่วนชื่อที่ไม่รู้จักจะถูกปฏิเสธ |
| `castle_level` | เลเวลปราสาทตอนเริ่มด่าน (1–3) หากไม่ระบุจะเป็นป้อมปราการ |
| `time_limit` | จำนวน tick ที่ด่านใช้ได้ เมื่อหมดแล้วยังไม่ชนะถือว่าแพ้ 0 หรือไม่ระบุคือไม่จำกัด |
| `advice` | คำแนะนำในสรุปภารกิจ เป็นคีย์ `i18n:` ได้เหมือนข้อความอื่น |
| `side_quests` | สิ่งที่ค้นพบเสริมบนด่าน สูงสุดสองอย่าง แต่ละอย่างเป็น `{"kind", "x", "y"}` โดย kind เป็น `supply_party`, `guarded_cache`, `lair_treasure` ใช้ `enemy` หรือ `lair` ระบุได้ว่าใครอยู่ที่นั่น |
| `objectives` | เงื่อนไขชนะเพิ่มเติมสูงสุด 8 ข้อ แต่ละข้อเป็น `{"victory", "value", "target", "required"}` ใช้เงื่อนไขใดก็ได้ยกเว้น `free` ด่านจะผ่านเมื่อเงื่อนไขหลัก (ถ้าไม่ใช่ `free`) และเงื่อนไขบังคับทั้งหมดสำเร็จ เงื่อนไขเสริมจะนับในบรรทัดเป้าหมายและแสดงในผลลัพธ์ |
| `defeats` | วิธีแพ้เพิ่มเติมสูงสุด 4 แบบ แต่ละแบบเป็น `{"kind", "value"}`: แพ้เมื่อ `heroes_lost`, `buildings_lost` หรือ `caravans_lost` ถึงค่านั้นนับตั้งแต่เริ่มด่าน |

ตัวแคมเปญเองระบุ `id` (ชื่อที่ใช้บันทึกความคืบหน้า) และ `"linear": false` (ชุดความท้าทายที่แยกจากกัน ชนะด่านหนึ่งแล้วจะไม่ต่อไปด่านถัดไป) ได้ และยังระบุ `blocked_events` ได้: ชื่อเหตุการณ์สุ่มที่ด่านของแคมเปญนั้นจะไม่สุ่มออกมา (เช่น `DRAGON_NEST`) และ `roster`: ชนิดศัตรู (ชื่อเช่น `GOBLIN`) ที่เร่ร่อนและบุกในด่านของแคมเปญ หากไม่ระบุคือทุกชนิด

:::tip[การรองรับการแปลภาษา]
ข้อความแคมเปญสามารถใช้แท็ก `i18n:KEY` ซึ่งจะแสดงคำแปลที่ตรงกันโดยอัตโนมัติตามภาษาของผู้เล่น
:::

## แคมเปญเดโม

แคมเปญเนื้อเรื่องของเดโม (`campaigns/demo_kingdom/`) เปิดได้จากเมนูหลัก เช่นเดียวกับบทสอน แคมเปญนี้เขียนโดย `game/systems/demo_campaign.py`

| ภารกิจ | เป้าหมาย | แพ้เมื่อ | เริ่มต้น |
|---|---|---|---|
| 1. มงกุฎใบแรก | หาค่ายก็อบลินทางตะวันออกของป้อมและทำให้มันถูกทำลาย | ป้อมแตก | 1600 ทองและรายการสิ่งก่อสร้างสั้น ๆ พร้อมซากร้านช่างตีเหล็กและซากตลาด |
| 2. เงาบนเส้นทางการค้า | ให้กองคาราวานไปกลับสำเร็จสามรอบและทำลายค่ายโจร | ปราสาทแตก | 2400 ทอง ปราสาทเลเวล 2 เมืองเล็ก ๆ และถนนปูสองสาย |
| 3. ราตรีของเขี้ยวขบ | ปราบหัวหน้าเผ่าเขี้ยวขบ | ปราสาทแตก | 3000 ทอง ปราสาทเลเวล 2 และเมืองที่มีสิ่งก่อสร้างหกหลัง |

ภารกิจ 1 เริ่มข้างซากร้านช่างตีเหล็กและซากตลาด: ทีมช่างของราชสำนักสร้างขึ้นใหม่โดยไม่มีค่าใช้จ่าย เริ่มจากร้านช่างตีเหล็กก่อน และสิ่งที่คุณวาง รวมถึงกิลด์แรกของคุณ จะรอคิวต่อจากนั้น เว้นแต่คุณจะทำเครื่องหมายให้สร้างก่อน ในภารกิจ 1 ข้อความจะพาจากกิลด์แรกไปสู่วีรบุรุษคนแรก ตลาด และคนเก็บภาษี ผ่านไปราว 48 วินาที ราชสำนักจะออกเงินเองปักค่าหัว «สำรวจ» ใกล้ค่าย เมื่อวีรบุรุษทำสำเร็จ คุณจะถูกขอให้ปักค่าหัว «สังหาร» ที่ค่าย ในภารกิจ 2 ราชสำนักให้สำรวจจุดตั้งสถานีการค้าทั้งสองแห่ง โจรซุ่มโจมตีถนนใต้หนึ่งครั้ง (แจ้งล่วงหน้า 20 วินาที) และการเสียสิ่งก่อสร้างครั้งแรกจะได้ทองช่วยเหลือ 400 ในภารกิจ 3 การปล้นระลอกแรกมาทางถนนตะวันออกที่ tick 1000 และระลอกที่สองมาทางถนนทางเหนือที่ tick 2500 และหัวหน้าเผ่าเขี้ยวขบมาที่ tick 4300 โดยแจ้งล่วงหน้า 100 tick ทุกครั้ง การทำลายป้อมของเขาเป็นการเดินทัพที่คุ้มค่าของที่ปล้นได้ แต่ต้องปราบตัวเขาเท่านั้นจึงจะชนะ ภารกิจ 1 และ 2 สร้างกิลด์ช่างก่อสร้างเพื่อซ่อมแซมได้ ในภารกิจ 3 ปราสาทเลเวล 2 อยู่แล้วจึงเลือกเส้นทางได้ทันที และป้อมที่ถูกทำลายจะไม่ส่งการปล้นของตัวเองอีก ภารกิจ 2 และ 3 เก็บงานวิจัยของภารกิจก่อนหน้าไว้เมื่อคุณเล่นต่อโดยตรง การลองใหม่ทุกครั้งเริ่มเหมือนครั้งแรก และภารกิจที่เลือกจากรายการจะเริ่มโดยไม่มีงานวิจัยนั้น

ด่านท้าทาย (`campaigns/demo_challenges/`, `"linear": false`) เขียนด้วยวิธีเดียวกัน “ทองร่อยหรอ” เปิดหลังภารกิจ 2: ทอง 600 ปราสาทระดับ 2 เมืองเล็ก ๆ ที่มีสถานีการค้าบนถนนใต้ และเวลา 15 นาที (`time_limit`) เพื่อทำลายค่ายก็อบลินและค่ายโจรที่ปล้นถนน โจรจะลองบุกถนนสองครั้งก่อนที่ค่ายจะเริ่มบุกเอง “รักษาถนน” เปิดหลังภารกิจ 3: สถานีการค้าเปิดอยู่แล้ว โจรมาทางถนนใต้ทุก 500 tick แข็งแกร่งขึ้นทีละน้อย และต้องให้กองคาราวานไปกลับสำเร็จ 10 รอบภายใน 14 นาที 20 วินาที อาณาจักรเสรี (อาณาจักรอิสระของเดโม หรือแซนด์บ็อกซ์ของเกมฉบับเต็ม) ไม่มีเป้าหมาย หน้าต่างเริ่มเกมให้เลือกได้ว่าจะให้หัวหน้าเผ่าเขี้ยวขบมาหนึ่งครั้งหลังเริ่ม 20 นาที (`game/systems/free_kingdom.py`)ใน *รักษาถนน* การปล้นทุกระลอกเดินทัพสู่สถานีการค้า สถานีที่ไม่มีใครป้องกันจะถูกทำลายและกองคาราวานก็หายไปด้วย การไม่ทำอะไรเลยจึงแพ้ด่านท้าทายนี้

## ทำภารกิจอาณาจักรทีละขั้น

1. ใน Creator / Workshop เลือก **โครงการใหม่** แล้วเลือก **ภารกิจอาณาจักร** และโฟลเดอร์ใหม่ คุณจะได้ด่านที่เล่นได้ทันที: เมือง ค่ายก็อบลินทางตะวันออก ค่าหัว «สำรวจ» «สังหาร» และ «ป้องกัน» ของราชสำนัก คลื่นศัตรูที่แจ้งล่วงหน้าสองระลอก และหัวหน้าเผ่าในฐานะบอสที่มีชื่อ
2. เปิดด้วยตัวแก้ไขแคมเปญ แบบฟอร์มของด่านมีเรื่องราว (บทนำ) คำแนะนำที่สรุปภารกิจแสดง ทองเริ่มต้น และเงื่อนไขชนะ ถัดลงไปคือระดับปราสาทเริ่มต้น จำกัดเวลา และเป้าหมายเสริมสูงสุดสองอย่างพร้อมตำแหน่ง
3. วาดแผนที่: ย้ายเมือง รัง และถนน สถานที่ต้องเดินถึงได้จากปราสาท มิฉะนั้นสิ่งที่อยู่ตรงนั้นจะถูกข้ามเมื่อด่านเริ่ม อาคารในไฟล์แผนที่ใส่ `"ruin"` (1 ถึง 99) ได้: อาคารจะเริ่มเป็นไซต์ก่อสร้างที่ทำงานเสร็จแล้วตามเปอร์เซ็นต์นั้น และทีมช่างของราชสำนักจะสร้างให้เสร็จโดยไม่มีค่าใช้จ่าย
4. เปิดทริกเกอร์เพื่อเปลี่ยนข้อความ ค่าหัวที่ราชสำนักมอบ (`post_bounty`) คลื่นศัตรู (`spawn_enemies`) และเวลาที่บอสมา (`spawn_boss`) เงื่อนไข `enemy_building_seen` จะรอจนกว่ารังจะเข้ามาในสายตา
5. ใน `campaign.json` ค่า `roster` ระบุมอนสเตอร์ที่เร่ร่อนบนแผนที่ และ `blocked_events` ระบุเหตุการณ์สุ่มที่ไม่ถูกสุ่ม
6. ตรวจสอบ: การตรวจจะชี้ระดับปราสาท จำกัดเวลา เป้าหมายเสริม รายชื่อ หรือเหตุการณ์ที่ผิดตามช่องของมัน จากนั้นเล่นด่านจากพื้นที่ทำงาน ความยากที่เลือกที่นั่นกำหนดขนาดการปล้น คลื่นศัตรู และทองเริ่มต้น
7. เผยแพร่แบบส่วนตัวก่อน แล้วค่อยเปิดสาธารณะเมื่อเล่นได้อย่างที่ตั้งใจ
