---
title: "웨이워드 크라운"
---

**웨이워드 크라운**은 경영 시뮬레이션 게임입니다. 웨이워드 크라운의 수장으로서 자유의지를 가진 모험가들을 현상금, 건물, 경제적 인센티브를 통해 **간접적으로** 이끕니다. 캐릭터를 직접 조종할 수 없으며 — 모험가 생태계 전체를 관찰하고 조작하는 것만 가능합니다.

---

## 주요 특징

- **간접 조종** — 모험가는 성격과 필요에 따라 자율적으로 행동합니다. 현상금, 건물, 연구를 통해서만 영향을 줄 수 있습니다
- **풍부한 랜덤 이벤트** — 붉은 달부터 보물의 비까지 50가지 이상의 이벤트 유형으로 매번 다른 플레이 경험을 제공합니다
- **깊이 있는 경제** — 현상금 보상, 건물 투자, 시장 세금, 모험가 소비의 균형을 맞추세요
- **대규모 전투** — 수천 명의 모험가와 수만 마리의 적을 동시에 필드에 표시 가능
- **커스텀 레벨** — 내장 맵 에디터와 캠페인 에디터로 나만의 시나리오를 제작하고 공유 가능
- **플러그인 시스템** — 소스 코드 수정 없이 기본 클래스, 적, 건물을 변경하고 언어 팩을 추가 가능
- **15개 언어 지원** — 영어, 번체 중국어, 간체 중국어, 일본어, 한국어, 러시아어, 독일어, 프랑스어 등

---

## 게임 모드

| 모드 | 설명 |
|------|-------------|
| **튜토리얼** | 메인 메뉴의 맨 위 버튼. 다섯 개의 장으로 게임을 차근차근 배웁니다 |
| **샌드박스 모드** | 무작위로 생성된 대형 맵에서 처음부터 시작하는 자유 왕국. 난이도와 맵 크기 조절 가능, 선택형 보스 있음 |
| **커스텀 맵** | 맵 에디터로 만든 레벨을 불러오기 |
| **캠페인** | 다단계 시나리오. 내장 튜토리얼 캠페인 (5레벨) 포함 |
| **게임 불러오기** | 이전 게임을 이어서 플레이 |
