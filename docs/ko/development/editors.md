웨이워드 크라운에는 커스텀 레벨과 시나리오를 제작할 수 있는 내장 맵 에디터와 캠페인 에디터가 포함되어 있습니다.

---

## 맵 에디터

메인 메뉴의 **지도 편집기** 버튼을 누르면 새 맵으로 에디터가 열립니다. 저장된 맵은 맵 관리자의 지도 탭에서 목록 확인, 플레이, 편집, 가져오기, 내보내기를 할 수 있으며, 맵 관리자는 메인 메뉴의 **캠페인** 버튼으로 엽니다.

### 기능

- **지형 페인팅** — 지형 유형을 선택하고 브러시(크기 1 – 20)로 맵 위에 칠하거나, 영역을 채우기
- **건물 배치** — 플레이어 건물, 적 거점, 보물 상자 배치, 성 이동, 지우기
- **무작위화** — 시작점으로 쓸 무작위 맵 생성
- **실행 취소 / 다시 실행** — 최대 30단계 (Ctrl+Z / Ctrl+Y)
- **맵 설정** — 크기 (한 변 100 – 1000타일), 이름, 작성자 등 세부 정보, 시작 골드, 승리 조건
- **저장/불러오기** — 맵을 `maps/` 디렉토리에 저장. 닫기·Esc·새로 만들기는 저장하지 않은 변경을 버리기 전에 묻고(저장 / 버리기 / 취소), 한 번도 저장하지 않은 캠페인을 버리면 그 폴더도 지웁니다
- **오브젝트…** — 이 맵을 위해 만든 영웅 직업, 몬스터, 건물, 거점, 보스를 오브젝트 에디터에서 편집합니다. 처음에는 맵의 콘텐츠 팩(맵이 필수로 지정하는 내 플러그인)을 만듭니다. 팩을 저장하면 콘텐츠를 다시 불러오므로 정의한 것을 바로 배치할 수 있습니다
- **테스트 플레이** — 저장된 맵(또는 캠페인에서 편집 중인 레벨)을 별도의 게임으로 시작합니다. 콘텐츠 팩만 불러오고 다른 콘텐츠는 불러오지 않습니다

맵에는 유닛이 들어 있지 않습니다: 모험가는 게임이 진행되면서 모집되고 적은 그때 스폰됩니다.

### 지형 유형

- 초원, 숲, 산, 물, 사막, 도로, 진흙, 늪, 설원, 구릉, 황무지, 꽃밭

### 저장 형식

맵은 JSON 형식으로 `maps/` 디렉토리에 저장되며 다음 내용을 포함합니다:

- 지형 데이터 (압축된 NumPy 배열)
- 높이 데이터
- 건물, 적 거점, 보물 상자
- 성 위치
- 맵 세부 정보, 시작 골드, 승리 조건

## 캠페인 에디터

캠페인은 맵 관리자의 캠페인 탭(메인 메뉴의 **캠페인** 버튼)에서 만들고, 열고, 가져오고, 내보냅니다. 캠페인을 열면 캠페인 패널이 있는 맵 에디터가 시작되므로, 각 레벨의 맵과 설정을 한곳에서 편집할 수 있습니다.

### 기능

- **레벨 순서** — 화살표 버튼으로 레벨을 위아래로 이동
- **승리 조건** — 각 레벨의 승리 조건 설정 (`destroy_building`의 거점 유형 포함)
- **스토리 텍스트** — 시작 텍스트와 완료 텍스트 설정
- **시작 자원** — 각 레벨의 초기 골드 설정
- **이월** — 이전 레벨의 골드, 모험가, 연구를 유지
- **건물 제한** — 플레이어가 사용할 수 있는 건물 유형 제한
- **트리거** — 레벨의 스크립트 메시지와 건물 잠금 해제 (캠페인 레벨 전용)
- **왕국 필드** — 레벨의 시작 성 레벨, 제한 시간, 브리핑의 조언, 최대 두 개의 선택 목표
- **추가 목표와 패배 조건** — 필수 또는 선택인 승리 조건 추가와 패배 방식 추가(쓰러진 영웅, 잃은 건물이나 상단)를 두 표에서 추가·제거
- **대상 출처** — 승리 대상 아래에 보스가 맵에 배치된 것인지 트리거로 시작되는 것인지, 거점 유형이 게임의 것인지 플러그인의 것인지와 맵에 몇 개 있는지를 표시. 추가 목표의 대상은 툴팁으로 같은 내용을 알려 줍니다

### 승리 조건 옵션

| 유형 | 설명 |
|------|-------------|
| `free` | 자유 모드, 승리 조건 없음 |
| `destroy_enemy_buildings` | 모든 적 거점 파괴 |
| `survive_ticks` | 지정된 시간 동안 생존 |
| `reach_gold` | 지정된 양의 골드 축적 |
| `destroy_building` | 특정 유형의 거점 파괴 |
| `defend` | 지정된 시간 동안 성 방어 |
| `collect_chests` | 모든 보물 상자 수집 |

### 저장 구조

```
campaigns/my_campaign/
├── campaign.json         # 캠페인 메타데이터
├── level1.json           # 레벨 1 맵
├── level2.json           # 레벨 2 맵
└── level3.json           # 레벨 3 맵
```

## 커스텀 콘텐츠 공유

- 맵과 캠페인 폴더는 단순히 복사하거나, 맵 관리자의 내보내기와 가져오기로 공유할 수 있습니다
- 받은 맵을 `maps/`에 넣으면 메인 메뉴에서 불러올 수 있습니다
- 받은 캠페인을 `campaigns/`에 넣으면 메인 메뉴에서 확인할 수 있습니다
- Steam으로 게임을 실행하면 맵 관리자의 **창작마당에 게시**로 내 맵이나 캠페인을 Steam 창작마당에 올릴 수 있고, 구독한 항목은 목록에 [창작마당] 표시와 함께 나타납니다. Steam이 최신 상태로 유지하므로 편집, 이름 바꾸기, 삭제는 할 수 없으며, **복제**하면 내 맵이 됩니다
- 콘텐츠 팩이 있는 맵이나 캠페인은 그 플러그인이 필요합니다. 공유할 때는 팩도 함께 주고, 게시할 때는 팩을 먼저 게시하세요(게시 창이 팩의 창작마당 아이템을 필수 아이템으로 제안합니다)
