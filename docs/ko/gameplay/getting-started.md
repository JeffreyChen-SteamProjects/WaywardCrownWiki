## 당신의 역할

당신은 웨이워드 크라운의 관리자입니다. 모험가의 이동이나 공격을 **직접 조종할 수 없습니다** — 모험가는 성격, 필요, 현재 상태에 따라 자율적으로 행동합니다.

할 수 있는 것：

- **현상금 깃발**을 배치하여 골드 보상으로 모험가를 특정 위치로 유인
- **건물**을 건설하여 특정 클래스를 모집하고 장비와 휴식 장소를 제공
- **도서관**에서 스킬을 연구하여 모든 모험가를 강화
- **경제**를 관리하여 수입과 지출의 균형을 유지하고 길드 운영을 지속

---

## 첫 번째 게임

### 1. 초기 건설

게임 시작 시 **1,500 골드**와 성이 있습니다. 다음 순서로 건설하세요：

1. **병영** (150g) — 전사를 모집. 가장 기본적인 전투력
2. **시장** (300g) — 안정적인 세금 수입 제공
3. **여관** (120g) — 부상당한 모험가가 HP를 회복 가능
4. **경비 초소** (120g) — 경비병을 모집하여 건물 순찰 및 방어

:::tip[건물 배치 팁]
건물 배치 시 블루프린트 미리보기가 표시됩니다: **파란색**은 배치 가능, **빨간색**은 배치 불가를 의미합니다. 건물은 탐험한 마른 땅이어야 하며, 성에서 최소 14타일, 다른 건물에서 최소 3타일 떨어져야 합니다.
:::

### 2. 현상금 게시

왼쪽 패널의 현상금 버튼을 클릭하여 맵에 깃발을 배치합니다：

- **탐색 현상금** — 전장의 안개를 걷어내고 새로운 지역 발견
- **처치 현상금** — 지정된 대상을 제거하도록 모험가를 파견
- **방어 현상금** — 자신의 건물이나 성을 순찰하고 지키도록 모험가를 배정

:::note[현상금 보상]
보상이 높을수록 더 많은 모험가가 현상금을 수락하려 합니다. 하지만 예산에 주의하세요!
:::

### 3. 관찰과 적응

모험가는 자동으로 다음을 수행합니다：

- 성 근처 상점에서 포션과 장비 구매
- 성격에 맞는 현상금 수락
- 조우한 적과 전투
- HP가 낮아지면 휴식하러 귀환
- 미지의 지역을 탐험하고 보물 상자를 획득

### 4. 위협 대응

게임이 진행됨에 따라 다양한 랜덤 이벤트가 발생합니다：

- **몬스터 침략**: 대규모 적 무리가 성을 공격
- **붉은 달**: 적의 공격력 증가
- **드래곤 둥지 각성**: 먼 곳에 드래곤 둥지가 출현, 파괴 필요

충분한 전투 인원과 화살 탑을 확보하여 방어하세요!

## 경제 관리

### 수입원

| 수입원 | 금액 | 빈도 |
|--------|--------|-----------|
| 시장 수입 | 30g × 시장 레벨 | 게임 시간 72초마다 |
| 세금 | 모험가가 쓰거나 버는 금액의 20% | 모험가가 구매, 학습, 처치, 상자 열기를 할 때 |

세금과 시장 수입은 세금 징수원이 성으로 나를 때까지 건물의 금고에서 기다립니다.

### 주요 지출

| 항목 | 비용 |
|------|------|
| 건물 건설 | 0 – 300g (같은 유형을 추가로 지을 때마다 50% 비싸짐) |
| 건물 업그레이드 | 140 – 600g |
| 현상금 보상 | 커스텀 (기본값 200g) |
| 스킬 연구 | 150 – 900g |

:::caution[경고]
지출이 수입을 초과하면 길드가 운영되지 않습니다. 안정적인 수입원을 확보하기 위해 시장 건설을 우선시하세요.
:::

## 난이도 설정

새 게임 시작 시 다음을 조정할 수 있습니다：

| 설정 | 설명 | 기본값 |
|---------|-------------|---------|
| 모험가당 적 수 | 모험가 1명당 적의 수 | 2 |
| 적 HP 배율 | 적 HP 배율 | 1.0배 |
| 골드 배율 | 골드 획득 배율 | 1.0배 |
| 적 건물 | 맵 위 적 거점의 수 | 3 |
| 지도 크기 | 맵 변의 길이 (250 – 1000) | 1000 |
| 샌드박스 유형 | 생성되는 거점을 한 종족으로 제한 | 아무거나 |
| 샌드박스 난이도 | 쉬움, 보통, 어려움: 소굴 습격마다 1마리 적거나 2마리 많음 | 보통 |
| 보스 도전 | 족장 내시팽이 20분 뒤 한 번 옴 | 꺼짐 |

쉬움과 어려움은 적의 체력을 결코 바꾸지 않습니다. 쉬움은 소굴 습격마다 1마리 적고 어려움은 2마리 많습니다. 미션 화면에서 난이도를 고르는 캠페인 레벨에서는 스크립트 웨이브도 원래의 75% 또는 125%가 되고 시작 골드는 125% 또는 85%가 됩니다. 길드가 하나도 남지 않고 새로 지을 돈도 없으면 왕실이 모자란 만큼을 채워 줍니다(최대 5분에 한 번). 난이도는 왕국이 스스로 불러온 압박에 대비할 시간도 정합니다. 초반의 유예와 무리가 오기 전의 경고 모두입니다. 쉬움에서는 평소의 125%, 어려움에서는 80%. 경고는 언제나 옵니다.

## 조작법

| 조작 | 설명 |
|--------|-------------|
| 스크롤 휠 | 맵 줌 |
| 우클릭 드래그 | 카메라 이동 |
| 좌클릭 (엔티티) | 상세 정보 보기 |
| 좌클릭 (맵) | 건물 / 현상금 배치 |
| 좌클릭 드래그 | 길 그리기 (길 도구 사용 시) |
| 드래그 없이 우클릭 | 현상금 메뉴 열기 |
| Space | 일시정지 / 재개 |
| 1 / 2 / 3 | 게임 속도 (일시정지된 게임도 재개) |
| Esc | 건물이나 현상금 배치 취소, 배치 중이 아니면 게임 메뉴(저장, 불러오기, 설정, 레벨 다시 시작, 메인 메뉴) 열기 |
| Shift + 좌클릭 | 건물을 배치하고 계속 선택된 상태로 두기 |
| 지도 더블클릭 | 그 자리에 맞는 현상금 걸기 |
| Ctrl+S / Ctrl+O | 게임 저장 / 불러오기 |
| 미니맵 클릭 | 해당 위치로 이동 |
| Home | 성 보기 |
| P | 성의 길 창 (성의 길이 있는 맵) |
| K / C | 왕국 개요 / 연대기 |
| L | 명부: 모든 영웅, 길드, 공사, 각 건물의 매출을 필터와 함께 |
| M | 지도 레이어: 보급, 옮겨지는 금, 공사, 알려진 위협, 마법 범위 |
| 장소가 있는 알림 클릭 | 그 장소 보기 |
| 골드 클릭 | 왕국 개요 열기 |
| F | 건설 메뉴 검색 |
| Q / W | 첫 번째 / 두 번째 왕실 마법 준비 |
| A / S / D / G / H | 패널에 나열된 순서대로 현상금 종류를 집기(같은 키를 다시 누르면 내려놓음) |
| B | 마지막으로 놓은 건물을 다시 집기 |
| F6 다음 Tab | 키보드를 다음 패널로 옮기고 그 안의 컨트롤을 돎 (Esc는 맵으로) |

Esc를 뺀 위의 모든 키는 설정 > 키에서 바꿀 수 있습니다. 두 동작에 지정된 키는 목록의 첫 동작에 쓰이며, 설정 화면이 이를 알려 줍니다. 이미 쓰이는 키는 거절됩니다. 숫자 키패드의 숫자는 숫자로 취급합니다. 키를 누르고 있어도 한 번만 작동합니다.

새로운 일을 처음 할 수 있게 되면 짧은 힌트가 나옵니다(공사장, 걷을 금고, 아무도 받지 않는 현상금, 올릴 수 있는 성, 고를 수 있는 길, 고를 수 있는 특화, 쓸 수 있는 마법). 힌트마다 한 번만 나오고 연대기에 남아 다시 읽을 수 있으며, 조언 설정으로 팝업을 끌 수 있고 설정 > 힌트 다시 보기로 모두 되살릴 수 있습니다. 이후의 힌트는 해당 시스템과 함께 나옵니다. 소굴을 알게 되었을 때의 지도 레이어, 공사가 밀릴 때의 작업반 작업 순서, 묶여 있는 금, 왕국이 스스로 불러온 압박, 길드를 잃은 영웅, 떠날 생각을 하는 영웅.
