---
title: "전투 시스템"
---

전투는 완전 자동입니다. 모험가와 적은 서로 공격 범위 내에 있으면 자동으로 교전합니다.

---

## 전투 흐름

1. **감지** — 모험가가 시야 내의 적을 발견 (2틱마다 확인)
2. **접근** — 적이 보이지만 공격 범위 밖이면 모험가가 추격
3. **공격** — 공격 범위 내에 들어오면 양측 전투 시작
4. **판정** — 데미지는 5틱마다 한 번 계산

---

## 데미지 계산

### 모험가가 적 공격

| 유형 | 데미지 공식 |
|------|---------------|
| 근접 | `ATK × 2` (글로벌 데미지 배율) |
| 원거리 | `ATK` (투사체 데미지, 배율 미적용) |

### 적이 모험가 공격

```
데미지 = (적 ATK + random(0~2)) × 2
```

### 방어

```
실제 데미지 = max(1, 데미지 - DEF)
```

### 회피

| 출처 | 회피율 |
|--------|-------------|
| 모험가 기본 회피 | 10% + 1% × 민첩 (≤ 70%) |
| 적 기본 회피 | 5% |
| 레인저 "회피" 스킬 | +15% |
| 도적: 회피 | +10% |
| 도적: 그림자 춤 | +18% |
| 레인저: 바람 가르기 | +25% |

## 투사체 시스템

원거리에서 싸우는 유닛은 저마다 고유한 투사체를 쏘므로, 날아가는 것만 보고도 누구의 공격인지 알 수 있습니다. 나머지 클래스는 3타일까지 닿더라도 근접전을 합니다:

| 클래스 | 투사체 유형 |
|-------|----------------|
| 레인저 | 화살 (arrow) |
| 길잡이 | 투창 (javelin) |
| 길목 지킴이 | 쇠뇌 화살 (bolt) |
| 마법사 | 화염구 (fireball) |
| 공명 술사 | 빛의 조각 (light_shard) |
| 고블린 궁수 (적) | 조잡한 화살 (goblin_arrow) |
| 어둠의 교도 (적) | 어둠의 구슬 (dark_orb) |
| 드래곤 (적) | 화염 숨결 (dragon_flame) |

투사체는 발사 후 매 틱마다 대상을 향해 이동하며 명중 시 데미지를 가합니다. 투사체는 날아가는 방향에 맞춰 그려집니다. 지도 위쪽으로 날아가는 것은 뒤에서, 가로질러 날아가는 것은 옆에서 보입니다.

## 화살 탑

화살 탑는 자동화된 방어 건물입니다:

| 속성 | 값 |
|----------|-------|
| 공격 범위 | 20타일 |
| 기본 데미지 | 16 + 8 × (Lv − 1) |
| 업그레이드 스케일링 | 레벨에 따라 증가 |

화살 탑는 범위 내 가장 가까운 적을 자동으로 공격합니다.

## 경험치 보상

| 출처 | XP |
|--------|-----|
| 타격당 (드립) | 처치 XP의 1/5 |
| 슬라임 처치 | 10 XP |
| 고블린 처치 | 25 XP |
| 해골 처치 | 40 XP |
| 좀비 처치 | 60 XP |
| 드래곤 처치 | 150 XP |

:::note[드립 XP]
모험가가 적을 타격할 때마다 — 근접이든 투사체든 — 해당 적의 처치 XP의 1/5을 받습니다. 이를 통해 최종 일격을 가하지 않아도 모험가가 경험치를 획득할 수 있습니다.
:::

## 전투 AI

### 모험가 도주 조건

- HP < 30% (HP_CRITICAL)
- 도주 확률은 안전 성격 특성에 영향을 받음

### 포션 사용

| 조건 | 행동 |
|-----------|----------|
| HP < 30% | 긴급 포션 사용 |
| HP < 50% | 포션 사용 |

### 적의 타겟 우선순위

1. 전투 중인 모험가 (비평화주의자)
2. 건축가 (평화주의자)
3. 화살 탑 등 위협적인 건물
4. 성
5. 기타 건물

중독의 남은 시간, 다음 피해 시점과 처치 공로는 저장 후에도 유지됩니다. 도적의 독도 제단과 목욕탕의 정화로 제거되며 보호막은 유지됩니다. 보스의 기본 제어 저항을 적용한 뒤, 고정된 10초 구간의 반복 제어는 지속 시간이 100%, 50%, 25%로 줄고 이후 시도는 구간이 끝날 때까지 효과가 없습니다. 더 짧은 재적용은 기존 제어를 단축하지 않으며 반복 시도는 초기화를 늦추지 않습니다. 일반 적에게는 이 면역이 없습니다.

임무는 순서대로 진행하는 최대 8단계를 가지며 각 단계에 필수와 선택 목표를 둘 수 있습니다. 완료 단계와 선택 결과는 저장되고 선택 목표 실패는 기본 승리를 막지 않습니다. 지정 적과 거점은 실제로 파괴되어야 하며 살아 있는 대상의 삭제는 완료로 처리되지 않습니다. 아군 보호는 임무 끝까지 원래 유닛이나 건물을 추적하므로 대체 대상으로 만족할 수 없습니다. 제작자는 명성, 유한한 적 파도와 대상 목록을 설정하며 누락 참조는 시작 전에 거부됩니다.
