## 你的角色

你是不馴之冠的管理者。你**無法**直接控制任何冒險者的移動或攻擊——他們會根據自己的性格、需求與當前狀態自主行動。

你能做的事：

- 放置**懸賞旗幟**，用獎金吸引冒險者前往指定地點
- 建造**建築**，招募特定職業、提供裝備與休息場所
- 透過**圖書館**研究技能，全面強化冒險者
- 管理**經濟**，平衡收支以維持公會運作

## 第一場遊戲

### 1. 開局建設

遊戲開始時你有 **1,500 金幣**與一座城堡。建議依序建造：

1. **兵營**（150g）— 招募戰士，最基本的戰力
2. **市場**（300g）— 提供定期稅收收入
3. **旅店**（120g）— 讓受傷冒險者休息回血
4. **衛兵哨所**（120g）— 招募城鎮衛士巡邏保護建築

:::tip[建築放置技巧]
建築放置時會顯示藍圖預覽：**藍色**表示可建造，**紅色**表示不可建造。建築必須蓋在已探索的陸地上，距離城堡至少 14 格，並與其他建築相隔至少 3 格。
:::

### 2. 發布懸賞

點擊左側面板的懸賞按鈕，在地圖上放置旗幟：

- **探索懸賞** — 揭開戰爭迷霧，發現新區域
- **討伐懸賞** — 派人擊殺指定目標
- **防守懸賞** — 指派冒險者巡邏守衛你的某棟建築或城堡

:::note[懸賞獎金]
獎金越高，越多冒險者願意接受。但要注意收支平衡！
:::

### 3. 觀察與適應

冒險者會自動：

- 在城堡附近的商店購買藥水和裝備
- 接受符合自身性格的懸賞
- 遭遇敵人時進入戰鬥
- 血量不足時返回休息
- 探索未知區域並拾取寶箱

### 4. 應對威脅

隨著遊戲進行，會出現各種隨機事件：

- **怪物入侵**：大批敵人進攻城堡
- **血月**：敵人攻擊力提升
- **龍巢覺醒**：遠處出現龍巢，需派人摧毀

確保你有足夠的戰力和箭塔來防禦！

## 經濟管理

### 收入來源

| 來源 | 金額 | 頻率 |
|------|------|------|
| 市場收入 | 30g × 市場等級 | 每 72 秒遊戲時間 |
| 稅收 | 冒險者花費或賺取金額的 20% | 冒險者購物、研習、擊殺或開啟寶箱時 |

稅收與市場收入會留在建築的錢櫃裡，等稅務員把它們送回城堡。

### 主要支出

| 項目 | 費用 |
|------|------|
| 建築建造 | 0 ~ 300g（同類建築每多蓋一棟，費用多 50%） |
| 建築升級 | 140 ~ 600g |
| 懸賞獎金 | 自訂（預設 200g） |
| 研究技能 | 150 ~ 900g |

:::caution[注意]
入不敷出時公會就無法運作。優先建造市場確保穩定收入。
:::

## 難度設定

開始新遊戲時可調整：

| 設定 | 說明 | 預設值 |
|------|------|--------|
| 敵人與冒險者比例 | 每位冒險者對應的敵人數量 | 2 |
| 敵人血量倍數 | 敵人 HP 乘數 | 1.0x |
| 金錢倍率 | 金幣獲取乘數 | 1.0x |
| 敵方建築數量 | 地圖上的敵方據點數 | 3 |
| 地圖大小 | 地圖邊長（250 ~ 1000） | 1000 |
| 沙盒類型 | 將生成的據點限制為單一種族 | 任意 |
| 沙盒難度 | 簡單、普通或困難：每次怪巢襲擊少一隻或多兩隻 | 普通 |
| BOSS 挑戰 | 裂牙酋長在 20 分鐘後來襲一次 | 關閉 |

簡單與困難絕不改敵人的血量：簡單讓每次怪巢襲擊少一隻，困難多兩隻；在任務畫面選定難度的戰役關卡，劇本敵波還會是原本的 75% 或 125%，起始金幣是 125% 或 85%。一座公會都不剩、又沒錢再蓋時，王室會補足差額（最多每五分鐘一次）。難度也決定王國有多少時間準備應付自己招來的壓力，包括開局的緩衝與敵群到來前的預警：簡單是平常的 125%，困難是 80%。預警一定會有。

## 快捷操作

| 操作 | 說明 |
|------|------|
| 滾輪 | 縮放地圖 |
| 右鍵拖曳 | 平移攝影機 |
| 左鍵點擊實體 | 查看詳細資訊 |
| 左鍵點擊地圖 | 放置建築 / 懸賞 |
| 左鍵拖曳 | 鋪設道路（使用道路工具時） |
| 右鍵點擊（不拖曳） | 開啟懸賞選單 |
| 空白鍵 | 暫停 / 繼續 |
| 1 / 2 / 3 | 遊戲速度（暫停中也會繼續） |
| Esc | 取消放置建築或懸賞；沒有在放置時開啟遊戲選單（存檔、讀檔、設定、重新開始本關、主選單） |
| Shift + 左鍵 | 放置建築並保持選取 |
| 雙擊地圖 | 發布適合該處目標的懸賞 |
| Ctrl+S / Ctrl+O | 存檔 / 讀檔 |
| 迷你地圖點擊 | 快速跳轉到該位置 |
| Home | 顯示城堡 |
| P | 城堡路線視窗（有城堡路線的地圖） |
| K / C | 王國總覽 / 事件簿 |
| L | 名冊：每位英雄、公會、工程與每棟建築的營收，附篩選 |
| M | 地圖圖層：補給、在路上的金幣、工程、已知威脅、法術範圍 |
| 點擊關於某地的通知 | 顯示那個地點 |
| 點擊金錢 | 打開王國總覽 |
| F | 搜尋建造選單 |
| Q / W | 準備第一個 / 第二個王室法術 |
| A / S / D / G / H | 照面板上的順序拿起一種賞金任務（再按同一個鍵放下） |
| B | 再拿起上一座放下的建築 |
| F6，再按 Tab | 把鍵盤移到下一個面板並走遍裡面的控制項（Esc 回到地圖） |

上面除 Esc 以外的按鍵都能在「設定 > 按鍵」更改；同一個鍵設給兩個動作時，只有清單裡第一個會用到，設定裡會提示；已被用掉的鍵會被拒絕。數字鍵盤的數字視同數字。按住一個鍵只會作用一次。

第一次能做某件新事時會有一則簡短提示：工地、該收的錢櫃、沒人接的懸賞、可以升級的城堡、可以選的路線、可以選的專精、可以用的法術。每則只出現一次，會記進事件簿可以重看；顧問設定可以關掉它的彈出訊息，「設定 > 重新顯示提示」能讓它們再出現。之後的提示會隨所屬的系統出現：發現巢穴後的地圖圖層、工程排隊時工班的施工順序、卡住的金幣、王國自己招來的壓力、失去公會的英雄、想離開的英雄。
