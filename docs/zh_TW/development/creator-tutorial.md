---
title: "創作者教學"
---

每個範本都從 **創作工具與 Steam 工作坊**（主選單、地圖管理員或外掛管理員）開始，用同樣的步驟從 **新增專案** 走到私人工作坊項目。只有最後一步需要 Steam。

## 共同步驟

1. **新增專案**：選擇範本、名稱與資料夾。對話框會在寫入任何東西之前顯示作品會放在哪裡。
2. **編輯專案**：外掛會開啟外掛編輯器；地圖或戰役用 **開啟地形／戰役編輯器** 開啟，它在獨立的行程中執行，只載入作品需要的內容。進入下一步前先存檔：檢查、試玩與發布都使用已存檔的檔案。
3. **驗證內容**：每個問題都會說明位置；按兩下即可在編輯器中開到那裡。
4. **試玩**：在獨立的遊戲中只載入這個作品與它需要的內容。報告會列出載入了什麼，並在執行時顯示 tick 時間、記憶體與精靈圖集，從正常到過重分級。
5. **匯出…**：輸出成 ZIP 或資料夾，作品 ID 不變，用來保存或分享。
6. **發布到工作坊**：在 Steam 執行時，第一次測試請選 **私人**，再按 **檢查並檢閱** 與 **送出發布**。發布不會檢查能否載入：請在 **瀏覽工作坊** 找到該項目、按 **訂閱**，並在 **訂閱** 看著它直到可用。

## 地圖

範本是一張 32×32 的地圖，有一座城堡、城堡東邊兩格有一個裝 100 金幣的寶箱、起始金幣 500，勝利條件是收集寶箱。

1. 在地形編輯器中繪製地形並放置建築、據點與寶箱，然後存檔。
2. **驗證內容** 會警告英雄從城堡走不到的據點、寶箱或 BOSS。
3. 版本：每次發布變更時都要提高 **專案版本**。用舊版本建立的存檔會保留舊版本的副本。

## 戰役

範本有兩關，每關都有自己的地圖，城堡與寶箱相同；戰役檔決定關卡順序，並為每關設定標題、劇情文字與起始金幣。

1. 在地形編輯器中開啟戰役面板，調整關卡順序、勝利條件、劇情文字、延續內容與觸發器。
2. **試玩** 可以從任何一關開始。
3. 相依：關卡用到某個外掛的單位時，在 **相依項目** 加入該外掛的作品，並設定版本範圍，例如 `>=1.0.0, <2.0.0`。

## 外掛

範本包含一個英雄職業、一種敵人、一座招募該職業的建築、一座派出該敵人的據點、一個技能、一項研究、一個事件、一個具名 BOSS、一種地塊外觀與一個英文語言檔，全部使用作品自己的命名空間。

1. 在各種類的表格中編輯；屬性表單會把沿用基礎定義的值標成灰色，並立即標出超出遊戲範圍的值。
2. 素材：**素材** 分頁可以直接拖放圖片檔，並把每個檔案與大小及記憶體限制比較。範本的地塊外觀用 `preview.png` 當作範例圖片，可在這裡替換。
3. 覆寫：**複製內建內容…** 會用你自己的 ID 加入遊戲角色的完整副本，並在用到的地方取代原本的角色。使用內建 ID 的定義（例如 base 為 `SLIME` 的 `SLIME`）會在外掛啟用時改變遊戲本身的史萊姆；**內容設定檔** 會顯示哪個外掛的覆寫生效。
4. 版本：**專案版本** 是作品本身的版本；**支援的遊戲版本** 是它接受的遊戲版本範圍（`*` 代表任何版本；開發版只接受 `*`）。

## 首領教學（外掛＋雙關卡戰役）

範本是一個資料夾，裡面有一個外掛與一個需要它的兩關戰役；第二關要擊敗外掛裡的具名 BOSS 才算勝利。

1. 戰役的 **相依項目** 寫著外掛的作品與版本，因此試玩時會一起帶上外掛。
2. 先發布外掛，再發布戰役：發布視窗會建議把外掛的工作坊項目設為必要項目。
3. 每次修改外掛都要提高它的 **專案版本**；戰役的版本範圍要寬到能接受新版本。

## 王國任務（單關：簡報、旗標、敵波、BOSS）

範本是一個王國關卡，包含任務簡報、城鎮、怪巢、王室的探索、擊殺與防守旗幟、兩波預告的襲擊、一個具名 BOSS 與一個可選的發現。在戰役面板中逐關拆解它，然後照共同步驟進行。

## 範本絕不包含的東西

範本不包含真實的工作坊項目 ID、Steam 帳號或絕對路徑：作品 ID 會在你的電腦上新產生，每個檔案都以作品內的相對路徑命名。
