## 語言檔格式

語言檔為 JSON 格式，放在 `game/lang/` 目錄下：

```json
{
  "window_title": "不馴之冠",
  "log_defeated_enemy": "{adv} 擊敗了 {enemy}（金幣: {gold} XP: {xp}）",
  "building_market": "市場",
  "class_warrior": "戰士"
}
```

- 支援 `{placeholder}` 動態替換
- 缺少的翻譯鍵自動回退至英文
- 切換語言即時生效，不需重啟

---

## 語言偵測順序

1. `--lang` / `--language` CLI 參數（最高優先；只套用於本次執行，不會儲存）
2. 使用者在設定選單手動選擇的語言（在那裡選擇「自動」會清除這項選擇）
3. Steam 客戶端語言（沒有手動選擇時，每次啟動都會自動偵測）
4. 上次使用的語言
5. 英文（預設回退）

## 新增語言（外掛）

透過外掛新增語言只需要翻譯檔，以及一個在 `content.languages` 底下列出該檔案的 `plugin.json`（未列出的檔案不會被載入）：

```
plugins/my_lang/
├── plugin.json
└── lang/
    └── xx.json    # 你的語言代碼
```

```json
{
  "id": "my_lang",
  "name": "My Language",
  "content": {"languages": ["lang/xx.json"]}
}
```

語言代碼和語言列表中顯示的名稱來自檔案的 `_meta` 區塊（`"_meta": {"language": "xx", "label": "My Language"}`）；沒有這個區塊時則使用檔名。語言代碼可以是任意字串（如 `ja`、`ko`、`my_custom`），會自動出現在設定選單的語言列表中。

## 戰役多語系

戰役文字可以使用 `i18n:` 前綴標記翻譯鍵：

```json
{
  "title": "i18n:tut_level1_title",
  "intro": "i18n:tut_level1_intro"
}
```

遊戲會根據當前語言自動解析翻譯鍵。如果找不到對應翻譯，會直接顯示鍵名。
