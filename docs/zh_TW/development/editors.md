title: "地圖與戰役編輯器"

不馴之冠內建地圖編輯器和戰役編輯器，讓你打造自訂關卡和劇本。

---

## 地圖編輯器

主選單的**編輯工具包**按鈕會以一張新地圖開啟編輯器。已儲存的地圖在地圖管理器的**地圖**分頁中列出，可在那裡遊玩、編輯、匯入和匯出；地圖管理器由主選單的**戰役**按鈕開啟。

### 功能

- **地形繪製** — 選擇地形類型，用筆刷（大小 1 ~ 20）在地圖上繪製，或填充一整個區域
- **建築放置** — 放置玩家建築、敵方據點和寶箱，移動城堡，或擦除
- **隨機地形** — 產生一張隨機地圖作為起點
- **復原 / 重做** — 最多 30 步（Ctrl+Z / Ctrl+Y）
- **地圖設定** — 大小（每邊 100 ~ 1000 格）、名稱、作者等資訊、初始金幣和勝利條件
- **存讀檔** — 存檔到 `maps/` 目錄；關閉、Esc 與新增會在丟棄未儲存的變更前詢問（儲存／不儲存／取消），放棄一個從未儲存的戰役會一併刪除它的資料夾
- **物件…** — 在物件編輯器裡，用你自己的內容包編輯英雄職業、怪物、建築、據點與首領。按鈕會列出你的內容包與**新增內容包…**，不需要先存好地圖。內容包是獨立的外掛；存檔後會重新載入內容，它定義的東西馬上可以放到地圖上。地圖或戰役要等到存檔時上面真的放了某個包的東西，才會把那個包列為必要項目
- **試玩** — 用已存檔的地圖（或戰役正在編輯的那一關）另開一場遊戲，只帶它需要的內容包，不帶你其他的內容
- **面板** — 筆刷與地圖的規則（或戰役）是地圖兩旁的分頁面板：可以拖到另一側或拉出視窗、關掉，再用**面板**叫回來。地形、建築、據點與首領都用圖來選；編輯器和它開出來的視窗（物件編輯器、觸發器編輯器、地圖資料）都可以放到最大

地圖不包含任何單位：冒險者在遊戲開始後才會招募，敵人也在遊戲開始後才會生成。

### 地形類型

- 草地、森林、山地、水域、沙漠、道路、泥地、沼澤、雪地、丘陵、荒地、草甸

### 存檔格式

地圖以 JSON 格式存放在 `maps/` 目錄下，包含：

- 地形資料（壓縮過的 NumPy 陣列）
- 高度資料
- 建築、敵方據點和寶箱
- 城堡位置
- 地圖資訊、初始金幣和勝利條件

## 戰役編輯器

戰役在地圖管理器的**戰役**分頁中建立、開啟、匯入和匯出（由主選單的**戰役**按鈕進入）。開啟戰役時會啟動附帶戰役面板的地圖編輯器，讓你在同一處編輯每一關的地圖和設定。

### 功能

- **關卡排序** — 用箭頭按鈕上下移動關卡
- **勝利條件** — 為每關設定勝利條件，包括 `destroy_building` 的據點類型
- **故事文字** — 設定開場與過關文字
- **初始資源** — 設定每關的初始金幣
- **沿用資源** — 保留上一關的金幣、冒險者和研究
- **建築限制** — 限制玩家可用的建築類型
- **觸發器** — 為關卡設定腳本訊息和建築解鎖（僅限戰役關卡）
- **王國欄位** — 關卡的起始城堡等級、時限、簡報的建議，以及最多兩個可選目標
- **附加目標與失敗條件** — 更多勝利條件（每個可設為必做或選做）與更多失敗方式（倒下的英雄、失去的建築或商隊），在兩個表格中新增與移除
- **目標來源** — 在勝利目標下方顯示：BOSS 是擺放在地圖上還是由觸發器啟動，據點類型是遊戲內建還是外掛的、地圖上有幾個；附加目標的目標欄以提示顯示同樣資訊

### 勝利條件選項

編輯器以你的語言顯示這些條件的名稱；下表的類型是地圖與戰役檔案裡存的值。

| 類型 | 說明 |
|------|------|
| `free` | 自由模式，無勝利條件 |
| `destroy_enemy_buildings` | 摧毀所有敵方據點 |
| `survive_ticks` | 存活指定時間 |
| `reach_gold` | 累積指定金額 |
| `destroy_building` | 摧毀特定類型據點 |
| `defend` | 防守城堡指定時間 |
| `collect_chests` | 收集所有寶箱 |
| `defeat_boss` | 擊敗具名首領（擺在地圖上或由觸發器啟動） |
| `secure_trade` | 讓商隊完成指定趟數的往返，並摧毀所有敵方據點 |

### 存檔結構

```
campaigns/my_campaign/
├── campaign.json         # 戰役元資料
├── level1.json           # 第一關地圖
├── level2.json           # 第二關地圖
└── level3.json           # 第三關地圖
```

## 分享自訂內容

- 地圖和戰役資料夾可以直接複製分享，也可以使用地圖管理器的匯出和匯入功能
- 收到的地圖放入 `maps/` 即可在主選單載入
- 收到的戰役放入 `campaigns/` 即可在主選單看到
- 透過 Steam 執行遊戲時，地圖管理器的**發布到工作坊**可以把自己的地圖或戰役發布到 Steam 工作坊，訂閱的內容會出現在清單中並標上 [工作坊]。這些內容由 Steam 保持更新，所以不能編輯、改名或刪除；**複製**可以得到一份自己的地圖
- 內容包可以單獨安裝：把它單獨發布或單獨分享它的 ZIP，裝了它的人不需要任何地圖，就能在自己的遊戲裡用到它的職業、怪物、建築與據點。放了某個包的東西的地圖或戰役會需要那個外掛：發布時先發布內容包（發布視窗會建議把內容包的工作坊項目列為必要項目）
