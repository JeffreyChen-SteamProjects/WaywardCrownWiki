title: "不馴之冠 Wayward Crown"
---

**不馴之冠**是一款模擬經營遊戲。你扮演不馴之冠的管理者，透過懸賞、建築與經濟手段**間接引導**一群擁有自主意志的冒險者。你無法直接控制任何角色——只能觀察並操控整個冒險者生態系。

---

## 核心特色

- **間接控制** — 冒險者依據自身性格與需求自主行動，你只能透過獎金、建築與研究來影響他們
- **豐富的隨機事件** — 超過 50 種事件，從血月到寶箱雨，每場遊戲都不同
- **深度經濟系統** — 平衡懸賞支出、建築投資、市場稅收與冒險者消費
- **大規模戰鬥** — 支援數千名冒險者與上萬敵人同時在場
- **自製關卡** — 內建地圖編輯器與戰役編輯器，打造並分享你自己的劇本
- **外掛系統** — 修改內建的職業、敵人與建築，新增語言包，無須修改原始碼
- **15 種語言** — 英文、繁中、簡中、日文、韓文、俄文、德文、法文等

---

## 遊戲模式

| 模式 | 說明 |
|------|------|
| **教學** | 主選單最上面的按鈕：五個章節一步步教你怎麼玩 |
| **沙盒模式** | 在隨機生成的大型地圖上從零開始經營的自由王國，可調整難度與地圖大小，還有可選的 BOSS |
| **自訂地圖** | 載入以地圖編輯器製作的關卡 |
| **戰役** | 多關卡劇本，內建教學戰役（5 關） |
| **讀取存檔** | 繼續先前的遊戲進度 |
