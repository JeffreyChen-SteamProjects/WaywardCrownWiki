title: "敵方據點"
---

敵方據點是散布在地圖各處的敵人基地。它們有自己的守衛，而且大多會襲擊你的城鎮（見下方的「怪巢襲擊」）。

## 攻略據點

### 攻擊流程

1. 冒險者到達據點附近
2. 先與**守衛敵人**交戰（最多 3 隻）
3. 在據點附近停留可**偷取金幣**
4. 金幣掏空後可**攻擊牆壁**
5. 牆壁 HP 歸零 → 據點被摧毀

### 策略建議

:::tip[如何有效摧毀據點]
1. 在據點附近放置**討伐懸賞**（高獎金）
2. 確保有足夠的遠程冒險者（法師 / 遊俠）
3. 法師（攻擊距離 12）和遊俠（攻擊距離 11）可以在安全距離外射擊
4. 帶上城鎮衛士保護遠程單位
5. 準備建築工人修復任何受損建築
:::

:::caution[注意]
攻擊據點牆壁**不會獲得經驗值**。只有擊殺守衛敵人才有經驗。摧毀據點可獲得 +25 聲望，並領取掛在上面的懸賞；不會掉落任何東西。
:::
