## Formato dos Arquivos de Idioma

Os arquivos de idioma estão em formato JSON, armazenados no diretório `game/lang/`:

```json
{
  "window_title": "Wayward Crown",
  "log_defeated_enemy": "{adv} derrotou {enemy} (Ouro: {gold} XP: {xp})",
  "building_market": "Mercado",
  "class_warrior": "Guerreiro"
}
```

- Suporta substituição dinâmica com `{placeholder}`
- Chaves de tradução ausentes utilizam automaticamente o inglês como fallback
- A troca de idioma tem efeito imediato, sem necessidade de reiniciar

---

## Ordem de Detecção de Idioma

1. Argumento CLI `--lang` / `--language` (maior prioridade; vale apenas para esta sessão e não é salvo)
2. Idioma selecionado manualmente pelo usuário no menu de configurações (escolher "Automático" ali o apaga)
3. Idioma do cliente Steam (detectado automaticamente a cada inicialização enquanto não houver escolha manual)
4. O idioma usado da última vez
5. Inglês (fallback padrão)

## Adicionando Idiomas (Plugins)

Adicionar um idioma via plugin requer apenas um arquivo de tradução e um `plugin.json` que o liste em `content.languages` (um arquivo que não está listado não é carregado):

```
plugins/my_lang/
├── plugin.json
└── lang/
    └── xx.json    # Seu código de idioma
```

```json
{
  "id": "my_lang",
  "name": "My Language",
  "content": {"languages": ["lang/xx.json"]}
}
```

O código de idioma e o nome exibido na lista de idiomas vêm do bloco `_meta` do arquivo (`"_meta": {"language": "xx", "label": "My Language"}`); sem ele, é usado o nome do arquivo. O código pode ser qualquer string (ex.: `ja`, `ko`, `my_custom`) e aparecerá automaticamente na lista de idiomas no menu de configurações.

## Internacionalização de Campanhas

O texto das campanhas pode usar o prefixo `i18n:` para referenciar chaves de tradução:

```json
{
  "title": "i18n:tut_level1_title",
  "intro": "i18n:tut_level1_intro"
}
```

O jogo resolve automaticamente as chaves de tradução com base no idioma atual. Se uma tradução correspondente não for encontrada, o nome da chave é exibido como está.
