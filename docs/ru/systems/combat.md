---
title: "Боевая система"
---

Бой полностью автоматический. Искатели и враги вступают в бой, когда находятся в пределах дальности атаки друг друга.

---

## Ход боя

1. **Обнаружение** — Искатель замечает врага в пределах обзора (проверяется каждые 2 tick)
2. **Сближение** — Если враг виден, но вне дальности атаки, искатель преследует его
3. **Атака** — Когда обе стороны в пределах дальности атаки, начинается бой
4. **Разрешение** — Урон рассчитывается каждые 5 tick

---

## Расчёт урона

### Искатель атакует врага

| Тип | Формула урона |
|-----|---------------|
| Ближний бой | `ATK × 2` (глобальный множитель урона) |
| Дальний бой | `ATK` (урон снаряда, без множителя) |

### Враг атакует искателя

```
Урон = (ATK врага + random(0~2)) × 2
```

### Защита

```
Фактический урон = max(1, Урон - DEF)
```

### Уклонение

| Источник | Шанс уклонения |
|----------|----------------|
| Базовое уклонение искателей | 10% + 1% × AGI (≤ 70%) |
| Базовое уклонение врага | 5% |
| Навык следопыта «Уклончивость» | +15% |
| Вор: Уклончивость | +10% |
| Вор: Танец теней | +18% |
| Следопыт: Разрыв ветра | +25% |

## Система снарядов

Каждый юнит, который сражается на расстоянии, выпускает собственный снаряд, так что выстрел узнаётся по тому, что летит. Остальные классы сражаются в ближнем бою, хотя и достают на 3 клетки:

| Класс | Тип снаряда |
|-------|-------------|
| Следопыт | Стрела (arrow) |
| Проводник | Дротик (javelin) |
| Дорожный страж | Арбалетный болт (bolt) |
| Маг | Огненный шар (fireball) |
| Адепт | Осколок света (light_shard) |
| Гоблин-лучник (враг) | Грубая стрела (goblin_arrow) |
| Тёмный культист (враг) | Тёмная сфера (dark_orb) |
| Дракон (враг) | Струя пламени (dragon_flame) |

Снаряды летят к цели каждый tick после выпуска и наносят урон при попадании. Каждый рисуется по направлению полёта: тот, что летит вверх по карте, виден сзади, а тот, что летит поперёк, сбоку.

## Лучная башня

Лучная башня — автоматическое оборонительное здание:

| Свойство | Значение |
|----------|----------|
| Дальность атаки | 20 клеток |
| Базовый урон | 16 + 8 × (Lv − 1) |
| Масштабирование при улучшении | Увеличивается с уровнем |

Лучные башни автоматически атакуют ближайшего врага в пределах дальности.

## Награда опытом

| Источник | XP |
|----------|-----|
| За попадание (постепенный) | 1/5 от XP за убийство |
| Убийство слизи | 10 XP |
| Убийство гоблина | 25 XP |
| Убийство скелета | 40 XP |
| Убийство зомби | 60 XP |
| Убийство дракона | 150 XP |

:::note[Постепенный XP]
Каждый раз, когда искатель наносит удар по врагу — ближним боем или снарядом — он получает 1/5 от XP за убийство этого врага. Это гарантирует получение опыта даже без нанесения завершающего удара.
:::

## Боевой ИИ

### Условия отступления искателей

- HP < 30% (HP_CRITICAL)
- Вероятность отступления зависит от черты характера «Безопасность»

### Использование зелий

| Условие | Поведение |
|---------|-----------|
| HP < 30% | Экстренное использование зелья |
| HP < 50% | Использование зелья |

### Приоритет целей врагов

1. Искатели в бою (не пацифисты)
2. Строители (пацифисты)
3. Угрожающие здания, такие как лучные башни
4. Замок
5. Другие здания
