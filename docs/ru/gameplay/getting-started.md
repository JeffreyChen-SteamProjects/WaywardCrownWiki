## Ваша роль

Вы — управляющий Wayward Crown. Вы **не можете** напрямую управлять движением или атаками искателей — они действуют автономно, основываясь на своей личности, потребностях и текущем состоянии.

Что вы можете делать:

- Размещать **флаги поручений** для привлечения искателей в определённые места за золотое вознаграждение
- Строить **здания** для найма определённых классов и обеспечения снаряжением и местами отдыха
- Исследовать навыки в **Библиотеке** для усиления всех искателей
- Управлять **экономикой**, поддерживая баланс доходов и расходов для работы гильдии

## Ваша первая игра

### 1. Начальное строительство

Вы начинаете игру с **1 500 золота** и замком. Стройте в следующем порядке:

1. **Казармы** (150з) — Нанимает воинов, вашу основную боевую силу
2. **Рынок** (300з) — Обеспечивает стабильный налоговый доход
3. **Таверна** (120з) — Позволяет раненым искателям отдыхать и восстанавливать HP
4. **Сторожевой пост** (120з) — Нанимает стражников для патрулирования и защиты зданий

:::tip[Советы по размещению зданий]
При размещении зданий появляется предварительный план: **синий** означает, что место допустимо, **красный** — что нет. Зданиям нужна разведанная суша не ближе 14 клеток к замку и 3 клеток к другим зданиям.
:::

### 2. Размещение поручений

Нажмите кнопку поручений на левой панели, чтобы разместить флаги на карте:

- **Поручение разведки** — Рассеивает туман войны и открывает новые области
- **Поручение на убийство** — Отправляет искателей уничтожить указанную цель
- **Поручение обороны** — Назначает искателей патрулировать и охранять одно из ваших зданий или замок

:::note[Награды за поручения]
Чем выше награда, тем больше искателей согласятся принять поручение. Но следите за бюджетом!
:::

### 3. Наблюдайте и адаптируйтесь

Искатели будут автоматически:

- Покупать зелья и снаряжение в магазинах возле замка
- Принимать поручения, соответствующие их характеру
- Вступать в бой с врагами при встрече
- Возвращаться на отдых при низком уровне HP
- Исследовать неизвестные области и открывать сундуки с сокровищами

### 4. Реагирование на угрозы

По мере прогресса игры будут происходить различные случайные события:

- **Вторжение монстров**: Большая волна врагов атакует замок
- **Кровавая луна**: Сила атаки врагов увеличивается
- **Драконье гнездо**: Вдалеке появляется драконье гнездо, которое необходимо уничтожить

Убедитесь, что у вас достаточно бойцов и лучных башен для обороны!

## Управление экономикой

### Источники дохода

| Источник | Сумма | Периодичность |
|----------|-------|---------------|
| Доход от рынка | 30з × уровень рынка | Каждые 72 секунды игрового времени |
| Налог | 20% от того, что искатели тратят или зарабатывают | Когда искатели покупают, учатся, убивают или открывают сундуки |

Налоги и доход рынка ждут в кассе здания, пока сборщик налогов не отнесёт их в замок.

### Основные расходы

| Статья | Стоимость |
|--------|-----------|
| Строительство зданий | 0 – 300з (каждая следующая копия того же типа на 50% дороже) |
| Улучшение зданий | 140 – 600з |
| Награды за поручения | Настраиваемые (по умолчанию 200з) |
| Исследование навыков | 150 – 900з |

:::caution[Внимание]
Гильдия не может функционировать, если расходы превышают доходы. Отдайте приоритет строительству рынков для обеспечения стабильного потока доходов.
:::

## Настройки сложности

При начале новой игры можно настроить следующие параметры:

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| Соотношение врагов | Количество врагов на одного искателя | 2 |
| Множитель HP врагов | Множитель HP врагов | 1.0x |
| Множитель золота | Множитель заработка золота | 1.0x |
| Вражеские крепости | Количество вражеских крепостей на карте | 3 |
| Размер карты | Длина стороны карты (250 – 1000) | 1000 |
| Раса крепостей песочницы | Ограничивает создаваемые крепости одной расой | Любой (случайно) |
| Сложность песочницы | Лёгкая, Обычная или Сложная: в каждом набеге логова на одного налётчика меньше или на двух больше | Обычная |
| Испытание боссом | Вождь Скрежезуб приходит один раз, через 20 минут | Выкл. |

Лёгкая и тяжёлая сложность никогда не меняют здоровье врагов: на лёгкой в каждом набеге логова на одного налётчика меньше, на тяжёлой на двух больше; на уровне кампании, сложность которого выбирается на экране миссии, сценарная волна к тому же составляет 75% или 125% своего размера, а уровень начинается со 125% или 85% своего золота. Если не осталось гильдий и нет золота на новую, корона возмещает разницу (не чаще раза в пять минут). Сложность задаёт и то, сколько времени у королевства на подготовку к напастям, которые оно навлекает на себя само: и спокойное начало, и предупреждение перед приходом стаи — 125% обычного времени на лёгкой, 80% на трудной. Предупреждение приходит всегда.

## Управление

| Действие | Описание |
|----------|----------|
| Колёсико мыши | Масштабирование карты |
| Перетаскивание правой кнопкой | Перемещение камеры |
| Левый клик по объекту | Просмотр подробной информации |
| Левый клик по карте | Размещение здания / поручения |
| Перетаскивание левой кнопкой | Прокладка дороги (инструментом дороги) |
| Правый клик без перетаскивания | Открыть меню поручений |
| Пробел | Пауза / продолжить |
| 1 / 2 / 3 | Скорость игры (заодно снимает паузу) |
| Esc | Отменить размещение здания или награды; иначе открыть меню игры (сохранение, загрузка, настройки, начать уровень заново, главное меню) |
| Shift + левый клик | Поставить здание и оставить его выбранным |
| Двойной клик по карте | Назначить награду, подходящую к тому, что там находится |
| Ctrl+S / Ctrl+O | Сохранить / загрузить игру |
| Клик по мини-карте | Переход к данной локации |
| Home | Показать замок |
| P | Окно путей замка (на картах с путями) |
| K / C | Обзор королевства / летопись |
| L | Реестры: каждый герой, гильдия, работа и доход каждого здания, с фильтрами |
| M | Слои карты: снабжение, золото в пути, работы, известные угрозы, дальность заклинаний |
| Щелчок по сообщению о месте | Показать это место |
| Щелчок по золоту | Открыть обзор королевства |
| F | Поиск в меню построек |
| Q / W | Подготовить первое / второе королевское заклинание |
| A / S / D / G / H | Взять вид задания, в порядке их панели (та же клавиша убирает его) |
| B | Снова взять последнее поставленное здание |
| F6, затем Tab | Перевести клавиатуру в следующую панель и обойти её элементы (Esc — назад к карте) |

Любую клавишу выше, кроме Esc, можно сменить в Настройки > Клавиши; клавиша, назначенная двум действиям, работает для первого в списке, и настройки об этом говорят; уже занятая клавиша отклоняется. Цифра с цифрового блока считается цифрой. Удерживаемая клавиша срабатывает один раз.

Короткая подсказка приходит, когда впервые можно сделать что-то новое: стройка, касса, которую стоит опустошить, задание, которое никто не берёт, замок, готовый к улучшению, путь на выбор, специализация на выбор, готовое заклинание. Каждая приходит один раз, остаётся в летописи, чтобы перечитать, настройка советника отключает её всплывающее окно, а Настройки > Показать подсказки снова возвращает все. Более поздние приходят вместе с системами, к которым относятся: слои карты, когда известно логово, порядок работ бригады, когда работы копятся, золото без движения, напасть, которую королевство навлекло на себя, герой, чьей гильдии больше нет, герой, думающий уйти.
