## Формат языковых файлов

Языковые файлы хранятся в формате JSON в директории `game/lang/`:

```json
{
  "window_title": "Wayward Crown",
  "log_defeated_enemy": "{adv} defeated {enemy} (Gold: {gold} XP: {xp})",
  "building_market": "Market",
  "class_warrior": "Warrior"
}
```

- Поддержка динамической подстановки через `{placeholder}`
- Отсутствующие ключи перевода автоматически используют английский вариант
- Смена языка вступает в силу немедленно без перезапуска

---

## Порядок определения языка

1. Аргумент командной строки `--lang` / `--language` (наивысший приоритет; действует только в текущем сеансе и не сохраняется)
2. Язык, выбранный пользователем вручную в меню настроек (выбор там варианта «Автоматически (Steam)» сбрасывает его)
3. Язык клиента Steam (определяется автоматически при каждом запуске, пока нет ручного выбора)
4. Язык, использованный в прошлый раз
5. Английский (значение по умолчанию)

## Добавление языков (плагины)

Для добавления языка через плагин нужны только файл перевода и `plugin.json`, в котором он указан в `content.languages` (файл, не указанный там, не загружается):

```
plugins/my_lang/
├── plugin.json
└── lang/
    └── xx.json    # Your language code
```

```json
{
  "id": "my_lang",
  "name": "My Language",
  "content": {"languages": ["lang/xx.json"]}
}
```

Код языка и название, показываемое в списке языков, берутся из блока `_meta` файла (`"_meta": {"language": "xx", "label": "My Language"}`); без него используется имя файла. Код может быть любой строкой (например, `ja`, `ko`, `my_custom`) и автоматически появится в списке языков в меню настроек.

## Интернационализация кампаний

Тексты кампаний могут использовать префикс `i18n:` для ссылки на ключи перевода:

```json
{
  "title": "i18n:tut_level1_title",
  "intro": "i18n:tut_level1_intro"
}
```

Игра автоматически подставляет перевод на основе текущего языка. Если соответствующий перевод не найден, отображается имя ключа как есть.
