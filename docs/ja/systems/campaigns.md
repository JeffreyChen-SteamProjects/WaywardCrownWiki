title: "キャンペーンモード"
---

キャンペーンモードでは、それぞれに特定の勝利条件とストーリー背景を持つ複数レベルのシナリオをプレイできます。

---

## 内蔵キャンペーン

ゲームには、新規プレイヤーにさまざまなゲームメカニクスを紹介する内蔵**チュートリアルキャンペーン**（5レベル）が含まれています。メインメニューの一番上に専用のボタンがあります。

---

## 遠征

遠征は、マップを一つずつ選びながら進むルートです。メインメニューの**遠征**ボタンから始めます。

**辺境遠征**には六つのマップと四つのルートがあり、どのルートも四つのマップを通ります。

| 段階 | マップ | やること |
|---|---|---|
| 開始 | **辺境の拠点** | 町を築き、東にあるゴブリンの野営地を破壊します。南西の古い烽火台は任意で、修復しても回収してもかまいません。 |
| 一つ目 | **交易路の護衛** | 南の道の終点に交易所を開き、隊商の往復を二回支払わせます。山賊のアジトは残しておいてもかまいません。次のマップに 300 ゴールドを渡します。 |
| 一つ目 | **失われた駅舎** | 駅舎の作業をやり遂げます。建て直すか、生存者を家まで連れ帰ります。次のマップに 150 ゴールドを渡します。 |
| 二つ目 | **封印された墓室** | 墓室の作業をやり遂げます。封印するか、研究するか、中を荒らすかです。 |
| 二つ目 | **敵の国境** | ゴブリンの補給線を断ち（荷を届ける前に運搬者を一人倒すか、運搬者を送り出す野営地を破壊します）、ゴブリンの前哨基地を破壊します。古い烽火台は任意です。 |
| 終点 | **王冠峠** | 二度の襲撃をしのぎ、それからゴブリンの砦を破壊します。 |

ルートは辺境の羊皮紙の地図に描かれています。各マップは印章で、この遠征での状態によって縁取りが変わります：勝利済み、今いる場所と開いている次の行き先、残りはまだ閉じたまま。次の行き先は印章か地図の横の一覧で選び、ダブルクリックか Enter で出発します。

峠の砦は増援の第三波を送り出します。ただし、この挑戦の中で敵の国境を破っていれば来ません。墓室を通るルートでも勝てますが、一波多く戦うことになります。駅舎と墓室では遺跡の作業そのものが目的なので、手を付けずに放っておく選択肢はありません。失敗したり撤回したりした作業はもう一度提示され、遺跡の現場を失ったときだけそのマップは負けになります。

**マップとマップの間**では、遠征画面にここまでのルートと次に進める道が表示されます。どの道にもブリーフィングと、ルートの終点で何が変わるかが添えられています。

- 隊を選ぶ: 先へ進む英雄は最大**六人**で、残りは後方で待ちます。控えは最大**十二人**までです。空きがなければ誰かを故郷へ帰してください。英雄は体力が全快して戻ってきます。倒れた者は倒れたままです。
- 次のマップの国庫は、そのマップ自身の予算に、前のマップで残ったゴールドの**半分**（最大 **1000**）と前のマップの報酬を足したものです。出発前に画面が合計を出してくれます。
- 研究と城の道は挑戦の最後まで引き継がれます。建物は置いていきます。

負けたマップは同じスタートからやり直しです。英雄もゴールドもマップも同じです。挑戦はマップの間で止まり、メインメニューから続けるまで待っています。**この挑戦を放棄**でその挑戦を諦め、**完了**で終点まで着いた挑戦を締めくくります。踏破したルートはそれぞれ、ベストタイムとともに記録に残ります。

### 体験版の地図

体験版の 5 つのマップは、1 枚の羊皮紙の地図、**遠征マップ**にも描かれています。最初は「最初の王冠」。それを終えると「交易路の影」「乏しい金貨」「道を守れ」が同時に開き、順番は自由です。3 本のうち 2 本で「グナッシュファングの夜」が開き、残る 1 本も終点を制するまでは遊べます。飛ばしても失敗にはなりません。

| 道 | 次のマップへの報酬 |
|---|---|
| **交易路の影** | 国庫に金貨 300 |
| **乏しい金貨** | 建物が 25% 引き（400 金貨分まで） |
| **道を守れ** | 英雄全員のポーションが満タン、補給金 200 を分配 |

報酬は次のマップで使われて消えます。そのマップをやり直せばもう一度もらえます。隊の英雄、国庫の半分（最大 1000）、研究、城の路線は辺境遠征と同じく持ち越されます。

印章を選ぶと右側にそのマップが表示されます：物語と目標、おおよその所要時間、開始時の国庫と報酬。点線の輪はまだ開いていないマップ（あと何本の道が必要かが書かれます）、金の輪は出発できるマップ、二重の輪はこの遠征で終えたマップです。**旅立つ**で始まり、**練習**ではクリア済みのマップを遠征に触れずに単独で遊べます。地図ができる前にクリアしたマップには印が押されます。ドラッグで移動、ホイールで拡大縮小、矢印キーで印章を移り、Enter で出発、Home で全体表示。

### 地図を作る

キャンペーンの `map_route.json` は、そのマップを地図の上に並べます。キャンペーンエディターの**地図**タブで作ります：各ノードは地図座標 `x`、`y`（左上から 0〜1）にあるマップで、待つノード（`after`）とそのうちいくつ勝てばよいか（`need`、省略時はすべて）を持ちます。`minutes` はブリーフィングの目安時間、`reward` は 1 回きりの報酬（`trade_subsidy`、`build_discount`、`escort_supply` と `amount`）。`links` は墨の線、`end` は最後のノード、`art` は地図の画像：`demo_frontier`、またはキャンペーンフォルダー内の PNG／JPG（1 辺 8192 ピクセル、合計 1600 万ピクセルまで。ないときは無地の羊皮紙）。**ルートを確認**でプレビューが描かれます。`after` のないノードがただ 1 つの出発点で、地図はどれかの順番で終点まで遊べなければならず、ワークショップはすべてのノードが同じキャンペーンか、ゲームに収録されたキャンペーンのマップであることを確かめます。

### キャンペーンのマップ選択の地図

どのキャンペーンも羊皮紙の上でマップを選びます。キャンペーンの `level_map.json` が各マップを置き、キャンペーンエディターの**マップ選択の地図**タブで作ります。`places` は各マップに固定の `id` ごとに座標 `x`、`y`（左上から 0〜1）を与え、`links` は 2 つのマップを結ぶ墨の線、`art` は地図の画像（ゲーム内蔵のもの、またはキャンペーンフォルダー内の PNG／JPG。遠征マップと同じ上限）です。ファイルがないとき、またはマップが一つでも抜けているときは、マップは無地の羊皮紙に道に沿って並び、`requires` で、または順番に遊ぶキャンペーンなら一つずつ線で結ばれます。マップが開いているかどうかは、これまでどおり `requires` で決まります。遠征ルート（`expedition.json`）も同じように `art` と各ノードの `x`、`y` でマップを置けます。ないルートは段ごとに並べられます。

### ルートを作る

キャンペーンは、`campaign.json` の隣に `expedition.json` ファイルを置くと遠征になります。キャンペーンエディタの**遠征ルート**タブで作ります。各ノードにキャンペーンのレベルと、次のノードに渡すゴールド（0〜2000）を割り当て、次に進める道を並べてから、開始と終点を選びます。**ルートを確認**を押すと、ルートがいくつできるかがわかります。ワークショップのチェックでは、すべてのノードが同じキャンペーンか、ゲームに収録されたキャンペーンのレベルを指していることが求められます。プレイテストでは、ルートを開始から遊べます。

```json
{
  "version": 1, "id": "frontier", "start": "camp", "end": "pass", "length": 4,
  "nodes": [{"id": "trade", "campaign": "expedition.frontier", "level": "trade", "grants": {"gold": 300}}, "..."],
  "edges": [["camp", "trade"], ["trade", "tomb"], "..."]
}
```

ルートは開始から終点へたどり着けなければならず、ループがなく、どのノードもいずれかのルート上にあり、どのルートも `length` と同じ長さである必要があります。`requires` には、そのルートが `expeditions` 以外に必要とする機能（たとえば `relics` や `lair_expansion`）を挙げます。レベルがインストールされていないルートや、必要な機能がそのエディションにないルートも、理由とともに遠征画面に表示されますが、始めることはできません。レベルはトリガー条件 `expedition_won` と `expedition_lacks`（`{"node": "<id>"}`）で挑戦のこれまでの道のりに応じて動き、目標 `complete_relic`（遺跡の作業を完了）と `intercept_supply`（敵の補給運搬者 N 人を荷を届ける前に倒すか、運搬者を送り出す野営地をすべて破壊する）でノードに目的を与えられます。

## 勝利条件

各キャンペーンレベルには以下のいずれかの勝利条件を設定できます：

| `victory` | 条件 | 説明 |
|---|-----------|-------------|
| `free` | **フリープレイ** | 特定の勝利条件なし。自由にプレイ |
| `destroy_enemy_buildings` | **全拠点破壊** | マップ上のすべての敵の拠点を殲滅する |
| `survive_ticks` | **指定時間生存** | 指定ティック数を超えて城を存続させる |
| `reach_gold` | **ゴールド蓄積** | 金庫の目標金額に到達する |
| `destroy_building` | **指定拠点破壊** | 特定タイプの敵の拠点を破壊する |
| `defend` | **城を防衛** | 制限時間内に城が破壊されないよう守る |
| `collect_chests` | **全宝箱回収** | マップ上のすべての宝箱を開ける |
| `secure_trade` | **交易路の確保** | 隊商の往復が `victory_value` 回支払われ、マップ上の敵の拠点がすべて破壊される |

## キャンペーンの構造

キャンペーンは `campaigns/` ディレクトリ内にフォルダとして保存されます：

```
campaigns/
└── tutorial/
    ├── campaign.json     # キャンペーンメタデータとレベル一覧
    ├── level1.json       # レベル1マップ
    ├── level2.json       # レベル2マップ
    └── ...
```

### campaign.json の形式

```json
{
  "name": "Tutorial Campaign",
  "description": "Learn the basic game mechanics",
  "levels": [
    {
      "map": "level1.json",
      "title": "A New Beginning",
      "intro": "Welcome to Wayward Crown...",
      "outro": "Congratulations on clearing this level!",
      "starting_gold": 500,
      "victory": "destroy_enemy_buildings",
      "victory_value": 0,
      "victory_target": "",
      "unlocked_buildings": [],
      "carry_over": {"gold": true, "adventurers": true},
      "triggers": [
        {"id": "welcome", "condition": "tick_reached", "params": {"value": 2},
         "action": "show_message", "action_params": {"text_key": "tut_welcome"}}
      ]
    }
  ]
}
```

### レベル設定

| フィールド | 説明 |
|-------|-------------|
| `map` | マップファイルパス（キャンペーンフォルダからの相対パス） |
| `title` | レベルタイトル |
| `intro` | オープニングテキスト |
| `outro` | クリアテキスト |
| `starting_gold` | 初期ゴールド (0 – 10⁷) |
| `victory` | 勝利条件タイプ |
| `victory_value` | 勝利条件の値（例：生存ティック数、目標ゴールド額など） (0 – 10⁹) |
| `unlocked_buildings` | 使用可能な建物ホワイトリスト（プレイヤーの建築オプションを制限）。空のリストはすべての建物を許可する。`unlock_building` は空でないリストに追加する。 |
| `victory_target` | `destroy_building` で対象にする拠点の種類（例: `DRAGON_NEST`）。それ以外の条件では無視されます |
| `carry_over` | 前のレベルから引き継ぐもの: `gold`、`adventurers`、`research`、`path`（城の道とその専門）（それぞれ true/false）。レベルが `carry_over` に挙げたものは、プレイヤーがそのまま次へ進むときに同じキャンペーンの別のレベルから引き継がれ、その時点で記録されます。そのレベルをやり直すたびに、この記録から始まります。キャンペーンの地図から始めたレベルは何も引き継がず、挙げていないもの（研究や城の路線も）はマップを越えて残りません。 |
| `triggers` | スクリプトイベント: `condition` + `params`、`action` + `action_params`、任意で `id`、`after`（そのトリガーの発動を待つ）、`once`。条件: `always`、`tick_reached`、`tick_after_fire`、`gold_at_least`、`adventurer_count_at_least`、`building_built`、`building_count_at_least`、`any_building_damaged`、`enemy_buildings_destroyed`、`enemy_building_seen`、`chests_opened`、`enemy_killed_count`、`bounties_completed`、`buildings_lost`、`caravan_rounds`、`caravans_lost`、`ticks_after_step`、`site_count_at_least`、`bounty_posted`、`taxes_collected`、`branch_chosen`、`spell_cast`、`hero_geared`。アクション: `show_message`、`unlock_building`、`spawn_boss`、`start_event`、`spawn_enemies`、`post_bounty`、`grant_gold`、`reveal`。オブジェクトでないトリガー、または値の種類が違うフィールドを持つトリガーは除外され、コンソールに報告されます。`chests_opened`、`enemy_killed_count`、`bounties_completed` はレベル開始時から数えます。繰り返すトリガー（`once: false`）は条件が成り立つ毎 tick 実行されるため、敵の出現・ゴールド付与・依頼の掲示・イベント開始を行うものはチェックで拒否されます。ボス遭遇は一度だけ始まり、自分が倒された後にしか始まらない形にはできません。`spawn_enemies` の波には `march`（`castle` または `road`）を付けられます。その場合、出現地点をうろつかずに、城または最寄りの交易所へ進軍します。`reveal`（`x`、`y`、1〜40 の `radius`）はプレイヤーに場所を見せます。その半径内の土地が探索済みになります。`ticks_after_step` は、`after` で指定したトリガーが発火したティックから `value` を数えます。`show_message` のパラメータを `i18n:<key>` と書くと、本文に入る前に翻訳されるので、メッセージ内でパネルや建物をゲーム内の呼び名で示せます。 |
| `id` | 進行状況と `requires` で使うレベルの固定名（英数字、`.`、`-`、`_`）。省略時は位置から `level<n>` |
| `requires` | 先にクリアが必要なレベル。このキャンペーンのレベル `id`、または `<キャンペーン id>/<レベル id>` |
| `ruleset` | `kingdom` のみで、省略できる。すべてのレベルは王国のルールで遊ぶ。`classic` を指定した、または何も指定しないレベルやマップは王国として遊ばれ、未知の名前は拒否される |
| `castle_level` | レベル開始時の城のレベル（1–3）。省略時は砦 |
| `time_limit` | レベルに使える tick 数。尽きたときに勝っていなければ敗北。0 または省略で無制限 |
| `advice` | ブリーフィングの助言。他のテキストと同じく `i18n:` キーにできる |
| `side_quests` | レベルの任意目標。二つまで。それぞれ `{"kind", "x", "y"}` で、kind は `supply_party`, `guarded_cache`, `lair_treasure`。`enemy` または `lair` でそこにいるものを指定できる |
| `objectives` | 追加の勝利条件を最大 8 個。各 `{"victory", "value", "target", "required"}` で、victory は `free` 以外のどれでも可。主な勝利（`free` でなければ）とすべての必須条件がそろったときにクリア。任意条件は目標行で数えられ、結果画面に並びます |
| `defeats` | 追加の敗北条件を最大 4 個。各 `{"kind", "value"}`: レベル開始から `heroes_lost`（倒れた英雄）、`buildings_lost`（失った建物）、`caravans_lost`（失った隊商）がその値に達すると敗北 |
| `hero_bonds_disabled` | `true` でこのレベルの英雄は新しい絆を結ばず、仲間も誘わない（それまでの絆は残る）。省略時はいつもどおり |

キャンペーン自体にも `id`（進行状況を記録する名前）と `"linear": false`（独立したチャレンジ集。クリアしても次のレベルへは進まない）を指定できます。`blocked_events` を並べることもできます。そのキャンペーンのレベルでは発生しないランダムイベントの名前です（例: `DRAGON_NEST`）。`roster` も指定できます。そのキャンペーンのレベルでうろつき、侵攻する敵の種類（`GOBLIN` など）で、省略するとすべての種類になります。

:::tip[ローカライズ対応]
キャンペーンテキストでは `i18n:KEY` タグを使用でき、プレイヤーの言語に応じて対応する翻訳が自動的に表示されます。
:::

## デモキャンペーン

デモのストーリーキャンペーン（`campaigns/demo_kingdom/`）はメインメニューから開きます。チュートリアルと同じく `game/systems/demo_campaign.py` が書き出します。

| ミッション | 目標 | 敗北条件 | 開始時 |
|---|---|---|---|
| 1. 最初の王冠 | 砦の東にあるゴブリンの野営地を見つけて破壊させる | 砦が落ちる | 1600 ゴールドと絞られた建物リスト、それに鍛冶屋と市場の廃墟 |
| 2. 交易路の影 | 隊商の往復を 3 回成功させ、盗賊の野営地を破壊する | 城が落ちる | 2400 ゴールド、レベル 2 の城、小さな町、舗装された二本の道 |
| 3. グナッシュファングの夜 | 族長グナッシュファングを倒す | 城が落ちる | 3000 ゴールド、レベル 2 の城、建物 6 棟の町 |

ミッション1は鍛冶屋と市場の廃墟のそばから始まります。王家の作業班が鍛冶屋から順に無償で建て直し、あなたが置いた建物は、最初のギルドも含めて、優先の印を付けないかぎりその後ろで順番を待ちます。ミッション 1 では、最初のギルドから最初の英雄、市場、徴税官へとメッセージが案内します。開始から約 48 秒後、王室が自費で野営地の近くに探索の依頼を出します。英雄がそれを達成すると、野営地に討伐の依頼を出すよう求められます。ミッション 2 では、王室が交易所の候補地を二か所とも探索させ、盗賊が南の道を一度だけ襲い（20 秒前に予告）、最初に建物を失ったときに 400 ゴールドの援助が届きます。ミッション 3 では、1000 tick に東の道から、2500 tick に北の道から襲撃が来て、4300 tick に族長グナッシュファングが来ます。いずれも 100 tick 前に予告されます。彼の要塞を落とすのは略奪の価値がある遠征ですが、勝利になるのは彼を倒したときだけです。ミッション 1 と 2 では修理のために建築者ギルドを建てられます。ミッション 3 では城がすでにレベル 2 なのですぐに道を選べ、落とした砦は自分の襲撃を送らなくなります。ミッション2と3は、そのまま進んだ場合に前のミッションの研究を引き継ぎます。やり直しは毎回最初の挑戦と同じ状態から始まり、地図から選んだミッションは研究なしで始まります。

チャレンジ（`campaigns/demo_challenges/`、`"linear": false`）も同じ方法で書き出されます。「乏しい金貨」はミッション 2 の後に開きます。600 ゴールド、レベル 2 の城、南の道に交易所のある小さな町で、15 分（`time_limit`）以内にゴブリンの野営地と、道を襲う盗賊の野営地を破壊します。野営地自身の襲撃が始まる前に、盗賊が二度道を襲います。「道を守れ」はミッション 3 の後に開きます。交易所はすでに開いており、盗賊が 500 tick ごとに少しずつ強くなって南の道に現れ、14 分 20 秒以内に隊商の往復を 9 回成功させなければなりません。自由王国（デモ版のフリー王国、または製品版のサンドボックス）に目標はありません。開始ダイアログで、開始 20 分後に族長グナッシュファングが一度だけ来るよう選べます（`game/systems/free_kingdom.py`）。「道を守れ」では、襲撃はどれも交易所へ進軍します。誰も守らない交易所は破壊され、隊商もいなくなるため、何もしなければチャレンジは失敗します。

**ボス挑戦**はメインメニューから、専用の羊皮紙の地図で選びます。族長グナッシュファング、砂海の大サソリ、灰燼の暴君の三体と、それぞれ一対一で戦います。建物と研究は14000金から支払い済みで、英雄はギルドが雇う者たちです。ボスは10分後に来て、残り時間は目標欄に表示され、1分前に知らせが届きます。ボスを倒せば勝利。前哨を守ること、灰燼の暴君の護衛を呼ぶ邪教の神殿を壊すことは任意目標で、達成できなくても負けません。難易度「難しい」では各ボスが同じ体力の区切りのまま強化された技を使います。

## 古代の烽火台

古代の烽火台があるマップでは、発見済みの現場を選ぶと詳細欄に費用、期限、選択肢が表示されます。修復には工班か建造者の到着が必要で、半分の進捗で追加出資か撤回を待ちます。完了すると20マス以内の発見済みの敵を警告します。財宝回収は英雄が探索旗を自ら受け、到着して作業する必要があり、国庫と作業者への報酬は各1回です。保留は期限を始めず、撤回は未使用分だけ返金します。遺跡には募集や旗への加算はありません。ステージを離れると、受諾した遺跡の作業は放棄され、撤回と同じく未使用の資金が戻ります。遺跡の効果はそのマップに残り、次のステージへ持ち越されるのはキャンペーンが引き継ぐもの（ゴールド、英雄、研究）だけです。

## 任意のゴブリン補給循環

マップとキャンペーンレベルは `lair_expansion` 機能と同名の最大4件の計画リストを指定できます。各計画には `id` と `target` が必要で、既存のゴブリンのテントを一意の `objective_id` で指定します。運搬者の実際の到着で前哨基地に補給し、生きた作業者が現場で建設します。輸送隊、護衛、守備兵、襲撃は有限予算を共有し、各拠点で最大4回・新規64体です。前哨基地の破壊は未出発の襲撃を遅らせ弱め、本拠地の破壊は新たな生産を止めますが、生存者と任意の前哨基地は残ります。前哨基地は本拠地の必須勝利目標を増やしません。指定なしでは従来の予定を維持します。 運搬者は専用の荷箱、アニメーション、効果音を持ち、指定輸送隊だけに現れます。偵察後、移動中の運搬者に討伐報奨を掲示できます。倒すとその荷物は失われ生産が遅れますが、生きた護衛は戦場に残ります。荷物と報奨は各一度だけ精算し、取り消しには通常の返金規則を使います。 前哨基地には足場、完成した補給棚、崩れた残骸の専用外観があります。攻撃可能な現場を生きた作業者が建設し、未完成では新しい守備兵を出しません。前哨基地の破壊は未出発の攻撃を遅らせ、本拠地に集合を戻します。本拠地の破壊は生産を止めますが、生存者と孤立した前哨基地は残ります。各拠点は装飾用残骸を最大1つ残し、守備兵や勝利目標を増やしません。

マップとキャンペーンの「巣の拡張」フォームで、既存のゴブリンのテントを最大4つ選びます。保護・準備・配達・建設・集合・待機時間、回数、共通ユニット予算、護衛、各拠点最大8つの禁止長方形を設定できます。時間は0.2秒刻みのゲーム内秒です。適用は作者の下書きを更新し、取り消しは元の値を保持します。マップの拠点を空にすると無効化します。キャンペーンのレベル無効化はマップより優先し、指定がなければ空のレベル一覧はマップを継承します。重複・不足拠点と範囲外区域は保存前に拒否します。

共通の前哨基地上限はマップ全体で1～4に設定できます。新しい現場へ向かう輸送隊は出発前に枠を予約し、満員時は他拠点が待機してユニットや襲撃を蓄積しません。生きた孤立前哨基地は破壊されるまで枠を使います。

敵補給情報レイヤーは観測済みの地点と拠点だけを示します。本拠地の生産・体力・金庫・守備兵、前哨基地の段階・進捗、輸送隊の位置には別々の観測時刻があります。視界外では最後の値を保持し、見えない建設や破壊で既知の外観は変わりません。再偵察で更新します。経路は観測済み16地点まで。発見通知は保存後も重複せず、簡報は迎撃、前哨基地破壊、本拠地破壊、有限予算への防衛を説明します。

自由プレイでは有限のゴブリンテント拡張を任意で有効にできます。既定では有効です。混合またはゴブリン限定なら指定した巣の一枠をテントに割り当て、既存テント最大4か所を対象にします。巣の総数は増えません。他種族に拡張元を追加せず、キャンペーンは作者設定を使います。

補給拠点は足場・倉庫・廃墟の異なる輪郭と動く旗布を持ちます。動きを減らす設定では布が静止し、運搬役は実作業中だけ槌を振ります。輸送隊発見と観測した建設・完成・廃墟に専用アイコンと音があり、見えない変化や再読込では通知を繰り返しません。小さい作者画面と情報欄はスクロールでき、情報欄はキーボードでも操作できます。

運搬者は移動中のユニットが新しい前哨基地の敷地から離れるのを最大 10 秒待ちます（納品期限は越えません）。それを過ぎると納品し、まだ敷地にいる者はいちばん近い空きマスへ移されます。運搬者と護衛は予定地の外で止まります。

古代の烽火台から資材を回収した後、作業班が無料で修復することはありません。回収と修復は排他的な選択です。

魔物は遺跡の現場に手を出しません。遺跡自身の守衛も同じで、現場を攻撃することも狙うこともありません。現場で作業するのは味方だけです。

遺跡の選択は一度きりではありません。受諾した作業はいつでも撤回でき、使っていない分は戻ってきます。その後は作業が失敗したときと同じく、現場が残っている限りまっさらな状態でもう一度提示されるので、同じ分岐を選び直すことも別の分岐を選ぶこともでき、どれかが完了するまで続けられます。*手を付けない*は「今はやめておく」という意味でしかありません。

以下は墓室と駅舎の既定条件。発見済みの現場を選ぶと、作者設定の実費、元の期限の残り、実際の結果が分かる。操作中もゲームは進む。

年代記の任意目標欄には、発見済み遺跡の選択分岐、進捗、待機理由、元の期限の残り、実際の結果を表示します。表示リンクは元の現場を示すだけで、選択を受諾したり金を使ったりしません。遺跡が視界に入ったとき、受諾した作業が途中で止まったとき、失敗したとき、完了したときは知らせが届きます。自分で撤回した場合はログに 1 行残ります。現場の見た目は状態を表します。作業を受諾するまでは廃墟、王室が作業中は足場と積まれた資材、完了すると選んだ結果（灯った烽火台か解体された烽火台、封印された墓室か開かれた墓室、建て直された駅舎）、失敗すると瓦礫になります。作業が止まっている理由は具体的に示されます。引き受ける英雄がいない、英雄が断った理由、現場近くの魔物、工兵隊が先に取りかかっている別の仕事（とこの現場の順番）、現場を囲む水辺や崖、建物などです。

任意遺跡の数: 0で生成を無効にします。城の安全区域外の到達可能な開けた場所に、異なる遺跡を最大2か所配置し、道路と通路を保ちます。選択を受諾するまで支払いや作業は始まりません。 現場は城から21～80タイルの範囲で、通常の工班経路検査を通る必要があります。

マップ規則と戦役の関は遺跡エディターを共有し、最大2か所の元の現場、固定選択肢の一部、有界の費用・報酬・作業量・期限を編集できます。取消は原稿を保ち、適用は現場を検証するだけでゲームを進めません。空の関設定はマップを継承し、`relics_disabled: true` で明示的に無効にします。単独マップで全遺跡を消すと、保存時にテンプレートも消えます。

**封印された墓室**

- 封印を補強: 追加支援後、墓地 / アンデッド城 の予定された襲撃だけを 2 回抑制。守軍、自然発生の敵、他の拠点は通常通り。元の拠点が存続する必要がある。
- 研究を支援: 条件を満たす「秘術の親和」を一度解放。利用不可または習得済みなら 80 ゴールド。通常の魔術師の塔と研究前提が必要。半程で停止し、追加支援か撤回を選ぶ。
- 墓室を開く: 実際に探索し、3 体のスケルトン守衛を倒すと財宝 240 ゴールドを一度獲得。資金提供で開棺し、撤回や期限切れ後も生きた守衛は残る。

**失われた駅舎**

- 補給所を再建: 通常価格で治療、薬、錬金試薬を購入できる共有 6 回のレベル1補給を復旧。定期収入や昇級はない。再建と救援は排他的。
- 生存者を護送: 志願英雄が元の生存者を安全な城まで護送する。加入確率 75% は支援時に固定。到着時に職業と経路が許可され、完成したレンジャーの宿舎に空席があれば通常のレンジャー1人が加入。 加入にかかわらず国庫報酬は 120 ゴールド。待機枠は残らず、救援と再建は排他的。

## このリリースの共通システム

体験版と製品版の両方にこの4つがあり、マップ・レベル・設定が求めたときだけ有効になります。古いセーブ・マップ・プラグインが勝手に有効になることはありません。

- **巣の拡張**：ゴブリンのテントの補給輸送、前哨、限られた攻勢。マップかレベルの `lair_expansion`（`lair_expansion_disabled` で無効）、自由プレイでは「有限のゴブリン補給拡張」（既定でオン）。
- **英雄の絆**：関係、誘い、同行と解散、名簿と理由のパネル。レベルが `hero_bonds_disabled` を設けない限り有効、自由プレイでは「英雄の絆」（既定でオン）。
- **遺跡**：古代の烽火台、封印の墓所、失われた駅舎。それぞれ主な選択が2回。マップかレベルの `relics`（`relics_disabled` で無効）、自由プレイでは「任意遺跡の数」（既定で0）。
- **遠征**：ラウンド、ルート、マップをまたぐ名簿の引き継ぎ、やり直し、6マップ4ルートの「辺境遠征」。テンプレートは `requires` する機能を挙げ、レベルや機能が欠けていれば何が欠けているかを示し、作りかけのルートは出しません。

このリリースにないもの：ほかの敵種族の拡張（いまはゴブリンのテントだけ）、遺跡のテンプレートと烽火台以外の遺跡建物の追加、より長い遠征、遠征テンプレートの追加とランダムなルート、そして実際のプレイで決める遺跡の費用・工期・戦闘の強さ（いまは自動計測の値）。
