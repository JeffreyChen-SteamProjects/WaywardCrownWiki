title: "キャンペーンモード"
---

キャンペーンモードでは、それぞれに特定の勝利条件とストーリー背景を持つ複数レベルのシナリオをプレイできます。

---

## 内蔵キャンペーン

ゲームには、新規プレイヤーにさまざまなゲームメカニクスを紹介する内蔵**チュートリアルキャンペーン**（5レベル）が含まれています。メインメニューの一番上に専用のボタンがあります。

---

## 勝利条件

各キャンペーンレベルには以下のいずれかの勝利条件を設定できます：

| `victory` | 条件 | 説明 |
|---|-----------|-------------|
| `free` | **フリープレイ** | 特定の勝利条件なし。自由にプレイ |
| `destroy_enemy_buildings` | **全拠点破壊** | マップ上のすべての敵の拠点を殲滅する |
| `survive_ticks` | **指定時間生存** | 指定ティック数を超えて城を存続させる |
| `reach_gold` | **ゴールド蓄積** | 金庫の目標金額に到達する |
| `destroy_building` | **指定拠点破壊** | 特定タイプの敵の拠点を破壊する |
| `defend` | **城を防衛** | 制限時間内に城が破壊されないよう守る |
| `collect_chests` | **全宝箱回収** | マップ上のすべての宝箱を開ける |
| `secure_trade` | **交易路の確保** | 隊商の往復が `victory_value` 回支払われ、マップ上の敵の拠点がすべて破壊される |

---

## キャンペーンの構造

キャンペーンは `campaigns/` ディレクトリ内にフォルダとして保存されます：

```
campaigns/
└── tutorial/
    ├── campaign.json     # キャンペーンメタデータとレベル一覧
    ├── level1.json       # レベル1マップ
    ├── level2.json       # レベル2マップ
    └── ...
```

### campaign.json の形式

```json
{
  "name": "Tutorial Campaign",
  "description": "Learn the basic game mechanics",
  "levels": [
    {
      "map": "level1.json",
      "title": "A New Beginning",
      "intro": "Welcome to Wayward Crown...",
      "outro": "Congratulations on clearing this level!",
      "starting_gold": 500,
      "victory": "destroy_enemy_buildings",
      "victory_value": 0,
      "victory_target": "",
      "unlocked_buildings": [],
      "carry_over": {"gold": true, "adventurers": true},
      "triggers": [
        {"id": "welcome", "condition": "tick_reached", "params": {"value": 2},
         "action": "show_message", "action_params": {"text_key": "tut_welcome"}}
      ]
    }
  ]
}
```

### レベル設定

| フィールド | 説明 |
|-------|-------------|
| `map` | マップファイルパス（キャンペーンフォルダからの相対パス） |
| `title` | レベルタイトル |
| `intro` | オープニングテキスト |
| `outro` | クリアテキスト |
| `starting_gold` | 初期ゴールド (0 – 10⁷) |
| `victory` | 勝利条件タイプ |
| `victory_value` | 勝利条件の値（例：生存ティック数、目標ゴールド額など） (0 – 10⁹) |
| `unlocked_buildings` | 使用可能な建物ホワイトリスト（プレイヤーの建築オプションを制限）。空のリストはすべての建物を許可する。`unlock_building` は空でないリストに追加する。 |
| `victory_target` | `destroy_building` で対象にする拠点の種類（例: `DRAGON_NEST`）。それ以外の条件では無視されます |
| `carry_over` | 前のレベルから引き継ぐもの: `gold`、`adventurers`、`research`、`path`（城の道とその専門）（それぞれ true/false）。レベルが `carry_over` に挙げたものは、プレイヤーがそのまま次へ進むときに同じキャンペーンの別のレベルから引き継がれ、その時点で記録されます。そのレベルをやり直すたびに、この記録から始まります。ミッション一覧から始めたレベルは何も引き継がず、挙げていないもの（研究や城の路線も）はマップを越えて残りません。 |
| `triggers` | スクリプトイベント: `condition` + `params`、`action` + `action_params`、任意で `id`、`after`（そのトリガーの発動を待つ）、`once`。条件: `always`、`tick_reached`、`tick_after_fire`、`gold_at_least`、`adventurer_count_at_least`、`building_built`、`building_count_at_least`、`any_building_damaged`、`enemy_buildings_destroyed`、`enemy_building_seen`、`chests_opened`、`enemy_killed_count`、`bounties_completed`、`buildings_lost`、`caravan_rounds`、`caravans_lost`、`ticks_after_step`、`site_count_at_least`、`bounty_posted`、`taxes_collected`、`branch_chosen`、`spell_cast`、`hero_geared`。アクション: `show_message`、`unlock_building`、`spawn_boss`、`start_event`、`spawn_enemies`、`post_bounty`、`grant_gold`、`reveal`。オブジェクトでないトリガー、または値の種類が違うフィールドを持つトリガーは除外され、コンソールに報告されます。`chests_opened`、`enemy_killed_count`、`bounties_completed` はレベル開始時から数えます。繰り返すトリガー（`once: false`）は条件が成り立つ毎 tick 実行されるため、敵の出現・ゴールド付与・依頼の掲示・イベント開始を行うものはチェックで拒否されます。ボス遭遇は一度だけ始まり、自分が倒された後にしか始まらない形にはできません。`spawn_enemies` の波には `march`（`castle` または `road`）を付けられます。その場合、出現地点をうろつかずに、城または最寄りの交易所へ進軍します。`reveal`（`x`、`y`、1〜40 の `radius`）はプレイヤーに場所を見せます。その半径内の土地が探索済みになります。`ticks_after_step` は、`after` で指定したトリガーが発火したティックから `value` を数えます。`show_message` のパラメータを `i18n:<key>` と書くと、本文に入る前に翻訳されるので、メッセージ内でパネルや建物をゲーム内の呼び名で示せます。 |
| `id` | 進行状況と `requires` で使うレベルの固定名（英数字、`.`、`-`、`_`）。省略時は位置から `level<n>` |
| `requires` | 先にクリアが必要なレベル。このキャンペーンのレベル `id`、または `<キャンペーン id>/<レベル id>` |
| `ruleset` | `kingdom` のみで、省略できる。すべてのレベルは王国のルールで遊ぶ。`classic` を指定した、または何も指定しないレベルやマップは王国として遊ばれ、未知の名前は拒否される |
| `castle_level` | レベル開始時の城のレベル（1–3）。省略時は砦 |
| `time_limit` | レベルに使える tick 数。尽きたときに勝っていなければ敗北。0 または省略で無制限 |
| `advice` | ブリーフィングの助言。他のテキストと同じく `i18n:` キーにできる |
| `side_quests` | レベルの任意目標。二つまで。それぞれ `{"kind", "x", "y"}` で、kind は `supply_party`, `guarded_cache`, `lair_treasure`。`enemy` または `lair` でそこにいるものを指定できる |
| `objectives` | 追加の勝利条件を最大 8 個。各 `{"victory", "value", "target", "required"}` で、victory は `free` 以外のどれでも可。主な勝利（`free` でなければ）とすべての必須条件がそろったときにクリア。任意条件は目標行で数えられ、結果画面に並びます |
| `defeats` | 追加の敗北条件を最大 4 個。各 `{"kind", "value"}`: レベル開始から `heroes_lost`（倒れた英雄）、`buildings_lost`（失った建物）、`caravans_lost`（失った隊商）がその値に達すると敗北 |

キャンペーン自体にも `id`（進行状況を記録する名前）と `"linear": false`（独立したチャレンジ集。クリアしても次のレベルへは進まない）を指定できます。`blocked_events` を並べることもできます。そのキャンペーンのレベルでは発生しないランダムイベントの名前です（例: `DRAGON_NEST`）。`roster` も指定できます。そのキャンペーンのレベルでうろつき、侵攻する敵の種類（`GOBLIN` など）で、省略するとすべての種類になります。

:::tip[ローカライズ対応]
キャンペーンテキストでは `i18n:KEY` タグを使用でき、プレイヤーの言語に応じて対応する翻訳が自動的に表示されます。
:::

## デモキャンペーン

デモのストーリーキャンペーン（`campaigns/demo_kingdom/`）はメインメニューから開きます。チュートリアルと同じく `game/systems/demo_campaign.py` が書き出します。

| ミッション | 目標 | 敗北条件 | 開始時 |
|---|---|---|---|
| 1. 最初の王冠 | 砦の東にあるゴブリンの野営地を見つけて破壊させる | 砦が落ちる | 1600 ゴールドと絞られた建物リスト、それに鍛冶屋と市場の廃墟 |
| 2. 交易路の影 | 隊商の往復を 3 回成功させ、盗賊の野営地を破壊する | 城が落ちる | 2400 ゴールド、レベル 2 の城、小さな町、舗装された二本の道 |
| 3. グナッシュファングの夜 | 族長グナッシュファングを倒す | 城が落ちる | 3000 ゴールド、レベル 2 の城、建物 6 棟の町 |

ミッション1は鍛冶屋と市場の廃墟のそばから始まります。王家の作業班が鍛冶屋から順に無償で建て直し、あなたが置いた建物は、最初のギルドも含めて、優先の印を付けないかぎりその後ろで順番を待ちます。ミッション 1 では、最初のギルドから最初の英雄、市場、徴税官へとメッセージが案内します。開始から約 48 秒後、王室が自費で野営地の近くに探索の依頼を出します。英雄がそれを達成すると、野営地に討伐の依頼を出すよう求められます。ミッション 2 では、王室が交易所の候補地を二か所とも探索させ、盗賊が南の道を一度だけ襲い（20 秒前に予告）、最初に建物を失ったときに 400 ゴールドの援助が届きます。ミッション 3 では、1000 tick に東の道から、2500 tick に北の道から襲撃が来て、4300 tick に族長グナッシュファングが来ます。いずれも 100 tick 前に予告されます。彼の要塞を落とすのは略奪の価値がある遠征ですが、勝利になるのは彼を倒したときだけです。ミッション 1 と 2 では修理のために建築者ギルドを建てられます。ミッション 3 では城がすでにレベル 2 なのですぐに道を選べ、落とした砦は自分の襲撃を送らなくなります。ミッション2と3は、そのまま進んだ場合に前のミッションの研究を引き継ぎます。やり直しは毎回最初の挑戦と同じ状態から始まり、一覧から選んだミッションは研究なしで始まります。

チャレンジ（`campaigns/demo_challenges/`、`"linear": false`）も同じ方法で書き出されます。「乏しい金貨」はミッション 2 の後に開きます。600 ゴールド、レベル 2 の城、南の道に交易所のある小さな町で、15 分（`time_limit`）以内にゴブリンの野営地と、道を襲う盗賊の野営地を破壊します。野営地自身の襲撃が始まる前に、盗賊が二度道を襲います。「道を守れ」はミッション 3 の後に開きます。交易所はすでに開いており、盗賊が 500 tick ごとに少しずつ強くなって南の道に現れ、14 分 20 秒以内に隊商の往復を 10 回成功させなければなりません。自由王国（デモ版のフリー王国、または製品版のサンドボックス）に目標はありません。開始ダイアログで、開始 20 分後に族長グナッシュファングが一度だけ来るよう選べます（`game/systems/free_kingdom.py`）。「道を守れ」では、襲撃はどれも交易所へ進軍します。誰も守らない交易所は破壊され、隊商もいなくなるため、何もしなければチャレンジは失敗します。

## 王国ミッションを一歩ずつ

1. Creator / Workshop で **新しいプロジェクト**、続いて **王国ミッション** を選び、新しいフォルダを指定します。すぐ遊べるレベルが一つできます。町、東のゴブリンの野営地、王室が出す探索・討伐・防衛の依頼、予告付きの二つの波、そして名のあるボスとしての族長です。
2. キャンペーンエディタで開きます。レベルのフォームには物語（イントロ）、ブリーフィングに出る助言、開始時のゴールド、勝利条件があり、その下に開始時の城レベル、制限時間、最大二つの任意目標とそのタイルがあります。
3. マップを描きます。町、巣、道を動かしてください。場所は城から到達できなければならず、できない場合そこにあるものはレベル開始時に省かれます。マップファイルの建物には `"ruin"`（1〜99）を付けられます。その割合だけ作業が済んだ工事現場として始まり、王家の作業班が無償で仕上げます。
4. トリガーを開いて、メッセージ、王室が出す依頼（`post_bounty`）、波（`spawn_enemies`）、ボスが来る時刻（`spawn_boss`）を変えます。条件 `enemy_building_seen` は巣が視界に入るまで待ちます。
5. `campaign.json` では、キャンペーンの `roster` がマップをうろつく魔物を、`blocked_events` が発生させないランダムイベントを指定します。
6. 検証します。チェックは誤った城レベル、制限時間、任意目標、顔ぶれ、イベント名をフィールドごとに示します。次にワークスペースからレベルを遊びます。そこで選んだ難易度が襲撃、波、開始時のゴールドの大きさを決めます。
7. まず非公開で公開し、思いどおりに遊べるようになってから一般公開します。
