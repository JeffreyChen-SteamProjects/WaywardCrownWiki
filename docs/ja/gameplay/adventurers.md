冒険者はゲームの中心です。自由意志を持ち、性格、ニーズ、現在の状態に基づいて意思決定を行います。

## 状態システム

冒険者は以下の状態を遷移します：

```
IDLE
  ├─→ MOVING_TO_BOUNTY
  ├─→ EXPLORING
  ├─→ PATROLLING
  ├─→ REPAIRING — 建築者のみ
  └─→ FIGHTING
        └─→ RETURNING
              └─→ LODGING
                    └─→ IDLE
```

---

## 宿泊システム

- HP が低くなると冒険者は休息と回復に向かいます。行き先は空きのあるいちばん近い場所で、自分のギルド、宿屋、野営地、城のどれかです。ほぼ同じ近さなら自分のギルドが先（8 タイル近いものとして数えます）、城は最後（8 タイル遠いものとして数えます）です。命からがら逃げるときは、いちばん近い場所に入ります
- 宿泊中の冒険者は**LODGING**状態になり、マップから消えて無敵になります
- 各建物は最大**3**人まで宿泊可能
- 建物が破壊されると、中の宿泊者は即座にマップ上に放出されます
- HPが完全に回復すると自動的に宿泊状態を解除します

## レベルアップシステム

| 項目 | 説明 |
|------|-------------|
| 最大レベル | 20 |
| 基本XP | 40 XP（Lv.2到達に必要） |
| XP計算式 | `40 × 1.6^(level-1)` |
| 撃破XP | 敵の種類により異なる（10 – 160 XP） |
| 戦闘滴下 | 各攻撃で撃破XPの1/5を獲得 |
| 撃破の分配 | 撃破のゴールドと経験値は、何も上乗せせずに分け合います。とどめを刺した英雄は、他に分け合う者がいれば60%を受け取り、残りは6タイル以内で戦っている英雄、または10タイル以内で直近30秒以内に他の英雄を助けた英雄のうち最大3人に等分されます |
| 依頼XP | 探索 15 XP、防衛 25 XP、討伐 30 XP |

レベルアップ時、主要・副次ステータスとHPが上昇します。

**スキルツリー**: 職業のスキルは決まった数の枠ではなく、一本のツリーです。各スキルには習得レベルがあり、先に別のスキルを必要とすることもあります。ツリーの大きさはその職業が持つスキルの数だけです。英雄は、自分のレベルとすでに習得したものが許すスキルをすべて習得します。英雄のパネルにはツリーが表示され、習得済みは太字、これから習得するものは灰色で習得レベルとともに、それぞれ前提となるスキルの下に並びます。（発動）と付いたスキルは英雄が自分で使うもので、それ以外は能力値を恒久的に変えます。

## 性格システム

各冒険者には4つの性格値（0.0 – 1.0）があり、依頼の受諾判断に影響します：

| 特性 | 効果 |
|-------|--------|
| **欲望（gold）** | 値が高いほど報酬を重視する |
| **安全志向（safety）** | 値が高いほど危険を避ける |
| **名誉心（glory）** | 値が高いほど戦闘任務を好む |
| **好奇心（curiosity）** | 値が高いほど探索を好む |

**依頼魅力度の計算式**:

```
level_scale = max(1, level × 0.6)
attraction  = reward / 100 / level_scale × greed + fame × glory - danger × safety
            + 0.3 × curiosity (Explore only) + renown bonus
            - distance × 0.02 / level_scale - danger × 2 (when HP < 40%)
```

- **警告**マーカーは決して受諾されません
- 報酬が **レベル × 20** ゴールド未満の依頼は即座に断られます
- 衛兵は依頼を受けず、代わりに町を巡回します
- レベル8未満の英雄は、警告区域内の依頼を断ります
- 冒険者は最もスコアの高い依頼を受けます（スコアが0.1を超える場合）

## 英雄の自主的な暮らし

することのない英雄は、選べる行動をすべて比べ、最も良いものを選びます。依頼、町での用事、探索のいずれかです。

- **用事**: 鍛冶屋で装備を買い替える、市場でポーションを補充する、図書館で学ぶ、宿屋でひと晩くつろぐ（15 ゴールド。噴水や庭園は無料）、負傷または疲労時に帰る。どれも建物・所持金・実際の必要がそろって初めて行い、英雄はその建物まで歩いて行きます。
- **継続**: 英雄は始めた行程を最後までやり遂げます。探索だけは、150 tick 経過後に明らかに良い選択肢があれば中断します。危険は常に優先で、重傷の英雄は最寄りの休息場所へ向かいます。
- **拠点**: レベル 3 以上の大胆な英雄は、発見済みの敵の拠点へ、単独で挑めると見れば自分から攻め込みます。盗賊はそこから盗みます。
- **支援**: 他者を助ける職業（回復・防護・鼓舞・身代わり）の英雄は、自分の仕事がないとき、仲間に同行します。30タイル以内で、懸賞の仕事や進軍に向かっている、あるいは戦っている最も近い英雄で、その仕事に同行する勇気が持てる相手です。相手が動けば後を追い、相手が倒れる・止まる・帰る、自分が負傷する、または2分が過ぎると離れます。
- **記憶**: 英雄は自分に起きたことをいくつか、それぞれ数分間覚えています。ギルドを襲われた英雄は防衛依頼を30%高く評価します。深手を負ったときに別の英雄に助けられた英雄、あるいは別の英雄と並んで依頼の報酬を受け取った英雄は、その英雄が受けている依頼をより高く評価します。深手を負って引き返した英雄、あるいはそうした英雄が倒れるのを見た英雄は、その場所から12タイル以内ではより良い勝算を求めます。英雄パネルに覚えていることが表示されます。
- **失われたギルド**: ギルドを破壊された、または取り壊された英雄は失われません。自分の職業を雇用し空きのある最も近い建物（再建されたギルドを含む）へ自ら移ります。それまでは城が保護します。城のレベルごとに3人を5分間、それ以上は100秒間です。時間切れになった英雄は持ち物とともに王国を去ります。事前にログと年代記が知らせ、英雄パネルが残り秒数を示します。
- **職業ごとの傾向**: 職業にはそれぞれの習性があります。戦士は深手を負うまで戦い、拠点攻めを好みます。魔法使いは町の近くにとどまり、早めに退き、学ぶことを好みます。レンジャーは遠くまで旅し、探索の依頼を好みます。盗賊は最も報酬の高い依頼を選び、拠点から盗みます。衛兵と建築者は町に残ります。英雄ごとの慎重さと好奇心でこの習性は少し変わり、英雄のパネルにその傾向が表示されます。行動範囲も英雄ごとに異なります。大胆で好奇心が強いほど城から遠くまで出かけるので、同じ職業の英雄でも同じ場所にとどまりません。英雄はまず範囲内の未踏の土地へ向かい、それがなくなると少し先まで足を延ばし、町のまわりを回り続けるのではなく範囲の反対側まで歩いていきます。
- **英雄を読み解く**: 英雄のパネルには、今していることとその理由、行き先、欲求、そして受付中の各依頼への態度（向かっている、手が離せない、断った理由と受ける報酬額）が表示されます。依頼のパネルでは英雄がその理由ごとにまとめられ、少ない報酬で動く者から順に並びます。パネルの最後は英雄の経歴で、直近の八件がゲーム内時刻つきで並びます。買った装備と学んだこと、受けた依頼と決め手（報酬、すでに向かっていた仲間、覚えていること）、受け取った報酬と一緒だった相手、深手を負ったとき誰が助けに来たか、いつ引き返したか。
