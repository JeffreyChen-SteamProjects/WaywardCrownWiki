## あなたの役割

あなたはウェイワード・クラウンの管理者です。冒険者の移動や攻撃を**直接操作することはできません** — 冒険者は性格、ニーズ、現在の状態に基づいて自律的に行動します。

できること：

- **依頼フラグ**を配置して、ゴールド報酬で冒険者を特定の場所に引き寄せる
- **建物**を建設して特定のクラスを募集し、装備や休憩場所を提供する
- **図書館**でスキルを研究して全冒険者を強化する
- **経済**を管理して収入と支出のバランスを保ち、ギルドの運営を維持する

---

## 最初のゲーム

### 1. 初期建設

ゲーム開始時には**1,500ゴールド**と城があります。以下の順序で建設しましょう：

1. **兵舎**（150g）— 戦士を募集。最も基本的な戦闘力
2. **市場**（300g）— 安定した税収を提供
3. **宿屋**（120g）— 負傷した冒険者がHPを回復できる
4. **衛兵所**（120g）— 衛兵を募集して建物を巡回・防衛

:::tip[建設配置のコツ]
建物配置時にブループリントプレビューが表示されます：**青色**は配置可能、**赤色**は配置不可を意味します。建物には探索済みの乾いた地面が必要で、城から14タイル以上、他の建物から3タイル以上離す必要があります。
:::

### 2. 依頼を出す

左パネルの依頼ボタンをクリックしてマップ上にフラグを配置します：

- **探索依頼** — 戦場の霧を晴らし、新しいエリアを発見
- **討伐依頼** — 指定されたターゲットを排除するよう冒険者を派遣
- **防衛依頼** — 自分の建物または城の巡回と防衛に冒険者を割り当て

:::note[依頼報酬]
報酬が高いほど、多くの冒険者が依頼を受けようとします。ただし、予算には注意してください！
:::

### 3. 観察と適応

冒険者は自動的に以下を行います：

- 城の近くのショップでポーションや装備を購入
- 性格に合った依頼を受諾
- 遭遇した敵と戦闘
- HPが低下したら休憩に戻る
- 未知のエリアを探索し宝箱を略奪

### 4. 脅威への対応

ゲームが進むにつれ、様々なランダムイベントが発生します：

- **モンスター侵攻**：大量の敵が城を攻撃
- **血月**：敵の攻撃力が上昇
- **ドラゴンの巣の覚醒**：遠方にドラゴンの巣が出現、破壊が必要

十分な戦闘要員と矢の塔を確保して防衛しましょう！

## 経済管理

### 収入源

| 収入源 | 金額 | 頻度 |
|--------|--------|-----------|
| 市場収入 | 30g × 市場のレベル | ゲーム内時間72秒毎 |
| 税金 | 冒険者が支払う・獲得する金額の20% | 冒険者が購入、研究、討伐、宝箱の開封をした時 |

税金と市場の収入は、徴税官が城へ運ぶまで建物の金庫で待ちます。

### 主な支出

| 項目 | コスト |
|------|------|
| 建物建設 | 0 – 300g（同じ種類の建物は1棟増えるごとに50%高くなる） |
| 建物アップグレード | 140 – 600g |
| 依頼報酬 | カスタム（デフォルト200g） |
| スキル研究 | 150 – 900g |

:::caution[警告]
支出が収入を上回るとギルドは機能しなくなります。安定した収入源を確保するため、市場の建設を優先しましょう。
:::

## 難易度設定

新しいゲームを開始する際に以下を調整できます：

| 設定 | 説明 | デフォルト |
|---------|-------------|---------|
| 冒険者あたりの敵数 | 冒険者1人あたりの敵の数 | 2 |
| 敵HP倍率 | 敵のHP倍率 | 1.0倍 |
| 金貨倍率 | ゴールド獲得倍率 | 1.0倍 |
| 敵の建物 | マップ上の敵拠点の数 | 3 |
| マップサイズ | マップの辺の長さ（250 – 1000） | 1000 |
| サンドボックス種別 | 生成される拠点を1つの種族に限定 | 任意 |
| サンドボックス難易度 | 簡単、普通、難しい：巣の襲撃ごとに襲撃者が1体少ない、または2体多い | 普通 |
| ボス挑戦 | 族長グナッシュファングが20分後に一度だけ来る | オフ |

イージーとハードで敵の体力が変わることはありません。イージーは巣の襲撃ごとに 1 体少なく、ハードは 2 体多くなります。ミッション画面で難易度を選ぶキャンペーンのレベルでは、スクリプトの波も本来の 75% または 125% になり、開始時のゴールドは 125% または 85% になります。ギルドが一つも残らず建てる金もないときは、王室が不足分を出します（最多で 5 分に 1 回）。難易度は、王国が自ら招いた圧力に備える時間も決めます。序盤の猶予と、群れが来る前の予告の両方です。やさしいでは通常の125%、難しいでは80%。予告は必ず出ます。

## 操作方法

| 操作 | 説明 |
|--------|-------------|
| スクロールホイール | マップのズーム |
| 右クリックドラッグ | カメラの移動 |
| 左クリック（エンティティ） | 詳細情報を表示 |
| 左クリック（マップ） | 建物 / 依頼を配置 |
| 左クリックドラッグ | 道路を敷く（道路ツール使用時） |
| 右クリック（ドラッグなし） | 依頼メニューを開く |
| Space | 一時停止 / 再開 |
| 1 / 2 / 3 | ゲーム速度（一時停止中なら再開も） |
| Esc | 建物や懸賞の配置をキャンセル。配置中でなければゲームメニュー（セーブ、ロード、設定、レベルのやり直し、メインメニュー）を開く |
| Shift + 左クリック | 建物を配置して選択したままにする |
| マップをダブルクリック | その場所に合った懸賞を出す |
| Ctrl+S / Ctrl+O | ゲームをセーブ / ロード |
| ミニマップクリック | その場所にジャンプ |
| Home | 城を表示 |
| P | 城の道のウィンドウ（城の道があるマップ） |
| K / C | 王国の概要 / 年代記 |
| L | 名簿: すべての英雄、ギルド、工事、各建物の売上を絞り込みつきで |
| M | マップのレイヤー: 補給、運ばれている金、工事、判明している脅威、魔法の届く範囲 |
| 場所のある通知をクリック | その場所を表示 |
| 所持金をクリック | 王国の概要を開く |
| F | 建設メニューを検索 |
| Q / W | 一つ目 / 二つ目の王家の魔法を構える |
| A / S / D / G / H | パネルの並び順で依頼の種類を選ぶ（同じキーをもう一度押すと戻す） |
| B | 最後に置いた建物をもう一度選ぶ |
| F6、続けて Tab | キーボードを次のパネルへ移し、中の操作を巡る（Esc でマップへ戻る） |

Esc 以外の上のキーはすべて「設定 > キー」で変えられます。二つの操作に割り当てたキーは一覧で先の操作に使われ、設定画面がそう伝えます。すでに使われているキーは受け付けません。テンキーの数字は数字として扱われます。キーを押し続けても動作は一度だけです。

新しいことが初めてできるようになると短いヒントが出ます（工事現場、回収したい金庫、誰も受けない依頼、強化できる城、選べる道、選べる専門、使える魔法）。各ヒントは一度だけで、年代記に残るので読み返せます。助言の設定でポップアップを消せ、「設定 > ヒントをもう一度表示」で全部戻せます。それ以降のヒントは、関係する仕組みとともに出ます。巣を把握したときのマップのレイヤー、工事が溜まったときの作業班の作業順、滞っている金、王国が自ら招いた圧力、ギルドを失った英雄、去ることを考えている英雄。
