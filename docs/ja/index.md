title: "ウェイワード・クラウン"
---

**ウェイワード・クラウン**は経営シミュレーションゲームです。ウェイワード・クラウンの長として、自由意志を持つ冒険者たちを報酬、建物、経済的なインセンティブを通じて**間接的に**導きます。キャラクターを直接操作することはできません — 冒険者の生態系全体を観察し、操作することしかできません。

---

## 主な特徴

- **間接操作** — 冒険者は性格やニーズに基づいて自律的に行動します。影響を与えられるのは依頼、建物、研究を通じてのみです
- **豊富なランダムイベント** — 50種類以上のイベント。血月から宝の雨まで、毎回異なるプレイ体験を提供します
- **奥深い経済** — 依頼の報酬、建物への投資、市場の税金、冒険者の消費のバランスを取りましょう
- **大規模戦闘** — 数千人の冒険者と数万体の敵を同時にフィールドに表示可能
- **カスタムレベル** — 内蔵のマップエディタとキャンペーンエディタで独自のシナリオを作成・共有可能
- **プラグインシステム** — ソースコードを変更せずに、組み込みのクラス・敵・建物を変更し、言語パックを追加可能
- **15言語対応** — 英語、繁体字中国語、簡体字中国語、日本語、韓国語、ロシア語、ドイツ語、フランス語など

---

## ゲームモード

| モード | 説明 |
|------|-------------|
| **チュートリアル** | メインメニューの一番上のボタン。5つの章でゲームを順に学べます |
| **サンドボックスモード** | ランダム生成された大型マップでゼロから始める自由王国。難易度とマップサイズを調整でき、ボスの登場も選べる |
| **カスタムマップ** | マップエディタで作成したレベルを読み込む |
| **キャンペーン** | 複数レベルのシナリオ。内蔵チュートリアルキャンペーン（5レベル）を含む |
| **ゲームを読み込む** | 以前のゲームを続ける |
