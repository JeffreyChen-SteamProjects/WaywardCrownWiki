ウェイワード・クラウンは15言語に対応しており、プラグインでさらに言語を追加できます。

---

## 言語ファイルの形式

言語ファイルはJSON形式で、`game/lang/` ディレクトリに保存されています：

```json
{
  "window_title": "Wayward Crown",
  "log_defeated_enemy": "{adv}が{enemy}を倒した（ゴールド: {gold} XP: {xp}）",
  "building_market": "マーケット",
  "class_warrior": "ウォリアー"
}
```

- `{placeholder}` による動的置換に対応
- 未翻訳のキーは自動的に英語にフォールバック
- 言語の切り替えは再起動なしで即座に反映

---

## 言語検出の優先順位

1. `--lang` / `--language` CLI引数（最優先。このセッションのみ有効で、保存されません）
2. 設定メニューでユーザーが手動選択した言語（そこで「自動（Steam）」を選ぶと解除されます）
3. Steamクライアントの言語（手動選択がない間は、起動のたびに自動検出）
4. 前回使用した言語
5. 英語（デフォルトのフォールバック）

---

## 言語の追加（プラグイン）

プラグインで言語を追加するには、翻訳ファイルと、それを `content.languages` に記載した `plugin.json` のみが必要です（記載されていないファイルは読み込まれません）：

```
plugins/my_lang/
├── plugin.json
└── lang/
    └── xx.json    # 言語コード
```

```json
{
  "id": "my_lang",
  "name": "My Language",
  "content": {"languages": ["lang/xx.json"]}
}
```

言語コードと言語一覧に表示される名前は、ファイルの `_meta` ブロック（`"_meta": {"language": "xx", "label": "My Language"}`）から取得されます。このブロックがない場合はファイル名が使われます。言語コードは任意の文字列（例：`ja`、`ko`、`my_custom`）を使用でき、設定メニューの言語一覧に自動的に表示されます。

## キャンペーンの国際化

キャンペーンテキストでは `i18n:` プレフィックスを使用して翻訳キーを参照できます：

```json
{
  "title": "i18n:tut_level1_title",
  "intro": "i18n:tut_level1_intro"
}
```

ゲームは現在の言語に基づいて翻訳キーを自動的に解決します。一致する翻訳が見つからない場合、キー名がそのまま表示されます。
