どのテンプレートも **クリエイター & Steam ワークショップ**（メインメニュー、マップ管理、プラグイン管理）から始まり、同じ手順で **新しいプロジェクト** から非公開のワークショップアイテムまで進みます。Steam が必要なのは最後の手順だけです。

## 共通の手順

1. **新しいプロジェクト**：テンプレート、名前、フォルダーを選びます。ダイアログは何かを書き込む前に作品の置き場所を表示します。
2. **プロジェクトの編集**：プラグインはプラグインエディターで開きます。地図やキャンペーンは **地形／キャンペーンエディターを開く** で、作品が必要とするものだけを読み込む別プロセスで開きます。次の手順の前に保存してください。確認、テストプレイ、公開は保存済みのファイルを使います。
3. **コンテンツの検証**：各問題は場所を示し、ダブルクリックするとエディターでその場所を開きます。
4. **プレイテスト**：この作品と必要なものだけを入れた別のゲームです。報告には読み込んだものと、実行中のティック時間・メモリ・スプライトアトラスが「問題なし」から「重すぎる」まで示されます。
5. **エクスポート…**：作品 ID を変えずに ZIP またはフォルダーへ書き出し、保存や共有に使います。
6. **ワークショップに公開**：Steam を起動した状態で、最初のテストは **非公開** を選び、**確認してレビュー** と **公開を送信** を押します。公開では読み込みは確かめられません。**ワークショップを閲覧する** でアイテムを見つけて **購読する** を押し、**購読** で利用可能になるまで見守ってください。

## 地図

テンプレートは 32×32 の地図で、城、城の東 2 マスに 100 ゴールドの宝箱、開始資金 500、宝箱を集めると勝利です。

1. 地形エディターで地形を塗り、建物・拠点・宝箱を置いて保存します。
2. **コンテンツの検証** は、英雄が城からたどり着けない拠点・宝箱・ボスを警告します。
3. バージョン：変更を公開するたびに **プロジェクトバージョン** を上げます。古いバージョンで作られたセーブは、その古い版のコピーを保持します。

## キャンペーン

テンプレートは 2 つのレベルで、それぞれ同じ城と宝箱のある独自の地図を持ちます。キャンペーンファイルがレベルの順序と、各レベルのタイトル・物語の文章・開始資金を決めます。

1. 地形エディターでキャンペーンパネルを開き、レベルの順序、勝利条件、物語の文章、引き継ぎ、トリガーを設定します。
2. **プレイテスト** はどのレベルからでも始められます。
3. 依存：レベルでプラグインのユニットを使うときは、**依存関係** にそのプラグインの作品を加え、`>=1.0.0, <2.0.0` のようなバージョン範囲を指定します。

## プラグイン

テンプレートには、英雄クラス、敵、そのクラスを募集する建物、その敵を送り出す拠点、スキル、研究、イベント、名前付きボス、地形タイルのスキン、英語の言語ファイルが入っていて、すべて作品自身の名前空間を使います。

1. **オブジェクト**タブで編集します。上のバーで種類を選びます。各定義はゲームが付ける名前と画像で一覧に並び、選んだものはプレビューされます（歩くユニットは歩きます）。**新規…**は元にするものと名前を選んで追加します。画像とサウンドは定義ごとの行で選ぶかインポートします。プロパティフォームは基本定義から受け継いだ値を灰色にし、ゲームの範囲外の値をすぐに示します。**詳細**は ID で追加する行と定義の JSON を表示します。名前はプラグインの各言語ごとに、その下の行で付けられます（**言語を追加**でプラグインに言語を増やせます）。城の道には効果と専門の表があり、そのほかのテキストにもそれぞれ行があります。
2. 素材：**素材** タブには画像ファイルをドロップでき、それぞれをサイズとメモリの制限と比べて表示します。テンプレートのタイルスキンは例として `preview.png` を使っているので、ここで置き換えます。
3. 上書き：**組み込みをコピー…** はゲームのキャラクターの完全なコピーを自分の ID で加え、使われる場所で元のものと置き換えます。組み込みの ID を使う定義（たとえば base が `SLIME` の `SLIME`）は、プラグインが有効な間ゲーム本来のスライムを変えます。どのプラグインの上書きが勝つかは **コンテンツプロファイル** に表示されます。
4. バージョン：**プロジェクトバージョン** は作品自身のバージョン、**サポートされているゲームのバージョン** は受け入れるゲームバージョンの範囲です（`*` はすべて。開発ビルドは `*` だけを受け入れます）。

## ボスのチュートリアル（プラグイン＋2レベルのキャンペーン）

テンプレートは、プラグインと、それを必要とする 2 レベルのキャンペーンが入ったフォルダーです。2 つ目のレベルはプラグインの名前付きボスを倒すと勝利です。

1. キャンペーンの **依存関係** にはプラグインの作品とバージョンが書かれているので、テストプレイでもプラグインが一緒に読み込まれます。
2. 先にプラグインを、次にキャンペーンを公開します。公開ウィンドウはプラグインのワークショップアイテムを必須アイテムとして提案します。
3. プラグインを変更するたびに **プロジェクトバージョン** を上げ、キャンペーンの範囲はそれを受け入れられる広さにしておきます。

## 王国ミッション（1 レベル: ブリーフィング、依頼、波、ボス）

テンプレートは王国の 1 レベルで、作戦説明、町、巣、王家の探索・討伐・防衛の旗、予告された 2 回の襲撃、名前付きボス、任意の発見物が入っています。キャンペーンパネルでレベルごとに分解し、共通の手順に進んでください。

## フロストファング見本（完成済みのコンテンツパックとそのマップ）

このテンプレートは分解して学べる完成済みの見本です。英雄クラス（フロストウォーデン）、モンスター（ライムイエティ）、そのクラスを募集する館、モンスターの巣、二つのスキル、研究、名前付きボスを収めたコンテンツパック（それぞれ専用の画像とサウンド付き）と、このパックを必須とし、ボスを倒すと勝利になるマップです。同じウィンドウでは、ほかのワークショップカテゴリについても完成済みのサンプルを **サンプル：〈カテゴリ〉** として選べます（マップ、キャンペーン、ストーリー、チャレンジ集、研究・イベント・言語のパックなど）。自分のプロジェクトとしてコピーされるので、遊んだり、中身を調べたり、改変したりできます。

1. 地形エディタでマップを開いて **オブジェクト…** を押し、各定義がゲームのどれを元にしているかを確認します。数値や名前を変えて保存し、その結果をマップに配置してみましょう。
2. **テストプレイ** を押すと、このパックだけを読み込んでマップをプレイできます。
3. 先にパックを公開し、次にマップを公開します。公開ウィンドウがパックのワークショップアイテムを必須アイテムとして提案します。

## テンプレートに決して入らないもの

テンプレートには実在のワークショップアイテム ID、Steam アカウント、絶対パスは入りません。作品 ID はあなたのコンピューターで新しく作られ、すべてのファイルは作品内の相対パスで示されます。
