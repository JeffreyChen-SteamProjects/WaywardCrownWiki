---
title: "マップエディタとキャンペーンエディタ"
---

ウェイワード・クラウンには、カスタムレベルやシナリオを作成できるマップエディタとキャンペーンエディタが内蔵されています。

---

## マップエディタ

メインメニューの **エディタツールキット** ボタンを押すと、新しいマップでエディタが開きます。保存したマップの一覧表示、プレイ、編集、インポート、エクスポートは、メインメニューの **キャンペーン** ボタンで開くマップ管理画面の「マップ」タブで行います。

### 機能

- **地形ペイント** — 地形タイプを選択し、ブラシ（サイズ 1 – 20）でマップに塗る、または領域を塗りつぶす
- **建物とユニット** — プレイヤーの建物、王国の英雄、敵の拠点、モンスター、宝箱を配置、城を移動、または消去。エディタが確かめるのは置ける地面かどうかだけです。ゲーム中は城のレベル、城の道、ステージの解放が必要なものも自由に置けます。道は建物ではなく地形の一つです
- **ランダム化** — 出発点となるランダムなマップを生成
- **元に戻す / やり直し** — 最大30手（Ctrl+Z / Ctrl+Y）
- **マップ設定** — サイズ（1辺 100 – 1000 タイル）、名前・作者などの詳細情報、開始金貨、勝利条件
- **保存/読み込み** — マップを `maps/` ディレクトリに保存。閉じる・Esc・新規は未保存の変更を捨てる前に確認し（保存／破棄／キャンセル）、一度も保存していないキャンペーンを破棄するとそのフォルダーも削除されます
- **オブジェクト…** — 英雄クラス、モンスター、建物、拠点、ボスを、自分のコンテンツパックの中でオブジェクトエディタを使って編集します。ボタンには自分のパックの一覧と **新しいコンテンツパック…** が並び、マップを保存していなくても使えます。パックは単体で成り立つプラグインです。保存するとコンテンツが読み込み直され、定義したものをすぐに配置できます。マップやキャンペーンがパックを必須とするのは、そのパックのものを置いた状態で保存したときだけです
- **テストプレイ** — 保存済みのマップ（またはキャンペーンの編集中のステージ）を別のゲームで開始します。必須としているコンテンツパックだけを読み込み、ほかのコンテンツは読み込みません
- **パネル** — ブラシとマップのルール（またはキャンペーン）は、マップの両脇に並ぶタブ付きのパネルです。反対側へドラッグしたり、ウィンドウの外へ出したり、閉じたりでき、**パネル**から呼び戻せます。地形、建物、拠点、ボスは絵で選びます。エディタと、そこから開くウィンドウ（オブジェクトエディタ、トリガーエディタ、マップの詳細）は最大化できます

配置した英雄とモンスターはマップに保存され、ゲーム開始時にその場所に立っています。ゲームが進むと、さらに英雄が募集され、モンスターも出現します。

### 地形タイプ

- 草原、森林、山岳、水域、砂漠、道、泥地、沼地、雪原、丘陵、荒地、花畑

### 保存形式

マップは `maps/` ディレクトリにJSON形式で保存され、以下の内容を含みます：

- 地形データ（圧縮されたNumPy配列）
- 高さデータ
- 建物、敵の拠点、宝箱、配置した英雄とモンスター
- 城の位置
- マップの詳細情報、開始金貨、勝利条件

## キャンペーンエディタ

キャンペーンの作成、オープン、インポート、エクスポートは、マップ管理画面（メインメニューの **キャンペーン** ボタン）の「キャンペーン」タブで行います。キャンペーンを開くとキャンペーンパネル付きのマップエディタが起動し、各レベルのマップとその設定を一か所で編集できます。

### 機能

- **レベル順序** — 矢印ボタンでレベルを上下に移動
- **勝利条件** — 各レベルの勝利条件を設定（`destroy_building` の対象となる拠点タイプを含む）
- **ストーリーテキスト** — イントロと完了テキストを設定
- **初期資金** — 各レベルの初期ゴールドを設定
- **引き継ぎ** — 前のレベルのゴールド、冒険者、研究を引き継ぐ
- **建物制限** — プレイヤーが使用できる建物タイプを制限
- **トリガー** — レベルごとのスクリプトメッセージと建物の解放（キャンペーンのレベルのみ）
- **王国用フィールド** — レベルの開始時の城レベル、制限時間、ブリーフィングの助言、最大二つの任意目標
- **追加の目標と敗北条件** — 必須または任意の勝利条件の追加と、敗北の追加（倒れた英雄、失った建物や隊商）を、二つの表で追加・削除
- **対象の出どころ** — 勝利対象の下に、ボスがマップに配置されたものかトリガーで開始されるものか、拠点タイプがゲームのものかプラグインのものか、マップにいくつあるかを表示。追加目標の対象はツールチップで同じことを示します

### 勝利条件の選択肢

エディターではこれらを名前で（表示言語で）一覧します。下の表のタイプは、マップやキャンペーンのファイルに保存される値です。

| タイプ | 説明 |
|------|-------------|
| `free` | フリーモード、勝利条件なし |
| `destroy_enemy_buildings` | すべての敵の拠点を破壊する |
| `survive_ticks` | 指定時間生き延びる |
| `reach_gold` | 指定金額のゴールドを蓄積する |
| `destroy_building` | 特定タイプの拠点を破壊する |
| `defend` | 指定時間城を防衛する |
| `collect_chests` | すべての宝箱を回収する |
| `defeat_boss` | 名前付きボスを倒す（マップに配置するか、トリガーで開始する） |
| `secure_trade` | 隊商の往復を指定回数成功させ、すべての敵の拠点を破壊する |

### 保存構造

```
campaigns/my_campaign/
├── campaign.json         # キャンペーンメタデータ
├── level1.json           # レベル1マップ
├── level2.json           # レベル2マップ
└── level3.json           # レベル3マップ
```

## カスタムコンテンツの共有

- マップやキャンペーンのフォルダは、コピーするだけで、またはマップ管理画面のエクスポートとインポートで共有できます
- 受け取ったマップを `maps/` に配置すると、メインメニューから読み込めます
- 受け取ったキャンペーンを `campaigns/` に配置すると、メインメニューに表示されます
- Steam から起動している場合、マップ管理画面の **ワークショップに公開** で自分のマップやキャンペーンを Steam ワークショップに公開でき、購読したものは一覧に [ワークショップ] 付きで表示されます。これらは Steam が最新に保つため編集・名前変更・削除はできません。**複製** すると自分のマップになります
- コンテンツパックは単体で導入できます。パックだけを公開するか、パックの ZIP だけを共有すれば、導入した人はマップなしで、そのクラス、モンスター、建物、拠点を自分のゲームで使えます。パックのものを置いたマップやキャンペーンはそのプラグインを必要とします。公開するときはパックを先に公開してください（公開ウィンドウがパックのワークショップアイテムを必須アイテムとして提案します）
