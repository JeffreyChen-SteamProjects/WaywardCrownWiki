title: "创作者教程"
---

每个模板都从 **创作工具与 Steam 创意工坊**（主菜单、地图管理器或插件管理器）开始，用同样的步骤从 **新增项目** 走到私人创意工坊项目。只有最后一步需要 Steam。

## 共同步骤

1. **新增项目**：选择模板、名称与文件夹。对话框会在写入任何东西之前显示作品会放在哪里。
2. **编辑项目**：插件会打开插件编辑器；地图或战役用 **打开地形／战役编辑器** 打开，它在独立的进程中运行，只加载作品需要的内容。进入下一步前先保存：检查、试玩与发布都使用已保存的文件。
3. **验证内容**：每个问题都会说明位置；双击即可在编辑器中打开到那里。
4. **试玩**：在独立的游戏中只加载这个作品与它需要的内容。报告会列出加载了什么，并在运行时显示 tick 时间、内存与精灵图集，从正常到过重分级。
5. **导出…**：导出为 ZIP 或文件夹，作品 ID 不变，用来保存或分享。
6. **发布到创意工坊**：在 Steam 运行时，第一次测试请选 **私密**，再按 **检查并审阅** 与 **提交发布**。发布不会检查能否加载：请在 **浏览创意工坊** 找到该项目、按 **订阅**，并在 **订阅** 看着它直到可用。

## 地图

模板是一张 32×32 的地图，有一座城堡、城堡东边两格有一个装 100 金币的宝箱、起始金币 500，胜利条件是收集宝箱。

1. 在地形编辑器中绘制地形并放置建筑、据点与宝箱，然后保存。
2. **验证内容** 会警告英雄从城堡走不到的据点、宝箱或 BOSS。
3. 版本：每次发布变更时都要提高 **项目版本**。用旧版本创建的存档会保留旧版本的副本。

## 战役

模板有两关，每关都有自己的地图，城堡与宝箱相同；战役文件决定关卡顺序，并为每关设置标题、剧情文字与起始金币。

1. 在地形编辑器中打开战役面板，调整关卡顺序、胜利条件、剧情文字、延续内容与触发器。
2. **试玩** 可以从任何一关开始。
3. 依赖：关卡用到某个插件的单位时，在 **依赖项** 加入该插件的作品，并设置版本范围，例如 `>=1.0.0, <2.0.0`。

## 插件

模板包含一个英雄职业、一种敌人、一座招募该职业的建筑、一座派出该敌人的据点、一个技能、一项研究、一个事件、一个具名 BOSS、一种地块外观与一个英文语言文件，全部使用作品自己的命名空间。

1. 在**物件**分页编辑。上方的栏选种类；每个定义都用游戏会给它的名称与图列出来，选到的那个有预览（会走路的单位会走）。**新增…**用“以什么为基础”加上名称来新增；图与音效在它自己的行里选取或汇入；属性表单会把沿用基础定义的值标成灰色，并立即标出超出游戏范围的值。**进阶**会显示用 ID 新增的那一行与定义的 JSON。
2. 素材：**素材** 标签页可以直接拖放图片文件，并把每个文件与大小及内存限制比较。模板的地块外观用 `preview.png` 作为示例图片，可在这里替换。
3. 覆盖：**复制内置内容…** 会用你自己的 ID 加入游戏角色的完整副本，并在用到的地方取代原本的角色。使用内置 ID 的定义（例如 base 为 `SLIME` 的 `SLIME`）会在插件启用时改变游戏本身的史莱姆；**内容配置** 会显示哪个插件的覆盖生效。
4. 版本：**项目版本** 是作品本身的版本；**支持的游戏版本** 是它接受的游戏版本范围（`*` 代表任何版本；开发版只接受 `*`）。

## 首领教学（插件＋双关卡战役）

模板是一个文件夹，里面有一个插件与一个需要它的两关战役；第二关要击败插件里的具名 BOSS 才算胜利。

1. 战役的 **依赖项** 写着插件的作品与版本，因此试玩时会一起带上插件。
2. 先发布插件，再发布战役：发布窗口会建议把插件的创意工坊项目设为必要项目。
3. 每次修改插件都要提高它的 **项目版本**；战役的版本范围要宽到能接受新版本。

## 王国任务（单关：简报、旗标、敌波、BOSS）

模板是一个王国关卡，包含任务简报、城镇、怪巢、王室的探索、击杀与防守旗帜、两波预告的袭击、一个具名 BOSS 与一个可选的发现。在战役面板中逐关拆解它，然后按共同步骤进行。

## 模板绝不包含的东西

模板不包含真实的创意工坊项目 ID、Steam 账号或绝对路径：作品 ID 会在你的电脑上新生成，每个文件都以作品内的相对路径命名。
