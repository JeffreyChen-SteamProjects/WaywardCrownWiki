title: "多语言"
---

不驯之冠支持 15 种语言，并可通过插件新增更多。

---

## 语言文件格式

语言文件为 JSON 格式，放在 `game/lang/` 目录下：

```json
{
  "window_title": "不驯之冠",
  "log_defeated_enemy": "{adv} 击败了 {enemy}（金币: {gold} XP: {xp}）",
  "building_market": "市场",
  "class_warrior": "战士"
}
```

- 支持 `{placeholder}` 动态替换
- 缺少的翻译键自动回退至英文
- 切换语言即时生效，不需重启

---

## 语言检测顺序

1. `--lang` / `--language` CLI 参数（最高优先；只对本次运行有效，不会保存）
2. 用户在设置菜单手动选择的语言（在那里选择「自动」会清除此选择）
3. Steam 客户端语言（没有手动选择时，每次启动都会自动检测）
4. 上次使用的语言
5. 英文（预设回退）

## 新增语言（插件）

通过插件新增语言只需要一个翻译文件，以及在 `content.languages` 中列出该文件的 `plugin.json`（未列出的文件不会被载入）：

```
plugins/my_lang/
├── plugin.json
└── lang/
    └── xx.json    # 你的语言代码
```

```json
{
  "id": "my_lang",
  "name": "My Language",
  "content": {"languages": ["lang/xx.json"]}
}
```

语言代码以及语言列表中显示的名称来自该文件的 `_meta` 区块（`"_meta": {"language": "xx", "label": "My Language"}`）；没有此区块时使用文件名。代码可以是任意字符串（如 `ja`、`ko`、`my_custom`），会自动出现在设置菜单的语言列表中。

## 战役多语言

战役文字可以使用 `i18n:` 前缀标记翻译键：

```json
{
  "title": "i18n:tut_level1_title",
  "intro": "i18n:tut_level1_intro"
}
```

游戏会根据当前语言自动解析翻译键。如果找不到对应翻译，会直接显示键名。
