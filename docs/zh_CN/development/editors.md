title: "地图与战役编辑器"

不驯之冠内建地图编辑器和战役编辑器，让你打造自定义关卡和剧本。

---

## 地图编辑器

主菜单的 **地图编辑器** 按钮会以一张新地图打开编辑器。已保存的地图在地图管理器的「地图」页签中列出，可在此游玩、编辑、导入与导出；地图管理器由主菜单的 **战役** 按钮打开。

### 功能

- **地形绘制** — 选择地形类型，用画笔（大小 1 ~ 20）在地图上绘制，或填充一整块区域
- **建筑放置** — 放置玩家建筑、敌方据点和宝箱，移动城堡，或擦除
- **随机地形** — 生成一张随机地图作为起点
- **撤销／重做** — 最多 30 步（Ctrl+Z／Ctrl+Y）
- **地图设置** — 大小（每边 100 ~ 1000 格）、名称、作者等信息、初始金币与胜利条件
- **存读档** — 存档到 `maps/` 目录；关闭、Esc 与新建会在丢弃未保存的更改前询问（保存／不保存／取消），放弃一个从未保存的战役会一并删除它的文件夹
- **物件…** — 在物件编辑器里编辑为这张地图做的英雄职业、怪物、建筑、据点与首领。第一次会创建地图的内容包（你自己的一个插件，地图会把它列为必需项目）；内容包保存后会重新载入内容，它定义的东西马上可以放到地图上
- **试玩** — 用已保存的地图（或战役正在编辑的那一关）另开一场游戏，只带它的内容包，不带你其他的内容

地图不包含单位：冒险者在游戏开始后招募，敌人也在游戏进行时生成。

### 地形类型

- 草地、森林、山地、水域、沙漠、道路、泥地、沼泽、雪地、丘陵、荒地、草甸

### 存档格式

地图以 JSON 格式存放在 `maps/` 目录下，包含：

- 地形数据（压缩的 NumPy 数组）
- 高度数据
- 建筑、敌方据点与宝箱
- 城堡位置
- 地图信息、初始金币与胜利条件

## 战役编辑器

战役在地图管理器的「战役」页签（主菜单的 **战役** 按钮）中新建、打开、导入与导出。打开战役会启动带有战役面板的地图编辑器，让你在同一处编辑每一关的地图与设置。

### 功能

- **关卡排序** — 用箭头按钮上下移动关卡
- **胜利条件** — 为每关设定胜利条件，包括 `destroy_building` 的据点类型
- **故事文字** — 设定开场与过关文字
- **初始资源** — 设定每关的初始金币
- **继承** — 保留上一关的金币、冒险者与研究
- **建筑限制** — 限制玩家可用的建筑类型
- **触发器** — 为关卡设定脚本信息与建筑解锁（仅限战役关卡）
- **王国字段** — 关卡的起始城堡等级、时限、简报的建议，以及最多两个可选目标
- **附加目标与失败条件** — 更多胜利条件（每个可设为必做或选做）与更多失败方式（倒下的英雄、失去的建筑或商队），在两个表格中添加与移除
- **目标来源** — 在胜利目标下方显示：BOSS 是摆放在地图上还是由触发器启动，据点类型是游戏内置还是插件的、地图上有几个；附加目标的目标栏以提示显示同样信息

### 胜利条件选项

编辑器以你的语言显示这些条件的名称；下表的类型是地图与战役文件里存的值。

| 类型 | 说明 |
|------|------|
| `free` | 自由模式，无胜利条件 |
| `destroy_enemy_buildings` | 摧毁所有敌方据点 |
| `survive_ticks` | 存活指定时间 |
| `reach_gold` | 累积指定金额 |
| `destroy_building` | 摧毁特定类型据点 |
| `defend` | 防守城堡指定时间 |
| `collect_chests` | 收集所有宝箱 |
| `defeat_boss` | 击败具名首领（摆在地图上或由触发器启动） |
| `secure_trade` | 让商队完成指定趟数的往返，并摧毁所有敌方据点 |

### 存档结构

```
campaigns/my_campaign/
├── campaign.json         # 战役元数据
├── level1.json           # 第一关地图
├── level2.json           # 第二关地图
└── level3.json           # 第三关地图
```

## 分享自定义内容

- 地图和战役文件夹可以直接复制分享，也可以用地图管理器的导出与导入
- 收到的地图放入 `maps/` 即可在主菜单载入
- 收到的战役放入 `campaigns/` 即可在主菜单看到
- 通过 Steam 运行游戏时，地图管理器的 **发布到创意工坊** 可以把自己的地图或战役发布到 Steam 创意工坊，订阅的内容会出现在列表中并标上 [创意工坊]。这些内容由 Steam 保持更新，所以不能编辑、重命名或删除；**复制** 可以得到一份自己的地图
- 有内容包的地图或战役会需要那个插件：分享时要一起给，发布时先发布内容包（发布窗口会建议把内容包的创意工坊项目列为必需项目）
