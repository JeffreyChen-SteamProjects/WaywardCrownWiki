---
title: "战斗系统"
---

战斗是完全自动的。冒险者与敌人在攻击范围内会自动交战。

---

## 战斗流程

1. **侦测** — 冒险者在视野内发现敌人（每 2 tick 检查一次）
2. **接近** — 如果敌人在视野内但不在攻击范围内，冒险者会追击
3. **攻击** — 进入攻击范围后，双方开始交战
4. **解算** — 每 5 tick 进行一次伤害结算

---

## 伤害计算

### 冒险者攻击敌人

| 类型 | 伤害公式 |
|------|---------|
| 近战 | `攻击力 × 2`（全局伤害倍率） |
| 远程 | `攻击力`（投射物伤害，不乘倍率） |

### 敌人攻击冒险者

```
伤害 = (敌人攻击 + random(0~2)) × 2
```

### 防御

```
实际伤害 = max(1, 伤害 - 防御力)
```

### 闪避

| 来源 | 闪避率 |
|------|--------|
| 冒险者基础闪避 | 10% + 1% × 敏捷 (≤ 70%) |
| 敌人基础闪避 | 5% |
| 游侠「闪避」技能 | +15% |
| 盗贼: 闪避 | +10% |
| 盗贼: 暗影之舞 | +18% |
| 游侠: 破风 | +25% |

## 投射物系统

每个远程作战的单位都有自己专属的投射物，看飞的是什么就知道是谁出手。其他职业即使攻击距离有 3 格，也是近战：

| 职业 | 投射物类型 |
|------|----------|
| 游侠 | 箭矢 (arrow) |
| 林径斥候 | 标枪 (javelin) |
| 税路卫士 | 弩矢 (bolt) |
| 法师 | 火球 (fireball) |
| 共鸣术士 | 光晶 (light_shard) |
| 哥布林弓手（敌人） | 粗制箭矢 (goblin_arrow) |
| 黑暗教徒（敌人） | 暗影球 (dark_orb) |
| 飞龙（敌人） | 龙焰 (dragon_flame) |

投射物在发射后每 tick 朝目标移动，命中后结算伤害。每种投射物都依飞行方向绘制：往地图上方飞的会看到背面，横向飞的会看到侧面。

---

## 箭塔

箭塔是自动防御建筑：

| 属性 | 值 |
|------|-----|
| 攻击距离 | 20 格 |
| 基础伤害 | 16 + 8 × (Lv − 1) |
| 升级提升 | 随等级增加 |

箭塔会自动攻击范围内最近的敌人。

## 经验奖励

| 来源 | XP |
|------|-----|
| 每次命中（Drip） | 击杀 XP 的 1/5 |
| 击杀史莱姆 | 10 XP |
| 击杀哥布林 | 25 XP |
| 击杀骷髅 | 40 XP |
| 击杀僵尸 | 60 XP |
| 击杀飞龙 | 150 XP |

:::note[Drip XP]
每次命中敌人（无论近战或投射物命中）都会获得该敌人击杀 XP 的 1/5。这确保即使没有击杀也能获得经验。
:::

## 战斗 AI

### 冒险者逃跑条件

- HP < 30%（HP_CRITICAL）
- 逃跑概率受安全性格影响

### 药水使用

| 条件 | 行为 |
|------|------|
| HP < 30% | 紧急使用药水 |
| HP < 50% | 使用药水 |

### 敌人攻击优先顺序

1. 战斗中的冒险者（非和平主义者）
2. 建筑工人（和平主义者）
3. 箭塔等威胁建筑
4. 城堡
5. 其他建筑
