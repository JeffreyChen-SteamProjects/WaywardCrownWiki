title: "不驯之冠 Wayward Crown"
---

**不驯之冠**是一款模拟经营游戏。你扮演不驯之冠的管理者，通过悬赏、建筑与经济手段**间接引导**一群拥有自主意志的冒险者。你无法直接控制任何角色——只能观察并操控整个冒险者生态系。

---

## 核心特色

- **间接控制** — 冒险者依据自身性格与需求自主行动，你只能通过奖金、建筑与研究来影响他们
- **丰富的随机事件** — 超过 50 种事件，从血月到宝箱雨，每场游戏都不同
- **深度经济系统** — 平衡悬赏支出、建筑投资、市场税收与冒险者消费
- **大规模战斗** — 支持数千名冒险者与上万敌人同时在场
- **自制关卡** — 内建地图编辑器与战役编辑器，打造并分享你自己的剧本
- **插件系统** — 修改内置的职业、敌人与建筑，新增语言包，无须修改源代码
- **15 种语言** — 英文、繁中、简中、日文、韩文、俄文、德文、法文等

---

## 游戏模式

| 模式 | 说明 |
|------|------|
| **教学** | 主菜单最上面的按钮：五个章节一步步教你怎么玩 |
| **沙盒模式** | 在随机生成的大型地图上从零开始经营的自由王国，可调整难度与地图大小，并有可选的 BOSS |
| **自定义地图** | 载入以地图编辑器制作的关卡 |
| **战役** | 多关卡剧本，内建教学战役（5 关） |
| **读取存档** | 继续先前的游戏进度 |
