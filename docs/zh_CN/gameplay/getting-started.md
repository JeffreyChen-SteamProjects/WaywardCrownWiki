## 你的角色

你是不驯之冠的管理者。你**无法**直接控制任何冒险者的移动或攻击——他们会根据自己的性格、需求与当前状态自主行动。

你能做的事：

- 放置**悬赏旗帜**，用奖金吸引冒险者前往指定地点
- 建造**建筑**，招募特定职业、提供装备与休息场所
- 通过**图书馆**研究技能，全面强化冒险者
- 管理**经济**，平衡收支以维持公会运作

## 第一场游戏

### 1. 开局建设

游戏开始时你有 **1,500 金币**与一座城堡。建议依序建造：

1. **兵营**（150g）— 招募战士，最基本的战力
2. **市场**（300g）— 提供定期税收收入
3. **旅店**（120g）— 让受伤冒险者休息回血
4. **卫兵哨所**（120g）— 招募城镇卫士巡逻保护建筑

:::tip[建筑放置技巧]
建筑放置时会显示蓝图预览：**蓝色**表示可建造，**红色**表示不可建造。建筑必须放在已探索的陆地上，距离城堡至少 14 格，与其他建筑至少相隔 3 格。
:::

### 2. 发布悬赏

点击左侧面板的悬赏按钮，在地图上放置旗帜：

- **探索悬赏** — 揭开战争迷雾，发现新区域
- **讨伐悬赏** — 派人击杀指定目标
- **防守悬赏** — 指派冒险者巡逻守卫你的某栋建筑或城堡

:::note[悬赏奖金]
奖金越高，越多冒险者愿意接受。但要注意收支平衡！
:::

### 3. 观察与适应

冒险者会自动：

- 在城堡附近的商店购买药水和装备
- 接受符合自身性格的悬赏
- 遭遇敌人时进入战斗
- 血量不足时返回休息
- 探索未知区域并拾取宝箱

### 4. 应对威胁

随着游戏进行，会出现各种随机事件：

- **怪物入侵**：大批敌人进攻城堡
- **血月**：敌人攻击力提升
- **龙巢觉醒**：远处出现龙巢，需派人摧毁

确保你有足够的战力和箭塔来防御！

## 经济管理

### 收入来源

| 来源 | 金额 | 频率 |
|------|------|------|
| 市场收入 | 30g × 市场等级 | 每 72 秒游戏时间 |
| 税收 | 冒险者花费或赚取金额的 20% | 冒险者购物、学习、击杀或开宝箱时 |

税收与市场收入会留在建筑的钱柜里，直到税务员把它们送回城堡。

### 主要支出

| 项目 | 费用 |
|------|------|
| 建筑建造 | 0 ~ 300g（同类型每多建一栋贵 50%） |
| 建筑升级 | 140 ~ 600g |
| 悬赏奖金 | 自定义（预设 200g） |
| 研究技能 | 150 ~ 900g |

:::caution[注意]
入不敷出时公会就无法运作。优先建造市场确保稳定收入。
:::

## 难度设定

开始新游戏时可调整：

| 设定 | 说明 | 预设值 |
|------|------|--------|
| 敌人与冒险者比例 | 每位冒险者对应的敌人数量 | 2 |
| 敌人血量倍数 | 敌人 HP 乘数 | 1.0x |
| 金钱倍率 | 金币获取乘数 | 1.0x |
| 敌方建筑数量 | 地图上的敌方据点数 | 3 |
| 地图大小 | 地图边长（250 ~ 1000） | 1000 |
| 沙盒类型 | 将生成的据点限定为单一种族 | 任意 |
| 沙盒难度 | 简单、普通或困难：每次怪巢袭击少一只或多两只 | 普通 |
| BOSS 挑战 | 裂牙酋长在 20 分钟后来袭一次 | 关闭 |

简单与困难绝不改变敌人的血量：简单让每次怪巢袭击少一只，困难多两只；在任务画面选定难度的战役关卡，剧本敌波还会是原本的 75% 或 125%，起始金币是 125% 或 85%。一座公会都不剩、又没钱再盖时，王室会补足差额（最多每五分钟一次）。难度也决定王国有多少时间准备应付自己招来的压力，包括开局的缓冲与敌群到来前的预警：简单是平常的 125%，困难是 80%。预警一定会有。

## 快捷操作

| 操作 | 说明 |
|------|------|
| 滚轮 | 缩放地图 |
| 右键拖拽 | 平移摄像机 |
| 左键点击实体 | 查看详细信息 |
| 左键点击地图 | 放置建筑 / 悬赏 |
| 左键拖拽 | 铺设道路（使用道路工具时） |
| 右键点击（不拖拽） | 打开悬赏菜单 |
| 空格键 | 暂停 / 继续 |
| 1 / 2 / 3 | 游戏速度（暂停中也会继续） |
| Esc | 取消放置建筑或悬赏；没有在放置时打开游戏菜单（保存、读取、设置、重新开始本关、主菜单） |
| Shift + 左键 | 放置建筑并保持选中 |
| 双击地图 | 发布适合该处目标的悬赏 |
| Ctrl+S / Ctrl+O | 保存 / 读取游戏 |
| 迷你地图点击 | 快速跳转到该位置 |
| Home | 显示城堡 |
| P | 城堡路线窗口（有城堡路线的地图） |
| K / C | 王国总览 / 事件簿 |
| L | 名册：每位英雄、公会、工程与每栋建筑的营收，附筛选 |
| M | 地图图层：补给、在路上的金币、工程、已知威胁、法术范围 |
| 点击关于某地的通知 | 显示那个地点 |
| 点击金钱 | 打开王国总览 |
| F | 搜索建造菜单 |
| Q / W | 准备第一个 / 第二个王室法术 |
| A / S / D / G / H | 照面板上的顺序拿起一种赏金任务（再按同一个键放下） |
| B | 再拿起上一座放下的建筑 |
| F6，再按 Tab | 把键盘移到下一个面板并走遍里面的控件（Esc 回到地图） |

上面除 Esc 以外的按键都能在「设置 > 按键」更改；同一个键设给两个动作时，只有列表里第一个会用到，设置里会提示；已被占用的键会被拒绝。数字小键盘的数字视同数字。按住一个键只会作用一次。

第一次能做某件新事时会有一则简短提示：工地、该收的钱柜、没人接的悬赏、可以升级的城堡、可以选的路线、可以选的专精、可以用的法术。每则只出现一次，会记进事件簿可以重看；顾问设置可以关掉它的弹出消息，「设置 > 重新显示提示」能让它们再出现。之后的提示会随所属的系统出现：发现巢穴后的地图图层、工程排队时工班的施工顺序、卡住的金币、王国自己招来的压力、失去公会的英雄、想离开的英雄。
