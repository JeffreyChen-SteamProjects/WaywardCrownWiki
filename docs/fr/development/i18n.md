Wayward Crown prend en charge 15 langues, avec la possibilité d'en ajouter d'autres via des plugins.

## Format des fichiers de langue

Les fichiers de langue sont au format JSON, stockés dans le répertoire `game/lang/` :

```json
{
  "window_title": "Wayward Crown",
  "log_defeated_enemy": "{adv} defeated {enemy} (Gold: {gold} XP: {xp})",
  "building_market": "Market",
  "class_warrior": "Warrior"
}
```

- Supporte la substitution dynamique avec `{placeholder}`
- Les clés de traduction manquantes sont automatiquement remplacées par l'anglais
- Le changement de langue prend effet immédiatement sans redémarrage

---

## Ordre de détection de la langue

1. Argument CLI `--lang` / `--language` (priorité la plus élevée ; s'applique uniquement à cette session et n'est pas enregistré)
2. Langue sélectionnée manuellement par l'utilisateur dans le menu des paramètres (y choisir « Automatique (Steam) » l'efface)
3. Langue du client Steam (détectée automatiquement à chaque lancement tant qu'aucun choix manuel n'existe)
4. La langue utilisée la dernière fois
5. Anglais (langue par défaut)

## Ajout de langues (Plugins)

L'ajout d'une langue via un plugin ne nécessite qu'un fichier de traduction et un `plugin.json` qui le liste sous `content.languages` (un fichier non listé n'est pas chargé) :

```
plugins/my_lang/
├── plugin.json
└── lang/
    └── xx.json    # Your language code
```

```json
{
  "id": "my_lang",
  "name": "My Language",
  "content": {"languages": ["lang/xx.json"]}
}
```

Le code de langue et le nom affiché dans la liste des langues proviennent du bloc `_meta` du fichier (`"_meta": {"language": "xx", "label": "My Language"}`) ; sans ce bloc, le nom du fichier est utilisé. Le code peut être n'importe quelle chaîne de caractères (ex. `ja`, `ko`, `my_custom`) et apparaîtra automatiquement dans la liste des langues du menu des paramètres.

## Internationalisation des campagnes

Le texte des campagnes peut utiliser le préfixe `i18n:` pour référencer des clés de traduction :

```json
{
  "title": "i18n:tut_level1_title",
  "intro": "i18n:tut_level1_intro"
}
```

Le jeu résout automatiquement les clés de traduction en fonction de la langue actuelle. Si aucune traduction correspondante n'est trouvée, le nom de la clé est affiché tel quel.
