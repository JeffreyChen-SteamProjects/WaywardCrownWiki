## Format plików językowych

Pliki językowe są w formacie JSON, przechowywane w katalogu `game/lang/`:

```json
{
  "window_title": "Wayward Crown",
  "log_defeated_enemy": "{adv} defeated {enemy} (Gold: {gold} XP: {xp})",
  "building_market": "Market",
  "class_warrior": "Warrior"
}
```

- Obsługuje dynamiczne podstawianie `{placeholder}`
- Brakujące klucze tłumaczeń automatycznie używają angielskiego jako języka zapasowego
- Zmiana języka działa natychmiast bez konieczności restartu

---

## Kolejność wykrywania języka

1. Argument CLI `--lang` / `--language` (najwyższy priorytet; obowiązuje tylko w bieżącej sesji i nie jest zapisywany)
2. Język wybrany ręcznie przez użytkownika w menu ustawień (wybranie tam opcji „Automatycznie (Steam)” usuwa ten wybór)
3. Język klienta Steam (wykrywany automatycznie przy każdym uruchomieniu, dopóki nie ma ręcznego wyboru)
4. Język użyty ostatnim razem
5. Angielski (domyślny język zapasowy)

## Dodawanie języków (pluginy)

Dodanie języka za pomocą pluginu wymaga jedynie pliku tłumaczenia i pliku `plugin.json`, który wymienia go w `content.languages` (plik, którego tam nie wymieniono, nie jest wczytywany):

```
plugins/my_lang/
├── plugin.json
└── lang/
    └── xx.json    # Twój kod języka
```

```json
{
  "id": "my_lang",
  "name": "My Language",
  "content": {"languages": ["lang/xx.json"]}
}
```

Kod języka i nazwa wyświetlana na liście języków pochodzą z bloku `_meta` pliku (`"_meta": {"language": "xx", "label": "My Language"}`); bez niego używana jest nazwa pliku. Kod może być dowolnym ciągiem znaków (np. `ja`, `ko`, `my_custom`) i automatycznie pojawi się na liście języków w menu ustawień.

## Internacjonalizacja kampanii

Teksty kampanii mogą używać prefiksu `i18n:` do odwoływania się do kluczy tłumaczeń:

```json
{
  "title": "i18n:tut_level1_title",
  "intro": "i18n:tut_level1_intro"
}
```

Gra automatycznie rozwiązuje klucze tłumaczeń na podstawie aktualnego języka. Jeśli odpowiednie tłumaczenie nie zostanie znalezione, wyświetlana jest nazwa klucza w niezmienionej formie.
