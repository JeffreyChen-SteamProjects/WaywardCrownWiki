## Formato dei file di lingua

I file di lingua sono in formato JSON, salvati nella directory `game/lang/`:

```json
{
  "window_title": "Wayward Crown",
  "log_defeated_enemy": "{adv} defeated {enemy} (Gold: {gold} XP: {xp})",
  "building_market": "Market",
  "class_warrior": "Warrior"
}
```

- Supporta la sostituzione dinamica con `{segnaposto}`
- Le chiavi di traduzione mancanti ricadono automaticamente sull'inglese
- Il cambio di lingua ha effetto immediato senza necessità di riavvio

---

## Ordine di rilevamento della lingua

1. Argomento CLI `--lang` / `--language` (priorità massima; vale solo per questa sessione e non viene salvato)
2. Lingua selezionata manualmente dall'utente nel menu impostazioni (scegliere "Automatico (Steam)" lì la cancella)
3. Lingua del client Steam (rilevata automaticamente a ogni avvio finché non c'è una scelta manuale)
4. La lingua usata l'ultima volta
5. Inglese (fallback predefinito)

---

## Aggiungere lingue (Plugin)

Aggiungere una lingua tramite plugin richiede solo un file di traduzione e un `plugin.json` che lo elenchi in `content.languages` (un file non elencato non viene caricato):

```
plugins/my_lang/
├── plugin.json
└── lang/
    └── xx.json    # Il tuo codice lingua
```

```json
{
  "id": "my_lang",
  "name": "My Language",
  "content": {"languages": ["lang/xx.json"]}
}
```

Il codice lingua e il nome mostrato nell'elenco delle lingue provengono dal blocco `_meta` del file (`"_meta": {"language": "xx", "label": "My Language"}`); senza di esso viene usato il nome del file. Il codice può essere qualsiasi stringa (es. `ja`, `ko`, `my_custom`) e apparirà automaticamente nell'elenco delle lingue nel menu impostazioni.

## Internazionalizzazione delle campagne

Il testo delle campagne può usare il prefisso `i18n:` per fare riferimento alle chiavi di traduzione:

```json
{
  "title": "i18n:tut_level1_title",
  "intro": "i18n:tut_level1_intro"
}
```

Il gioco risolve automaticamente le chiavi di traduzione in base alla lingua corrente. Se non viene trovata una traduzione corrispondente, viene visualizzato il nome della chiave così com'è.
